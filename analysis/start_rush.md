# START RUSH!! — 楽曲分析

BPM 196 で駆け抜けながら、Ab major から C major、E major を経て Ab major へと、長 3 度ずつ調を巡って帰ってくる。iii から駆け上がる 4 段の進行をエンジンに、間奏ではヘンドリクス・コード、ブリッジでは増長 7 の和音まで持ち込む。「もっともっと強くなりたい！」と叫ぶ真っすぐな歌の裏で、カタログ屈指の大がかりな調の旅が組まれている。

## iii から駆け上がる 4 段のエンジン

曲のエンジンは、イントロから鳴る一つの上行進行である。

```
Cm → Db → Eb → Fm
Cm → Db → Eb → Fm → Ab
```

Ab major の iii→IV→V→vi。根音が C→Db→Eb→F と一段ずつ上がり、最後に I の Ab へ届く。トニックから始めず、短調の iii から階段を登り始めるので、**最初から「上へ上へ」と駆け上がる力**が働く。Aメロとサビはこの進行をそのまま土台にしている。

```
Cm → Db → Eb → Fm                     「もっともっと上に行きたい！」
Cm → Db → Eb → Edim → Fm → Ab
Cm → Db → Eb → Edim
Fm → Cm → Db → Eb → C7/E
Ab/C → Db
Eb → Fm
Ab
```

階段には細かい部品が足されている。Eb と Fm の間に挟まる Edim は、ベースを Eb→E→F と半音で押し上げる経過和音だ。C7/E は Fm（vi）へ向かう二次ドミナント（V7/vi）で、同じく E をベースに置き、Fm へ力強く流れ込む。Ab/C は I の 3 度をベースにした転回形で、低音を C から Db へ滑らかにつなぐ。どの部品も、ベースラインを止めずに上へ運ぶために置かれている。

サビは同じ進行の上で、「もっともっと強くなりたい！」「夢に向かって今すぐ走り出すよ」と歌詞が前向きに爆発する。そこに「ReadyReady! HurryHurry! いくよ START RUSH!」のコール＆レスポンスが重なり、曲は最高潮に達する。

## 長 3 度ずつ、三つの調を巡って帰る

この曲の最大の仕掛けは、調の動きである。

最初の転調は 1 番の後の間奏で起きる。Ab major から C major へ、長 3 度上への大胆な移動だ。続く Bメロ、Cメロも C major のまま進み、サビで Ab major に戻る。ブリッジにあたる Dメロで再び C major に移り、その終わりで E major の領域へ踏み込む。落ちサビは E major とその平行調 C#m（表記は Dbm）の圏内で歌われ、最後の Eb を足場に、Ab major のラストサビへ一瞬で帰還する。

Ab から C、C から E、E から Ab（G#）。どの移動も長 3 度上で、三度動くとオクターブを一周して元の調に戻る。**調を均等に三分割した輪の上を、ぐるりと一周する設計**である。

落ちサビの中身を見ると、その設計がさらにはっきりする。

```
A → B → Dbm                           「大切なもの守る気持ちが」
Abm → A → B → Cdim → Dbm → E
Abm → A → B → Cdim
Dbm → Abm → A → B → E → Eb
```

Abm→A→B→Cdim→Dbm→E は、E major の iii→IV→V→（経過 dim）→vi→I。サビの Cm→Db→Eb→Edim→Fm→Ab を、そっくり E major に移した形だ。Cdim はサビの Edim と同じく、V から vi へベースを半音で押し上げる経過和音の役を担う。同じエンジンを別の調で回してから、最後の Eb で半音下へ踏み外し、Eb を V とする Ab major のサビへ落ちていく。この帰還の瞬間は鳥肌ものである。

## ヘンドリクス・コードと増長 7 の和音

調の旅の途中には、ジャンルの枠をはみ出す和音がいくつも置かれている。

```
F → Em7 → Dm7 → Cadd9 → C
G9/B → Am7 → E7#9/G# → G → C
```

間奏の 2 行目にある E7#9/G# は、いわゆるヘンドリクス・コード（ジミ・ヘンドリクスが好んだ、長 3 度と短 3 度が同居する 7(#9) の和音）だ。C major では Am への二次ドミナントにあたり、Am への導音 G# をベースに置きながら、実際には G→C へ解決する。疾走の只中に、ジャズやファンクの風味が鋭いフックを作る。

Dメロでは、さらに珍しい和音が現れる。

```
F → C/E → G/D → C
CM9/B → Am7 → AbaugM7 → G/B → Cadd9
CM9/B → Am7 → AbaugM7 → E → Abm          （繰り返し後）
```

AbaugM7 は、C major から見て ♭VI の Ab を増三和音にし、長 7 度の G を足した和音だ。Ab-C-E-G という構成は、どの調の中にも素直には収まらず、幻想的に浮遊する響きを持つ。分析した曲の中で増長 7 の和音が出てくるのは、この曲だけである。繰り返しの後、AbaugM7 は E へ進み、E→Abm（G#m）と E major の圏内へ入っていく。AbaugM7 に含まれる E と G#（Ab）の音が、次の調への入り口になっている。

## 楽曲を追う

### Intro

前述の iii→IV→V→vi→I の上行。

### Aメロ（もっともっと上に行きたい！）

前述の上行ループに Edim、C7/E、Ab/C を足した形。

### 間奏

前述のとおり、ギターとシンセのブレイクで C major へ移り、E7#9/G# のテンションを鳴らす。

### Bメロ（できない理由探して）

```
C → C/D → C/E
C → G/B → C
C → C/D → C/E → F
G → Abdim7
```

C を保ったまま、ベースだけが C→D→E と歩いて上がるウォーキングベース。「歩き出す」から「走り出す」へ、足取りが速まっていくさまを低音で描く。歌われるのは「できない理由探して」「逃げてばかりいたよね」と、昨日までの弱い自分だ。行末の Abdim7 が突然現れ、Ab major の圏へ戻ることを不安な色で予告する。

### Cメロ（やっと見つけた大切なもの）

```
Am → Caug/G# → C → D/F#
Dm7 → Em7 → G → C7
E7
```

Am から Caug/G# へ。増三和音の G# がベースの半音下行の一部となり、夢見るような浮遊感を生む。D/F# は C major の II（V/V、V への二次ドミナント）の第 1 転回形で、ベースを F# に上げて次へつなぐ。C7 は I に短 7 度を足した形で、ここから Fm を含む Ab major の圏へ帰る準備をする。最後に E7 が単独で放たれ、強烈なドミナント感を残してサビへなだれ込む。

### サビ（もっともっと強くなりたい！）

前述のとおり、Aメロと同じ進行で、最後は Eb→Fm→Ab と I まで登りきる。

### Dメロ

前述の F→C/E→G/D→C と、AbaugM7 を含む進行。

### 落ちサビ（大切なもの守る気持ちが）

前述の E major／C#m 圏でのエンジンの再現と、Eb による帰還。

### ラストサビ〜アウトロ

```
Cm → Db → Eb → Fm                     （サビ）
Cm → Db / Eb → Fm                     「ありがとう…」（×3）
Ab                                    「Don't be afraid! 走れ…」
```

フルのサビの後、「ありがとう」を三度繰り返す。「生まれた気持ちに」「巡り逢えた君に」「今から始まる未来すべてに」と、感謝の対象が少しずつ広がっていく。最後は「Don't be afraid! 走れ / 想い / 届け」の三連呼で、I の Ab に着地する。

## カタログの中で

BPM 196 は、リリース時点ではビスケットケース（206）に次ぐカタログ 2 位の速さだった。その後に速い曲が増え、今は PLAYFUL ROMANTIC、POJI POJI GO と同じ 196 で、上には Happy Go Round と MY FIRST LOVE SONG（220）、Hey! get up kids（210）、ビスケットケース（206）、BABY BABY BABY（200）、もちぷる（198）の 6 曲がいる。

古橋勇紀の作品はカタログでこの一曲だけだが、その転調の設計は後の作品と響き合う。NNBS. の MY FIRST LOVE SONG は C major から Ab major へ長 3 度下に転調し、本作の Ab→C（長 3 度上）とちょうど鏡像の関係になる。同じ NNBS. の恋するとちゅうも Ab→Eb→F と三つの調を巡るが、本作は長 3 度の輪を一周して元の調に帰る点で、より大がかりである。ヘンドリクス・コードについても、本作の E7#9/G# が、分析ファイルで確認できる限りカタログ最初の例で、AILI の OK（2025）や Hey!Yummy!（2025）に先立つ。

スコアでは、クール 6.6 とエモ 7.1 が目を引く。同じ時期の速い曲と比べると、Hey!Baby!（クール 4.7）、SCP!（5.7）、ビスケットケース（3.4）のいずれよりもクールが高い。歌詞の「走れ」「強くなりたい」は Hey!Baby! の「Dash」「Jump」と通じるが、あちらが理由のいらない身体の躍動だったのに対し、こちらは「できない理由探して」いた過去の自分を自覚し、それを乗り越えるという物語を持っている。

## 総評

iii から駆け上がる階段を、Ab、C、E と三つの調で踏み、長 3 度の輪を一周して帰ってくる。その途中にはヘンドリクス・コードも増長 7 の和音もあるが、196 の速度の中ではそれらが難解さではなく、景色の変化として通り過ぎていく。弱さを認めるところから始まり、「ありがとう」で終わる歌詞もまた、一周して出発点に戻る構造を持つ。全力疾走のロックに、緻密な調の地図を仕込んだ一曲である。
