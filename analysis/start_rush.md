## 構成とコード進行

### Intro
```
Cm → Db → Eb → Fm
Cm → Db → Eb → Fm → Ab
```
Ab major の iii→IV→V→vi→I。順次上行する力強い進行が「走り出す」感覚を生む。

### Aメロ（もっともっと上に行きたい！）
```
Cm → Db → Eb → Fm
Cm → Db → Eb → Edim → Fm → Ab
Cm → Db → Eb → Edim
Fm → Cm → Db → Eb → C7/E
Ab/C → Db
Eb → Fm
Ab
```
- iii-IV-V-vi の上行ループが基本骨格
- **Edim** を経過和音として挿入し、Fm への半音アプローチを形成
- **C7/E** = V7/vi（二次ドミナント）で Fm に力強く解決
- **Ab/C** 転回ベースで低音を滑らかに Db へ接続

### 間奏（ギター＋シンセブレイク）
```
F → Em7 → Dm7 → Cadd9 → C
G9/B → Am7 → E7#9/G# → G → C
```
- **Ab major → C major** へ大胆に転調（長3度上）
- **E7#9/G#** = ジミヘンコード的テンション。Am への導音を含みつつ G → C へ解決
- Jazz/Funk フレーバーが疾走感の中にフックを作る

### Bメロ（できない理由探して）
```
C → C/D → C/E（ウォーキングベース上行）
C → G/B → C
C → C/D → C/E → F
G → Abdim7
```
- C major 圏でウォーキングベース（C→D→E）が「歩き出す→走り出す」を音で描写
- **Abdim7** が突然現れ、Ab major 圏への帰還を予告する不安な色彩

### Cメロ（やっと見つけた大切なもの）
```
Am → Caug/G# → C → D/F#
Dm7 → Em7 → G → C7
E7
```
- **Caug/G#** = 増三和音。G# が半音下行ベースラインの一部となり、夢見るような浮遊感
- **D/F#** = IV の転回。ベースが F# に上がり Em7 へ滑らかに接続
- **C7** = I7。サブドミナント化して Fm 圏への帰還準備
- **E7** = 単独で放たれ、次セクションへの強烈なドミナント感

### サビ（もっともっと強くなりたい！）
```
Cm → Db → Eb → Fm
Cm → Db → Eb → Fm → Ab
Cm → Db → Eb → Edim
Fm → Cm → Db → Eb → C7/E
Ab/C → Db
Eb → Fm → Ab
```
Aメロと同じ進行だが、歌詞が「もっともっと強くなりたい！」「夢に向かって今すぐ走り出すよ」と前向きに爆発。「ReadyReady! HurryHurry! いくよ START RUSH!」のコール＆レスポンスで最高潮。

### Dメロ（ブリッジ・落ちサビ）
```
F → C/E → G/D → C
CM9/B → Am7 → AbaugM7 → G/B → Cadd9
（繰り返し後）
CM9/B → Am7 → AbaugM7 → E → Abm
```
- C major 圏に再び転調
- **AbaugM7** = ♭VI augM7 という極めて珍しい和音。Ab の増三和音に長7度。幻想的で浮遊する響き
- **E → Abm** = enharmonic に G#m = Abm。E major 圏（Dbm の関係調）への転調ブリッジ

### 落ちサビ（大切なもの守る気持ちが）
```
A → B → Dbm
Abm → A → B → Cdim → Dbm → E
Abm → A → B → Cdim
Dbm → Abm → A → B → E → Eb
```
- **Dbm (= C#m) 圏** に転調。iii-IV-V-vi にあたる構造を E major で再現
- **Cdim** = 経過減和音（Ab major 圏の Edim に相当する役割）
- 最後の **Eb** がピボットとなり、Cm サビ（Ab major）に一瞬で復帰 — 鳥肌もの

### ラストサビ → アウトロ（ありがとう）
```
Cm → Db → Eb → Fm（サビフル）
Cm → Db / Eb → Fm（ありがとう×3）
Ab
```
- 「ありがとう 生まれた気持ちに」「巡り逢えた君に」「今から始まる未来すべてに」
- 最後は「Don't be afraid! 走れ / 想い / 届け」で I (Ab) に着地

## 楽曲の特徴

### コード面
1. **iii-IV-V-vi 上行進行** がメインエンジン — 常に「上へ上へ」駆け上がる構造
2. **3つの調性圏を横断**: Ab major → C major → E major/Dbm → Ab major
3. **長3度転調** (Ab→C) と **enharmonic 転調** (E→Abm=G#m→Eb→Cm) の組み合わせ
4. **E7#9 (ジミヘンコード)** と **AbaugM7 (増長7)** — ジャンルを超えたテンション

### リズム・サウンド面
- **196 BPM** はグループ最速クラス（ビスケットケース 206BPM に次ぐ）
- ギターとシンセの**ハイブリッド編成**が疾走感と空間の広がりを両立
- 間奏のJazzフレーバーが知的なアクセント

### 歌詞面
- 「**もっともっと強くなりたい！**」— 核心メッセージ
- 「できない理由探して / 上手ないいわけして / 逃げてばかりいたよね / 昨日までの私」— 過去の弱さの自覚
- 「夢に向かって今すぐ走り出すよ」「どんなときでもポジティブに」— 決意
- 「**風の行方 変えられるよね**」— 運命を変える意志
- 「**これだけは譲れない！ってコト**」— 譲れないもの
- 「ありがとう 生まれた気持ちに / 巡り逢えた君に / 今から始まる未来すべてに」— 感謝
- 「**Don't be afraid! 走れ / 想い / 届け**」— 締めの三連呼

## Hey!Mommy! 楽曲群での位置づけ

- **BPM 196** はビスケットケース (206) に次ぐ超疾走枠
- Hey!Baby!・SCP!・ビスケットケースと同じ「全力はしゃぎ！」象限だが、**クール値が最も高く**、3調性横断の知的な構成が異彩を放つ
- 「Don't be afraid!」「ReadyReady! HurryHurry!」はライブのセットリスト序盤〜中盤のブースターとして最適
- 歌詞の「走れ」「強くなりたい」テーマは Hey!Baby! の「Dash」「Jump」と対になるが、こちらは**弱さの自覚→克服**というストーリー性を持つ
