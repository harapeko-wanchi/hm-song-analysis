### Intro / Hook（CUNE EVERY DAY PA PA PARTY）
```
Absus4
Dbadd9 → Eb6 → Fm7 → Ab
Dbadd9 → Eb6
Dbadd9 → Eb6 → Ab
```
- **Absus4** で幕開け — sus4 の浮遊感で世界観に引き込む
- **Dbadd9(IVadd9) → Eb6(V6) → Fm7(vi7) → Ab(I)** = IV-V-vi-I に **add9 / 6th / 7th** の装飾を施したドリーミーな循環
- テンションコードだらけの「ファンシーな」響きが 7777777 の世界観を形成
- 「CUNE EVERY DAY PA PA PARTY」「YEAH YEAH WONDER STORY WORLD」
- 「MAYBE LOVE MAYBE LUCK Chu Chu」「CAN DO DO DO」

### Aメロ（アニメ見すぎて フワフワして）
```
Ab → Db → Ab → Db（繰り返し）
（※ Ab → Absus4 の繰り返しでも可）
```
- **I ↔ IV の2コードループ** — 最小限の和声でリズムと歌詞に全振りするミニマルアプローチ
- コードを動かさない分、「アニメ見すぎて フワフワして」「夢見る気分で 踊っても」のフロウが際立つ
- 「世界がドンドンね 何だかいつでも」「カラフルなトキメキだね」

### Bメロ（HEY! LUCKY LUCKY LUCKY）
```
Ab → Db → Ab → Db（同一パターン）
Ab → Db → Ab
```
- I-IV ループ継続。コードは変わらないがボーカルが「HEY! LUCKY LUCKY LUCKY I! WANT YOU WANT YOU」「HEY! CHO CHO CHO CHO CHO WHAT'S UP WHAT'S UP」とエネルギーを上げていく
- ハーモニーを抑えることでコール＆レスポンスのリズム感を最優先

### Cメロ（SUPER SUPERな 可能性とか）
```
Db → Ab → Eb → Fm
Ab → Bbm → Db → Eb
```

- 2コードに抑えていた A/B メロからの解放感が「SUPER SUPERな可能性」の歌詞とシンクロ
- **Bbm (ii)** が唯一のマイナー系ダイアトニック — 「夢中で 無敵で」の一瞬の陰影
- 「SAY ヤホ ハピ GO GO」→ N.C.「ARE YOU READY? YAH YAH YAH プリプリで」

### サビ（ちょっとの言葉と ちょっとの時間で ちょっとのリズムで）
```
Eb（ココから）
Ab → AbM7 → Fm → Fm7
Db → DbM7/C → Bb → Eb
```
- サビの真骨頂は**全音階内声下行ライン**:
  - Ab(root Ab) → AbM7(7th **G**) → Fm(root **F**) → Fm7(7th **Eb**) → Db(root **Db**) → DbM7/C(bass **C**) → Bb(root **Bb**) → Eb
  - **Ab → G → F → Eb → Db → C → Bb** = 完全な全音階下行！
  - コードが変わるたびに内声/ベースが1音ずつ階段を降りる — 美しい構造美
- **Ab → AbM7** = I → IM7。内声で G が加わる微妙な変化
- **Db → DbM7/C** = IV → IVM7/III。ベースが Db → C と半音下行
- **Bb (II major)** = V/V 二次ドミナントで Eb(V) に力強く解決
- 「単純にボクとキミの歌が ナナナ NO.1になる」
- 2回目: 「いつもよりボクのキミが CUTE タタタ 単純でいいよね」

## 楽曲の特徴

### コード面
1. **I-IV (Ab-Db) の2コードループ** — Aメロ・Bメロを支配するミニマルアプローチ。コードを動かさないことでリズムとコールに全振り
2. **Dbadd9→Eb6→Fm7→Ab 装飾循環** — IV-V-vi-I に add9/6th/7th を施したドリーミーなフック。7777777 のサウンドアイデンティティ
3. **サビの全音階内声下行** — Ab→G→F→Eb→Db→C→Bb と完全にスケールを降りる構造美。「ちょっとの言葉と ちょっとの時間で」の反復と完璧にシンクロ
4. **F major (VI)** クロマティックメディアント — ブリッジで一瞬の輝き
5. **Bb (II)** 二次ドミナント — サビの推進力
6. **Cメロでの「和声解放」** — 2コードに抑えた A/B メロから一気にフルダイアトニックに展開する設計

### リズム・サウンド面
- **145 BPM** の打ち込み系 — HeyBaby!(178) や START RUSH!!(196) より落ち着いているが、グルーヴィーなビート
- 「ブギウギだよね」のセリフ通り、跳ねるリズムパターンが Aメロの2コードループ上で効く
- テンションコード多用（add9, 6th, M7, 9th）がファンシーで浮遊する音響を形成

### 歌詞面
- 「**CUNE EVERY DAY PA PA PARTY**」— 造語 "CUNE" が意味不明だからこそキャッチー（cute + tune? clone?）
- 「**YEAH YEAH WONDER STORY WORLD**」— ワンダーランド的世界観
- 「**MAYBE LOVE MAYBE LUCK Chu Chu**」「**CAN DO DO DO**」— タイトルの「7」のリピートと呼応する反復の美学
- 「**アニメ見すぎて フワフワして**」— サブカル的な等身大
- 「**世界がドンドンね 何だかいつでも カラフルなトキメキ**」— 日常の多幸感
- 「**これってブギウギだよね**」— メタ的な自己言及
- 「**ちょっとの言葉と ちょっとの時間で ちょっとのリズムで / 単純にボクとキミの歌がナナナ NO.1になる**」— 曲のコアメッセージ。シンプルでいいんだという肯定
- 「**CUTE タタタ 単純でいいよね**」— ミニマリズムの肯定
- 「**SUPER SUPERな可能性とか ここで描く未来とか / 夢中で無敵で**」— 多幸感の爆発
- 「**LET'S PARTY**」「**DANCING DANCING**」「**ARE YOU READY?**」— パーティーコール三連打

## Hey!Mommy! 楽曲群での位置づけ

- **1st MV** として選ばれた名刺代わりの一曲。「CUNE EVERY DAY PA PA PARTY」のフレーズがグループの世界観を象徴
- **Map B で childlike 5.0** はグループ内**最高値**。CANDY POP (4.5)、Voyage! (4.5) を上回る「最も子供心がある曲」
- **Map A (-2.5, 3.5)** は CANDY POP (-3.0, 3.0) のすぐ近くに配置。「かわいい×超ポップ」ゾーンの双璧
- **I-IV の2コードループ**は BOOOOOOON の3コードループ、MAGNET の F#m ワンコードと共通する**ミニマルアプローチ**。NNBS. の得意技
- **サビの全音階内声下行** (Ab→G→F→Eb→Db→C→Bb) は、恋するとちゅうの Db→DbM7→Db7 内声下行を大規模化したような構造。NNBS. がクロマティックな内声の動きを好む証拠
- 「**単純でいいよね**」「**ちょっとの○○で NO.1になる**」というメッセージは、複雑なコード構成を使いつつ「シンプルが最高」と歌う**自己矛盾的な面白さ**がある
- 「DANCING DANCING」「LET'S PARTY」「ARE YOU READY?」のコールポイントの多さは CANDY POP、Hey!Baby! と並んで**ライブ盛り上がり最高クラス**
