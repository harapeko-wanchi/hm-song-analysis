# 7777777 — 楽曲分析

Hey!Mommy! の 1st ミュージック・ビデオに選ばれた、名刺代わりの一曲である。Aメロと Bメロは Ab と Db の 2 コードだけで押し切り、和音の数を絞った分を add9 や 6th のきらびやかな装飾と、サビで 1 音ずつ階段を降りる内声の動きに注ぎ込む。複雑さのスコアはカタログ最低の 0.1。それでいて耳に残る響きは驚くほどファンシーだ。

## 2 コードに絞り、リズムと言葉に全振りする

Aメロと Bメロを支配するのは、Ab→Db、**I↔IV の 2 コードループ**である。和音を動かさない分、聴き手の耳は「アニメ見すぎて フワフワして」と転がる言葉のフロウと、跳ねるビートに向かう。2 番の Aメロで歌われる「これってブギウギだよね」は、まさにこのループの上で跳ねるリズムを自分で言い当てたような一節だ。

Bメロでもコードは変わらない。それでもボーカルは「HEY! LUCKY LUCKY LUCKY」「CHO CHO CHO」とエネルギーを上げていく。和声を抑えることで、コール＆レスポンスのリズム感を最優先している。

この禁欲があるから、Cメロで和声が開く瞬間が効く。

```
Db → Ab → Eb → Fm      「SUPER SUPERな…」
Ab → Bbm → Db → Eb     「夢中で 無敵で…」
N.C.                   「ARE YOU READY?…」
```

IV→I→V→vi、そして I→ii→IV→V。2 コードに閉じ込められていた A・B メロから、一気にダイアトニックの和音が広がる。その解放感が「SUPER SUPERな可能性」という歌詞と重なる。ii の Bbm がここで初めて顔を出し、「夢中で 無敵で」に一瞬の陰影を落とす。

## サビで 1 音ずつ降りる、全音階の下行ライン

この曲の構造美がいちばん表れるのはサビだ。

```
Eb                           （ココから）
Ab → AbM7 → Fm → Fm7         「ちょっとの言葉と…」
Db → DbM7/C → Bb → Eb        「単純にボクとキミの歌が…」
```

和音が変わるたびに、根音か 7 度かベースのどれか 1 音が、Ab→G→F→Eb→Db→C→Bb と音階を一段ずつ降りていく。Ab から AbM7 で G が加わり、Fm の根音 F、Fm7 の 7 度 Eb、Db の根音、DbM7/C のベース C、Bb の根音と続く。**和声の中に、完全な全音階の下行が隠されている**のだ。「ちょっとの言葉と ちょっとの時間で ちょっとのリズムで」と小さな単位を重ねていく歌詞と、1 音ずつの下降がきれいに重なる。

締めの Bb は、Ab major のダイアトニックなら Bbm になるところを長三和音にした II、つまり V への二次ドミナント（V/V）である。ここで Eb（V）へ力強く押し出され、次の周回へつながる。

## add9 と 6th が作るファンシーな循環

Intro と Hook で鳴る Dbadd9→Eb6→Fm7→Ab は、IV-V-vi-I という定番の循環に add9、6th、7th の装飾を施したものだ。

```
Absus4
Dbadd9 → Eb6 → Fm7 → Ab      「CUNE EVERY DAY PA PA PARTY」
Dbadd9 → Eb6                 「YEAH YEAH WONDER STORY WORLD」
Dbadd9 → Eb6 → Ab            「CAN DO DO DO」
```

冒頭の Absus4 は 3 度を 4 度に吊り上げた和音で、長調とも短調ともつかない浮遊感で世界観へ引き込む。続く循環はテンション（基本の三和音に足された彩りの音）だらけで、どの和音もどこか甘くきらめいている。7777777 のサウンドを決定づけているのは、進行そのものではなくこの響きだ。進行は単純なまま、装飾だけでファンシーな世界を立ち上げる。複雑さ 0.1 という数字と、耳に残るきらびやかさが両立する理由はそこにある。

## 楽曲を追う

### Intro / Hook（CUNE EVERY DAY PA PA PARTY）

前述の Absus4 と Dbadd9→Eb6→Fm7→Ab。「CUNE」という意味の定まらない造語が、意味が分からないからこそ耳に引っかかる。「MAYBE LOVE MAYBE LUCK」「CAN DO DO DO」と、タイトルの「7」の連打に呼応するような反復が続く。

### Aメロ（アニメ見すぎて フワフワして）

```
Ab → Db → Ab → Db    （繰り返し）「アニメ見すぎて…」「世界がドンドンね…」
```

I↔IV のループ。Ab→Absus4 の繰り返しとしても聴ける。

### Bメロ（HEY! LUCKY LUCKY LUCKY）

```
Ab → Db → Ab → Db    「HEY! LUCKY LUCKY LUCKY…」
Ab → Db → Ab         「HEY! CHO CHO CHO…」
```

I-IV のループを継続し、ボーカルのエネルギーだけを上げていく。

### Cメロ（SUPER SUPERな 可能性とか）

前述の IV-I-V-vi と I-ii-IV-V で和声が開き、「SAY ヤホ ハピ GO GO」を経てノーコードの「ARE YOU READY?」へなだれ込む。

### サビ（ちょっとの言葉と ちょっとの時間で）

前述の全音階下行。2 回目は「CUTE タタタ 単純でいいよね」と歌われる。

### ブリッジ（SAY HELLO SAY HELLO）

```
Db → Eb               「SAY HELLO…」
Ab → F                「PARTY PARTY GOOD WAKE UP BOO」
Bbm → Db → Eb         「これからも HEY! READY?…」
```

ここで鳴る F は、ダイアトニックなら Fm になる vi を長三和音に変えた VI である。トニックの Ab と短 3 度離れた長三和音、いわゆるクロマティック・メディアントで、3 度の A♮ が半音上がった分だけ、一瞬キラッと異質な光が走る。続く Bbm へ向かう二次ドミナントとしても働く。その F が「BOO」の一言に当てられているあたりに、遊び心がのぞく。

### 間奏（ナナナ LET'S PARTY）

```
Db → Eb6 → Fm → Ab9    （×4）「ナナナ LET'S PARTY…」「DANCING DANCING…」
```

IV-V-vi-I のバリエーション。Eb6 と Ab9 のテンションが Intro の装飾と呼応する。4 回の繰り返しは、曲で最大のコール＆レスポンスのゾーンだ。

### 2 番

Aメロ、Bメロ、Cメロ、サビ、ブリッジとも 1 番と同じ進行。歌詞だけが「誰よりも 鏡みて」「LOVE YOU LOVE YOUな関係とか」と入れ替わる。

### アウトロ（ナナナナナ ナナ）

```
Dbadd9 → Eb6 → Fm7 → Ab
Dbadd9 → Eb6 → Fm7 → Ab7
Dbadd9 → Eb6 → Dbadd9 → Eb6
Ab
Dbadd9 → Eb6 → Ab
```

Intro の装飾循環に戻り、「CUNE」「WONDER STORY WORLD」「CAN DO DO DO」と冒頭と同じ言葉を回収して円環を閉じる。一度だけ現れる Ab7 は、トニックに 7 度を足して IV への二次ドミナント（V7/IV）に変えたもので、パーティーが終わらない感覚を残す。最後は Ab で明るく着地する。

## カタログの中で

複雑さ 0.1 はカタログ 36 曲の最低値で、7777777 は「最もシンプルな Hey!Mommy!」といえる。子供心 8.2 はもちぷる、GALAXY! GALAXY! に次ぐ 3 番目、バンド 1.2 はもちぷるに次いで 2 番目に低く、打ち込みのキラキラ感と子供心で振り切ったパーティーソングだ。BPM 145 は Hey!Baby!（178）や START RUSH!!（196）より落ち着いているが、跳ねるビートでグルーヴを作っている。

和音を絞るミニマルな手法は、NNBS. の BOOOOOOON の 3 コードループにも通じる。また、サビの全音階下行は、恋するとちゅうの Db→DbM7→Db7 という内声の半音下行を、全音階の規模に広げたような構造で、NNBS. が内声の動きを好む作家であることをうかがわせる。アウトロに一度だけ置かれた I7（Ab7）も、後の GALAXY! GALAXY! や PLAYFUL ROMANTIC で NNBS. の署名となっていく和音だ。

## 総評

「ちょっとの○○で NO.1になる」「単純でいいよね」と歌いながら、その裏で全音階の下行や二次ドミナントをきっちり仕込んでいる。シンプルが最高だと歌う曲が、実は細部まで作り込まれている。その自己矛盾めいた面白さこそが、7777777 の魅力だろう。2 コードの禁欲と、装飾和音のきらめき。その振れ幅で、1st MV にふさわしい Hey!Mommy! の世界観を一曲で描き切っている。
