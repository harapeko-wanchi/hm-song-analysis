# MAGNET — 楽曲分析

クール 9.9、カタログで最も格好いい曲は、Verse を F#m のワンコードだけで押し切る。AILI のカタログへの初登場作は、動かない和音で闘志を張りつめさせ、サビで D と A の明るい響きへ一気に開く。マイナーの緊張とメジャーの開放、その落差を「磁石」のように引き合わせた一曲である。

## 基本情報

| 項目 | 値 |

| リリース | 2022-02-25 |

## F#m ワンコードの Verse が張りつめさせる闘志

Verse は 1 番も 2 番も、8 フレーズずつ F#m の和音一つだけで歌われる。

```
F#m    「変わりばえしない！…」
F#m    「何もかもが同じ感じ…」
F#m    「ミニスカート履いて…」
F#m    「夢だけ見てたって…」
（以下 8 フレーズすべて F#m）
```

合わせて 16 フレーズ、和音は一度も動かない。和声の変化に頼らないぶん、リズムと言葉の切れ味がむき出しになり、ミニマルな緊張感が生まれる。アイドルソングとしては珍しい大胆な構成だ。

その緊張の上で歌われるのは闘いの言葉である。「ここはいつもバトルフィールド」と舞台を戦場に見立て、「気合なんてものはすでに あって当たり前の世界」と言い放ち、「やり切るしかない（Do it!）」と自らを追い込む。各ブロックの終わりには「夢だけ見てたって」のリフレインが置かれ、「何も掴めない！」「何も語れない」「誰も気づかない！」「誰も叶わない！」と言い換えながら 4 回繰り返される。**動かない和音が、そのまま揺るがない決意の音になっている**。

## マイナーの曲が、サビで明るく開く

Key は F# minor だが、サビの中心にあるのは D（VI）と A（III）の明るい長三和音だ。

```
D → A → F#m7 → A/C# → A    「あなたがいて…」
D → A → F#m7 → A/C# → A    「飛んでいける…」
D → A                      「Hey Hey はしゃいでいこう」
F#m7 → A → D               「Hey Hey どんな明日にしよう」
A → F#m7 → Aadd9 → A       「あなたとなら…」
```

VI→III と明るく鳴らしてから、i7 の F#m7 に着地する。続く A/C# はベースに C#、F#m の属音を置いた A で、ベースの動きが F#m の重心を感じさせたまま A へ戻る。ワンコードの Verse で張りつめた暗さが、ここで一気に解放される。暗から明へのコントラストが、この曲の構造の要だ。

「磁石みたいに 引き寄せ合う」という歌詞は、メンバー同士の、そしてファンとの絆を指していると読める。マイナーの調の中にメジャーの和音が引き寄せられるサビの作りは、その比喩の和声版といえる。

## 楽曲を追う

### Intro

```
F#m    「Hey M.O.M.M.Y」…
```

F#m の上で、グループ名を一文字ずつスペルアウトする。アイデンティティの宣言から曲が始まる。

### Verse 1（変わりばえしない！）

前述の F#m のワンコードが 8 フレーズ続く。

### プレサビ 1（Only one）

```
F#m → E    「Only one…」
A → D      「We're the one…」
F#m → E    「言葉だけじゃ…」
A → D      「I need you x I need you…」
D → E      「U Rea dy？？」
```

F# minor のナチュラルマイナーの中で、i→VII→III→VI と進む。ベースは F#→E と一歩下がってから、E→A、A→D と 4 度ずつ上へ跳ね、サビへの期待を積み上げる。最後は D→E（VI→VII）でサビ頭の D の手前まで引き絞る。「I need you」の繰り返しは、一方通行ではなく互いを必要とする関係を描いている。

### サビ 1（あなたがいて ワタシがいる）

前述の VI→III→i7 の開放。

### Verse 2（言うのは簡単）

1 番と同じく F#m の 8 フレーズ。「Make fun」と楽しむ姿勢を掲げつつ、「高望みする前に 身だしなみフル装備」「ポニーテール キツく結ぶ」と、自分を鍛え上げる言葉が並ぶ。

### プレサビ 2（Day & Day）

```
F#m → E    「Day & Day…」
A → E      「No more cry…」
F#m → E    「代わりなんて…」
A → D      「I need you x I need you…」
D → E      「U Rea dy？？」
```

2 行目だけが変わる。1 番の A→D が、ここでは A→E になる。VII の E に進むことで、より明るい解決感が生まれる。歌詞も「No more cry 見つけてくれたから」と、見つけてもらえた喜びに変わっている。

### サビ 2

1 番と同じ進行。

### 間奏

```
A    「ヘイマミー！」
```

### ブリッジ（終わりのない 夢を見てる）

```
D → A → F#m7 → A/C# → A    「終わりのない…」
D → A → F#m7 → A/C# → A    「そばにいてね…」
D → A                      「Hey Hey 目を合わせて」
F#m7 → A → D               「Hey Hey 連れて行って…」
A → F#m7 → Aadd9 → A       「あなたとなら…」
```

サビと同じ進行の上で、落ちサビのように歌われる。「そばにいてね」「連れて行って欲しいの」と、ファンに向けた想いがいちばん素直に表れる場所だ。

### ラストサビ

```
D → Aadd9 → F#m7 → Aadd9/C# → A    「あなたがいて…」
D → Aadd9 → F#m7 → Aadd9/C# → A    「飛んでいける…」
D → Aadd9                          「Hey Hey はしゃいでいこう」
F#m7 → Aadd9 → Bm7/D               「Hey Hey どんな明日にしよう」
Aadd9 → F#m7 → Aadd9 → A           「あなたとなら…」
```

最後のサビでは、A が Aadd9 に、A/C# が Aadd9/C# に置き換わる。9 度の B が加わることで響きが開き、壮大な広がりが生まれる。

そして一か所だけ、新しい和音が現れる。「どんな明日にしよう」の Bm7/D だ。F# minor の iv7 を、VI の D をベースにして鳴らしたもので、曲中で唯一のサブドミナントマイナーの色になる。それまでの D-A の明るさに陰影が差し、未来がまだ決まっていない不確かさを感じさせる。最後の最後に新しい色を一つだけ足して、曲は閉じる。

## カタログの中で

MAGNET は AILI がカタログに提供した 5 曲の最初の作品だ。のちの Voyage!、ご機嫌マミーはご機嫌ガール、OK が多彩な和音と仕掛けで勝負していくのに対し、本作は和音の数を絞り、構成のコントラストで聴かせる。和音を削ぎ落として感情を露わにする姿勢は、のちの Next Story にも通じるものがある。ただし聴かせる方向は対照的で、Next Story がエモ 9.9 に振り切った内省の曲なら、MAGNET はクール 9.9 の尖った格好良さで聴かせる曲だ。

クール 9.9 はカタログの最高値で、Map A でも x 座標 +8.1 と、最もかっこいい側に位置する。エモ 8.2 も Next Story、SUMI-HAJI に次ぐ 3 番目の高さだ。一方でキュート、お祭り感、ハッピーはいずれも 1.8 にとどまる。明るさを基調とするこのカタログの中で、グループの「攻め」の側面を最も鋭く象徴する一曲といえる。

和音を動かさない Verse という手法は、のちに CANDY POP の B のワンコードの Aメロや、7777777 の I↔IV の 2 コードのループにも見られる。和音を絞ってリズムと言葉に集中させる、同じ系譜のミニマルなアプローチだ。

## 総評

16 フレーズ動かない F#m で闘志を張りつめさせ、サビで D と A へ一気に開き、最後に Aadd9 の広がりと Bm7/D の陰影を足して終わる。少ない材料で最大のコントラストを作り出す設計が、クール 9.9 という数字の正体だろう。かわいさを封印した Hey!Mommy! の、最も格好いい姿がここにある。
