# SUMI-HAJI — 楽曲分析

カタログで最も古い 2021 年 10 月の曲にして、Hey!Mommy! の原点ともいえるのが、山崎あおいのこの F minor の一曲である。シンプルな 4 コードのループで焦燥を刻み、テンションコードの陰影で若さの痛みを描く。「青春のすべて使い切っていこ！」という全力の宣言が、短調の響きの中で鳴らされるところに、この曲の切実さがある。

## 4 コードのループが刻む焦燥

Aメロは Fm→Eb→Bb→C の 4 コードを回し続ける。

```
Fm → Eb → Bb → C      （4 コードのループ）
```

i→♭VII→IV→V。主和音から全音ずつ下りて Bb へ行き、ドミナントの C で主和音へ引き戻す。F minor の自然な音階なら Bbm になるはずの IV が長三和音の Bb になっているため、短調の中に少しだけ明るく開いた響きが混じる。和音は単純で、変化もない。だからこそ、「話題のドラマは早送り」「"あの子"比べつまんない」と、焦りや自意識をまくし立てる言葉が前に出る。同じループを回り続ける和声は、どこにも行けない苛立ちそのものに聴こえる。

イントロとサビは、このループに色を足した形だ。

```
Fm → Ebadd9 → Bb7 → C7 → Fm     「端から端…青春のすべて使い切っていこ！」
```

Eb には 9 度が、Bb と C には 7 度が加わる。骨格は Aメロと同じなのに、add9 の透明感と属七の緊張で、響きがぐっと大人びる。サビの最後は C7 から Fm へきちんと解決し、**「使い切っていこ！」の宣言を短調の主和音で言い切る**。明るい長調に逃げずに、痛みを抱えたまま走り出す決意である。

## テンションコードが描く若さの痛み

この曲の和声のもう一つの顔は、テンションコード（9 度や 11 度、♭9 などを足して響きに陰影をつけた和音）の多用だ。最もはっきり出るのがブリッジである。

```
DbM7 → Cm7 → Fm9 → Bbm → C7(b9) → Fm → F
DbM7 → Cm7 → Fm9 → Bbm7 → C
```

DbM7→Cm7→Fm9 とルートが下っていく進行は、ジャジーで洗練された響きを持つ。♭VI のメジャー 7th から v7 へ、そして 9 度を加えた主和音へ。続く C7(b9) は、ドミナントに ♭9 の D♭ を足した、強い緊張を孕む和音だ。ここで高まった緊張が Fm に解け、さらに F に変わって一瞬だけ明るく開く。2 行目は C で止まり、次へ渡す。

ポストサビの「Give me Give me 覚悟」は C7→Fm7 の短い解決で、「喜怒哀楽ちょうだい」と感情のすべてを欲しがる言葉を、ドミナントから主和音への最短の動きで畳みかける。

## 楽曲を追う

### Intro

```
Fm → Ebadd9 → Bb7 → C7      （×3、最後は C7 を 2 回）
```

サビと同じ色付きのループで幕を開ける。最後に C7 を引き延ばすことで、Aメロへの緊張をためる。

### Aメロ

前述の Fm→Eb→Bb→C のループ。

### プレサビ（語り）

```
Fm 上でフリー
```

和音を Fm 一つに止め、その上で語りやラップのように言葉を放つ。和声が動かない分、言葉の焦燥がむき出しになる。

### ブリッジ

前述の DbM7→Cm7→Fm9 の下行と C7(b9) の緊張。

### サビ（端から端）

前述の Fm→Ebadd9→Bb7→C7→Fm。「隅から隅」まで、青春を使い切る宣言である。

### ポストサビ（Give me Give me 覚悟）

```
C7 → Fm7      「Give me Give me 覚悟」
```

### 間奏

```
Eb(11) → DbM9 → Eb(11)
Fm7 → Eb(11) → DbM9 → Eb(11) → Fm7 → Eb(11) → DbM9
Fm → Db → Eb      （×4）
```

Eb(11) と DbM9、つまり ♭VII と ♭VI のテンションコードが行き来し、浮遊するような響きをつくる。後半は Fm→Db→Eb と、i→♭VI→♭VII の骨組みだけを 4 回繰り返し、2 番以降の展開へつなぐ。

### 2 番〜大サビ〜Outro

2 番も Aメロ、語りのプレサビ、ブリッジと同じ流れをたどり、Fm→Db→Eb の間奏を経てサビ、大サビ、ポストサビへ。「イノチ短し」「人生も始まったばかりでしょ？」と、若さの痛みから覚悟へ向かう言葉が重ねられていく。

## カタログの中で

山崎あおいはカタログに 2 曲を提供している。本作と、その 4 か月後の LOOK!!（2022）だ。BPM は 128 と 125、クールは 7.4 と 7.1 とほぼ同じ位置にありながら、本作が F minor で焦燥と痛みを描くのに対し、LOOK!! は A major で痛みすら武器に変える自信を歌う。同じ作家が書いた、表と裏の 2 曲である。

スコアの上でも、本作はカタログの暗い極に立つ。エモ 8.8 は Next Story（9.9）に次ぐカタログ 2 位で、キュート、ハッピー、子供心、お祭り感はいずれも 1.2 と、Next Story に次いで低い。2025 年 12 月に Next Story が登場するまでは、本作がカタログで最もエモーショナルで、最も明るさから遠い曲だったことになる。クール 7.4 も MAGNET、Hey! get up kids、DIAMOND JET、OK に次ぐ 5 位で、尖った格好良さも併せ持つ。バンド 6.3、BPM 128 というミドルテンポのバンド寄りの立ち位置は、DIAMOND JET（BPM 149、バンド 7.4）に近い。

## 総評

単純な 4 コードのループに焦燥を閉じ込め、テンションコードの陰影で若さの痛みに奥行きを与える。そして「青春のすべて使い切っていこ！」という最も前向きな言葉を、あえて短調の主和音で言い切る。明るさを基調とするこのカタログの、いちばん最初の曲が、いちばん暗い場所から始まっていた。そのことが、Hey!Mommy! という表現の幅の広さを物語っている。
