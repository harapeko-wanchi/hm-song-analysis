## 構成とコード進行

### Intro
```
| Db  Db7 | Gb  Gbm |
| ----- -|---- ----| ---- --- -|----- ----|

| Db  Db7 | Gb  Fm7 | Ebm7  Db7/B | Badd9 |
| ----- -|---- ----| --- --- --|- --- --- -|
```
- **Db → Db7 → Gb**: I → I7 → IV。Db7 は V7/IV として機能し Gb へ解決
- **Gb → Gbm**: IV → iv — 同主調（Db minor）から借用した iv が明→暗の色彩変化を作る
- 後半フレーズのベースライン: **Gb → F → Eb → Cb(B)** — IV → iii → ii → ♭VII の順次下行
- **Db7/B → Badd9**: I7第3転回（Cb低音）から♭VIIadd9へ — 低音ペダル Cb=B を保持したまま上声部だけが転換する滑らかなボイスリーディング

### Refrain A（飛び出して）
```
| Db  Db7 | Gb     | Gbm    |
  飛び出して  驚いて    散らかして  キラめいて

| Db  Db7 | Gb  Fm7 | Ebm7  B | Db   |
  泣いたって  Night and day 走(は し) り抜 けて け
```
- Intro と同一の和声骨格を歌メロで再現
- **Gb → Fm7 → Ebm7 → B → Db**: IV → iii7 → ii7 → ♭VII → I の下行ウォーク
- ♭VII（B）は Db（I）への "裏口解決" — V（Ab）を経由しないプラガル系終止

### Verse（いつも味気ない / 空気は読む）
```
| Db  Db7 | Gb     | Gbm    |  ← iv 終止
  いつも味気な いルーティーン 可能性し かない日々 どこ？

| Db  Db7 | Gb     | B7     |  ← ♭VII7 終止
  山積みのや りたいこと リストにして やっつけてやろ

| Db  Db7 | Gb     | Gbm    |
| Db  Db7 | Gb     | B7     |
```
- 4行で1セット — **iv（Gbm）** と **♭VII7（B7）** が交互に終止
- Gbm 終止 = 柔らかい陰り（同主調借用の iv）
- B7 終止 = 強い前傾姿勢（♭VII7 → 次小節の I に解決を促す）
- この **iv ↔ ♭VII7 の交替**がヴァース全体の push & pull を生む

### Chorus A（優しくなれない日は / 眠れない真夜中）
```
| Bbm    | Gb     | Db     | Ab     |
  優しくな  れない日は  私が私（わ  たし）に告げる

| Bbm    | Gb     | Db     | Ab     |
  今日もよく  がんばりました 十分すぎ  るほど上出来

| Bbm    | Gb     | Db     | Ab     |
  土砂降り  のこの空も  あっという  間に晴れる

| Bbm    | Gb     | Db     |
  立ち止  まってる場合（ばあ い）じゃない

N.C.
  オーケー
```
- **vi → IV → I → V（Bbm → Gb → Db → Ab）** — 現代ポップ定番の循環進行
- 4小節 × 3回 + 3小節（V省略）で最終行を短縮 → **N.C.「オーケー」** へ劇的に落とす
- vi スタートが歌詞の内省的トーン（「優しくなれない日」「眠れない真夜中」）と一致
- Ab（V）が次の Chorus B の Db（I）へ完全終止で接続

### Chorus B / Hook（パパパパパ〜んって）
```
| Db  Db7 | Gb     | Gbm    |
  パパパパパ〜んって 飛び出して ほら やっぱりね だから 言ったでしょ

| Db  Db7 | Gb     | B7     |
  予想通りっ ていうか キモチ に素直になっ ただけ

| Db  Db7 | Gb     | Gbm    |
  パパパパパ〜んって 飛び出して 声 大にして 己 を称えよ

| Db  Db7 | Gb  Fm7 | Ebm7  B | Db   |
  これでイイの だ！っていうか自分 を褒め 称 えて あげるん だ
```
- ヴァースと同一の iv ↔ ♭VII7 交替を踏襲しつつ、最終行で下行ウォークを挿入
- **IV → iii7 → ii7 → ♭VII → I**: Refrain A と同じカデンツで曲全体を統一
- 「パパパパパ〜ん」「己を称えよ」「自分を褒め称えてあげるんだ」— 自己肯定の絶頂

### Interlude（ルルララルル）
```
| Db  Db7 | Gb  Gbm | Db  Db7 | Gb  Ab |
  ----- -|ルルララルル ラ ご機嫌でい け やりたいように やればいい い

N.C.
  オーケー
```
- 前半は通常パターン（I–I7–IV–iv）、後半で **Ab（V）** に着地 — 曲中唯一の V 終止行
- 「ご機嫌でいけ　やりたいようにやればいい」— 曲のテーゼを最もストレートに語るブリッジ

### Final Hook
```
| Db  Db7 | Gb  Fm7 | Ebm7  BM7 | Db   |
  これでイイの だ！っていうか自分 を褒め 称 えて あげるん だ
```
- 最終リピートのみ **B → BM7** に差し替え
- ♭VII → ♭VIIM7 の変化 = 長7度（A#=Bb）が加わり、解決直前に柔らかな光が射す
- **BM7 → Db（♭VIIM7 → I）**: 半音進行 A#→Bb(= A#) と D#→Db の交差で滑らかに着地

## 特徴分析

### 1. I7 の恒常ドミナント化
Db7（I7）は本来トニックだが、Gb（IV）への二次ドミナント（V7/IV）として全セクション冒頭に配置される。「常にトニックが IV を呼び、IV がさらに iv か ♭VII7 に変容する」— この連鎖がご機嫌マミーの和声エンジンそのもの。

### 2. IV → iv 同主調借用（Gb → Gbm）
明るい Gb が Gbm に暗転するのは、ハリウッド映画音楽でも多用される古典テクニック。本曲ではヴァースの奇数行（内省パート）に iv を、偶数行（前進パート）に ♭VII7 を配し、**明暗のオシレーション**を作り出す。

### 3. ♭VII 多面体（B / B7 / Badd9 / BM7）
♭VII（B = Cb）が曲中4つの姿で登場する：
| 形態 | 使用箇所 | 機能 |
|------|----------|------|
| B（トライアド） | Refrain A, Hook 下行 | ♭VII → I プラガル系解決 |
| B7 | ヴァース偶数行 | ♭VII7 — 前傾ドミナント |
| Badd9 | Intro 末尾 | ♭VIIadd9 — 浮遊感 |
| BM7 | 最終 Hook のみ | ♭VIIM7 — 柔化終止 |

同一度数がこれほど多彩に変容するのは AILI 作品でも珍しい。♭VII を "一枚岩" でなく **可変レンズ** として扱うアプローチ。

### 4. vi-IV-I-V 循環の配置設計
Chorus A（vi-IV-I-V）は自己肯定の "語りかけ" パート。vi スタートの沈み込みから I-V で持ち上げ、N.C.「オーケー」で一瞬の静寂を作り、Chorus B（I-I7-IV-iv/♭VII7）の爆発へ繋ぐ。**静→動→静→爆発**の波状設計。

### 5. 下行ウォーク IV → iii → ii → ♭VII → I
Gb → Fm7 → Ebm7 → B → Db のステップワイズ下行は Intro・Refrain A・Hook 共通のカデンツ。ダイアトニック音階を IV から順に降りて ♭VII（Mixolydian 借用）に着地し I へ解決する — トニックへの帰還を "下り坂" の勢いで実現する。

### 6. N.C. ブレイク ×3
「オーケー」の一言だけを N.C.（無伴奏）で叫ぶ構造が3回登場。音楽理論的には「フェルマータ付きの構造的休止」。歌詞上は自己肯定の合言葉を最大限に際立たせる演出。

## AILI 作品比較

| | Voyage! | ご機嫌マミー |
|---|---------|-------------|
| Key | B major | Db major |
| BPM | 170 | 182 |
| コーラス進行 | IV-vi-V-I | vi-IV-I-V |
| ♭VII 使用 | A/Bb 借用 | B/B7/Badd9/BM7 四面体 |
| 転調 | B→C 半音上 | なし（単一 Key） |
| 特殊和音 | Bsus4M7 浮遊感 | Db7(V7/IV) 恒常ドミナント化 |
| I7 使用 | なし | 全セクション冒頭 |
| テーマ | 冒険・航海 | 自己肯定 |

**共通点**: ♭VII を主要色彩和音として使う / エレクトロポップ基調 / コール映え設計 / 高 BPM ドライブ

**相違点**: Voyage! が外向き冒険ならご機嫌マミーは内向き自己受容。和声的には Voyage! が転調で盛り上げ、ご機嫌マミーは ♭VII の変容と N.C. ブレイクで盛り上げる。I7 の恒常的使用はご機嫌マミー独自の特徴。
