# ご機嫌マミーはご機嫌ガール — 楽曲分析

「己を称えよ」と歌う AILI の自己肯定エレクトロポップは、トニックをいきなりドミナントに変えてしまう I7 を和声のエンジンにしている。IV が明るくも暗くも転び、♭VII が四つの姿で現れ、要所では伴奏がすべて止まって「オーケー」の一言だけが残る。仕掛けの多さを、ご機嫌な勢いとして聴かせる一曲だ。

## トニックが休まない — I7 が回す和声のエンジン

ほぼすべてのセクションは Db→Db7→Gb、つまり I→I7→IV で始まる。Db7 は本来ならトニックの Db に 7 度の Cb を足しただけの和音だが、この 7 度によって Gb（IV）への二次ドミナント（V7/IV）に変わる。落ち着くはずのトニックが、鳴った瞬間に次の IV を呼び込んでしまうのだ。

**トニックが常に IV を呼び、IV がさらに別の姿へ変わる**。この連鎖がこの曲の和声のエンジンで、Intro から最後のフックまで止まらない。BPM 182 の速さとあいまって、曲全体が休むことなく前へ転がっていく。

## 明と暗の振り子 — Gb と Gbm、そして B7

IV の Gb は、そのまま Gbm（iv）に暗転することがある。同主調の Db minor から借りた和音で、映画音楽でも多用される古典的な技法だ。長 3 度が半音下がるだけで、明るい響きにふっと陰が差す。

```
Db → Db7 → Gb → Gbm    「いつも味気ない…」
Db → Db7 → Gb → B7     「山積みの…」
Db → Db7 → Gb → Gbm
Db → Db7 → Gb → B7
```

Verse では、奇数行が Gbm（iv）で、偶数行が B7（♭VII7）で終わる。Gbm の終止は柔らかい陰り、B7 の終止は次の小節の I へ向かって前のめりになる強い推進力を持つ。内省と前進が 1 行ごとに入れ替わり、この振り子が Verse 全体の押し引きを作っている。

## ♭VII の四つの姿

この曲では、♭VII にあたる B（＝Cb）が四つの形で現れる。

- **B**（三和音）: Refrain とフックの下行ウォークの終点。V を経ずに I へ戻る
- **B7**: Verse の偶数行。前のめりの終止
- **Badd9**: Intro の末尾。9 度を足した浮遊感
- **BM7**: 最後のフックだけ。長 7 度を足した柔らかな終止

同じ度数の和音を一つの役割に固定せず、場面ごとに色を変えるレンズのように使っている。AILI の作品の中でも、一つの度数をここまで多彩に変化させた例は珍しい。

## 楽曲を追う

### Intro

```
| Db  Db7 | Gb  Gbm |
| Db  Db7 | Gb  Fm7 | Ebm7  Db7/B | Badd9 |
```

前半は前述の I→I7→IV→iv。後半はベースが Gb→F→Eb→Cb（B）と順次下行し、IV→iii→ii→♭VII と降りていく。最後の Db7/B は Db7 の 7 度 Cb をベースに置いた第 3 転回形で、そのベースを保ったまま上声だけが Badd9 へ移る。低音を動かさずに和音を差し替える、滑らかな声部の運びだ。

### Refrain（飛び出して）

```
Db → Db7 → Gb → Gbm             「飛び出して…」
Db → Db7 → Gb → Fm7 → Ebm7 → B → Db    「泣いたって…」
```

Intro と同じ骨格を歌で再現する。2 行目の Gb→Fm7→Ebm7→B→Db は IV→iii7→ii7→♭VII→I の下行ウォークだ。ダイアトニックの音階を IV から一段ずつ降り、ミクソリディアンから借りた ♭VII を経て I に戻る。V（Ab）を通らない裏口からの解決で、トニックへの帰還を下り坂の勢いで果たす。このカデンツは Intro、Refrain、フックに共通していて、曲全体を一つにまとめている。

### Verse（いつも味気ない）

前述の iv と ♭VII7 の交替。4 行で 1 セットになる。

### サビ A（優しくなれない日は）

```
Bbm → Gb → Db → Ab    「優しくなれない日は…」
Bbm → Gb → Db → Ab    「今日もよく…」
Bbm → Gb → Db → Ab    「土砂降りの…」
Bbm → Gb → Db         「立ち止まってる場合じゃない」
N.C.                  「オーケー」
```

ここだけは I7 のエンジンを止め、vi→IV→I→V の現代ポップの定番循環を回す。vi から始まる沈み込みが、「優しくなれない日」という内省的な歌詞に合っている。4 小節を 3 回回したあと、最後の行は V を省いた 3 小節に縮められ、無伴奏の「オーケー」へ一気に落ちる。

### サビ B／フック（パパパパパ〜んって）

```
Db → Db7 → Gb → Gbm                    「パパパパパ〜んって…」
Db → Db7 → Gb → B7                     「予想通りっていうか…」
Db → Db7 → Gb → Gbm                    「パパパパパ〜んって…」
Db → Db7 → Gb → Fm7 → Ebm7 → B → Db    「これでイイのだ！…」
```

Verse と同じ iv と ♭VII7 の交替を踏み、最終行で Refrain と同じ下行ウォークに入る。「己を称えよ」「自分を褒め称えてあげるんだ」と、自己肯定が頂点に達する場所だ。サビ A の vi 始まりで沈み、I-V で持ち上げ、N.C. の静寂を挟んでからこのフックで爆発する。静から動、静、そして爆発へという波の設計である。

### 間奏（ルルララルル）

```
Db → Db7 → Gb → Gbm → Db → Db7 → Gb → Ab    「ルルララルル…」
N.C.                                       「オーケー」
```

前半はいつもの I→I7→IV→iv だが、後半は Ab（V）で終わる。I→I7→IV で始まる行が V に着くのは、ここだけだ。歌われるのは「ご機嫌でいけ」「やりたいようにやればいい」で、曲のテーマを最もまっすぐ語る場所になっている。ここでも最後は無伴奏の「オーケー」が置かれる。

### ラストのフック

```
Db → Db7 → Gb → Fm7 → Ebm7 → BM7 → Db    「これでイイのだ！…」
```

最後の繰り返しだけ、下行ウォーク終点の B が BM7 に差し替えられる。長 7 度の A# が加わり、解決の直前に柔らかな光が射す。♭VIIM7→I という終止で、跳ねるような曲が最後だけふわりと着地する。

## 「オーケー」と、ことわざのパンチライン

伴奏が完全に止まり「オーケー」の一言だけが響く N.C. のブレイクは、曲中に 3 回ある。音楽的にはフェルマータ付きの構造的な休止で、自己肯定の合言葉を最大限に際立たせる演出だ。

歌詞は「パパパパパ〜ん」の擬音、天才バカボンを思わせる「これでイイのだ！」、「笑う門には福」の直接引用、「空気は読むんじゃなくて吸うもの」というひねったパンチラインと、口に出して楽しい言葉で埋め尽くされている。「己を称えよ」という古風な命令形を現代のポップに置くのも、AILI らしい言葉の遊びだ。

## カタログの中で

AILI はカタログに 5 曲を提供していて、本作は MAGNET、Voyage! に続く 3 曲目にあたる。直前の Voyage! と並べると、同じ作家の共通点と相違点が見えてくる。

| | Voyage! | ご機嫌マミーはご機嫌ガール |
|---|---|---|
| Key / BPM | B major / 170 | Db major / 182 |
| サビの進行 | IV-vi-V-I | vi-IV-I-V |
| ♭VII の使い方 | A、Bb（両方の調で借用） | B / B7 / Badd9 / BM7 |
| 転調 | B→C の半音上 | なし |
| 特徴的な和音 | Bsus4M7 の浮遊感 | Db7（V7/IV）の常用 |
| テーマ | 冒険・航海 | 自己肯定 |

どちらも ♭VII を主要な色彩の和音に使い、エレクトロポップを基調に、コールの映える高めの BPM でドライブする。違うのは盛り上げ方で、Voyage! は転調で盛り上げ、本作は ♭VII の変化と N.C. のブレイクで盛り上げる。I7 を常用するのは本作独自の特徴だ。テーマも、Voyage! が外へ向かう冒険なら、本作は内へ向かう自己受容である。

翌年の OK は同じ自己肯定を、かわいさではなく格好良さで描き直した。本作はキュート 5.7、クール 3.9 と可愛げのある側に立ち、9 軸すべてが 3.9〜6.8 に収まるバランス型の曲になっている。

## 総評

I7 が休まずトニックを押し出し、IV が明暗に揺れ、♭VII が姿を変え、最後に BM7 で柔らかく着地する。和声の仕掛けはどれも凝っているが、聴こえてくるのは理屈ではなく「ご機嫌でいけ」という勢いだ。3 度の「オーケー」の沈黙が、その勢いをいっそう際立たせる。仕掛けを総動員して、自分を褒めることの楽しさを鳴らした曲である。
