### Verse（Key: D）
```
| G       A   | Bm      D   |
  この世界（せかい）はきっとそう だ 限界（げんかい）はない
| A           | D       F#  |
  怖がって迷ってる暇はないから 飛 び越えちゃおう
| G       A   | Bm      D   |
  つない だ夢も 一緒 走れ走れ
| A           | B            |
  オモシロければ無敵届くん だ
| C#          |
  GET A KICK KICK
```
- 前半: **IV-V-vi-I** — 王道進行のローテーション（IV スタート）
- **A → D → F#**: V → I → III — F# は V/vi（Bm へのセカンダリードミナント）であり、同時に Key: F# のトニック予告
- **A → B**: V → VI — ダイアトニック vi（Bm）を **B major（VI）** に置換。Picardy 式ブライトニング
- **C#**: D major における VII — 導音上の長三和音。Key: F# の V として機能する **ピボットコード**
- 「GET A KICK KICK」で C# → Key: F# へ飛び込む — C# が蹴り（KICK）の推進力そのもの

```

- **I → I/5 → IV → II → II7 → V** — 3段ロケット構造
  - 第1段: F# → F#/C# (I → I/5) — トニック安定
  - 第2段: B (IV) — サブドミナント高揚
  - 第3段: G# → G#7 → C# (II → II7 → V) — ダブルドミナント → ドミナント解決
- **G#（II = V/V）**: F# key で最も緊張感のある和音 — 「SUPER SUPER SUPER SUPER SUPER」の5連呼に配置
- **G#/F#（G#7）**: II に I のバスペダルを敷く — 低音の安定感と上声部の緊張が同居
- C#（V）が「Hey！CUTE WINK LOVE」「ずっとあそぼう」で解決を宣言

### Chorus B「SUPER MOMMY GIRLS」（Key: F#）
```
          B                |

| A#      D#m         C#  |

          B           C#  |

- **IV → III → vi → V → IV → V → I**

- B → C# → F# = **IV → V → I**: 最もオーソドックスな完全終止で「不可能はない → オモシロイ」を着地

## 特徴分析

### 1. vi7 ↔ vi シャトル（Bm7 ↔ Bm）
Chorus A の全体が vi7 と vi の2音色だけで構成される。NNBS. ミニマリズムの系譜:
| 曲 | ミニマル構造 | コード数 |
|----|-------------|---------|
| 7777777 | I-IV ループ（装飾あり） | 2+装飾 |
| もちぷる | I-IV(サビ) / I-V(ヴァース) | 2 |
| SUPER MOMMY GIRLS | vi7-vi シャトル | 2(vi限定) |

本作の特異性は **vi（マイナー）上でのミニマリズム** — I-IV の明るいミニマルとは正反対の「暗いミニマル」。これが192BPMの高速ビートと組み合わさり、不穏なエネルギーを生む。

### 2. D → F# 長3度上転調
D major から F# major（III）への転調は **長3度上（M3↑）** — クロマティックメディアント関係。共通音は F#（D の III / F# のトニック）と C#（D の VII / F# の V）。

転調プロセス:
1. Verse で F#（III）が V/vi として登場 — 「ここは D の中の III だ」
2. 直後に B（VI）が「D の VI かつ F# の IV」として二重機能を発揮
3. C#（VII = V of F#）が「GET A KICK KICK」で **蹴り出し** — F# key へ着地

**逆転調**: Interlude で Bm に戻ると D key に復帰。Bm = D の vi / F# の iv と解釈可能で、ここでもダブルファンクション。

### 3. C# のピボット機能（VII → V）
C# は D major では **VII**（導音上の長三和音 — ダイアトニック外）、F# major では **V**（属和音 — 最も基本的な和音）。この二面性が転調の鍵:
- D key 内: C# は「ここにいてはいけない感」のする異質な和音
- F# key 内: C# は「帰ってきた」安定のドミナント
- 「GET A KICK KICK」のフレーズが C# の位置に来るのは、まさに「蹴って飛び越える」転調の演出

### 4. G#（II = V/V）のダブルドミナント
F# key での G# は II 度上の長三和音 = V/V（C# への二次ドミナント）。「SUPER SUPER SUPER SUPER SUPER MOMMY」の 5 連呼がこのダブルドミナント上に載る — 二重の緊張が「SUPER」の過剰さとシンクロ。

G#/F#（G#7）はさらに I（F#）のバスペダルを敷いており、低音の安定 × 上声部の不安定 = 「地に足をつけたまま飛ぶ」構造。

### 5. A#（III = V/vi）セカンダリードミナント
Chorus B の「SUPER MOMMY FRIENDS」で A# → D#m（III → vi）。ダイアトニック iii は A#m だが、A# major に変更することで D#m への解決力が増す。「FRIENDS」という仲間のキーワードを vi の切なさに載せ、III が感情を引き上げる。

### 6. B（VI/IV）のダブルファンクション
B は D key では VI（ダイアトニック外の明るい6度）、F# key では IV（サブドミナント）。両 key でピボット和音として機能し、転調の接着剤。NNBS. 作品群で VI（major vi）が頻出するパターン（7777777 の F(VI)、もちぷるの C#(VI)、恋するとちゅうの C(VI)）と連続する署名。

### 7. N.C. + ベース only ブレイク
Cantabile 末尾の「歩いていける」で全楽器停止 → F# ベースのみ。直後の ARE YOU READY? コールセクションも全編 N.C.。192BPMの密度から一瞬ゼロにする「真空」が、再開時の爆発を最大化。

## NNBS. 転調手法比較

| | HELLO!! Hey!! WORLD!! | SUPER MOMMY GIRLS |
|---|----------------------|-------------------|
| 転調 | なし（♭VII借用のみ） | D → F# 長3度上 |
| ピボット | — | C# (VII→V), B (VI→IV) |
| vi の扱い | I-ii-iii-V 上行ウォーク | vi7↔vi シャトル（Chorus A の骨格） |
| 非ダイアトニック | ♭VII(A) | III(F#), VI(B), VII(C#), II(G#), III(A#) |
| ミニマル要素 | NATTO, CHUCHU | Bm7↔Bm 2音色 |

**SUPER MOMMY GIRLS はNNBS.作品中最大の転調スケール** — 長3度上のクロマティックメディアント転調。他の NNBS. 曲が単一 key のミニマリズムで勝負するのに対し、本作は「ミニマル（vi7↔vi）× 転調（D→F#）」の二層構造を持つ。
