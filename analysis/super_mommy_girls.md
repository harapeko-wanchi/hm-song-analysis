# SUPER MOMMY GIRLS — 楽曲分析

ゴッドタンのエンディングに起用された 2nd MV 曲は、Bm7 と Bm の 2 つの音色だけで「ARE YOU READY」を煽るところから始まる。暗いミニマリズムで助走をつけ、「GET A KICK KICK」の一蹴りで D major から長 3 度上の F# major へ飛び込む。その蹴り出しの瞬間がこの曲の聴きどころだ。

## vi の上のミニマリズム — Bm7 と Bm だけの Chorus A

Chorus A は、最初から最後まで Bm7 と Bm しか鳴らない。

```
Bm7 → Bm     「ARE YOU READY EVERYBODY…」
Bm7 → Bm     「SUPER じゃじゃんじゃ…」
Bm7 → Bm     「WHAT'S UP WHAT'S UP…」
Bm7 → Bm     「オモシロイって…」
Bm           「自分越えてやらなきゃ損損」
```

D major の vi7 と vi を往復するだけのシャトルで、変わるのは 7 度の有無だけだ。最小限の和声運動で明暗を揺らす。もちぷるや 7777777 の I-IV に続く NNBS. の「2 音色」の手法だが、決定的に違うのは、それが短調の vi の上で行われていることである。

I-IV のミニマルが明るく安定しているのに対し、こちらは**明るい曲調の底に暗さが沈む「暗いミニマル」**だ。192 の高速ビートと組み合わさると、不穏なエネルギーが生まれ、「SUPER」の爆発力を増幅する。Intro も「バナナン ナナナン ナン」のナンセンスワードを Bm 一発に乗せ、vi の沈み込みと能天気な言葉の対比で緊張感のある幕開けを作っている。

## 「GET A KICK KICK」— 3 つのピボットで長 3 度上へ

D major から F# major への転調は長 3 度上、クロマティックメディアント（同じ長調どうしで 3 度離れた、共通音の少ない遠い調）の関係にある。NNBS. はこの遠い調への移動を、Verse の中で 3 段階に分けて準備する。

まず「飛び越えちゃおう」の F#。D major の III で、Bm（vi）への二次ドミナント（V/vi）として鳴るが、同時に転調先のトニックの予告にもなっている。次に「無敵届くんだ」の B。ダイアトニックなら Bm のところを長三和音にした VI で、D major の VI であり、F# major の IV でもある。最後に「GET A KICK KICK」の C#。D major では導音の上に立つ長三和音（VII）で、そこにいてはいけないような異質な響きを持つが、F# major では最も基本的な V だ。

D major の耳には異物だった C# が、次の瞬間には帰ってきた安定のドミナントに変わる。**「蹴って飛び越える」という言葉が、そのまま転調の推進力になる**。D と F# の共通音は F# と C# で、その C# が蹴り出しの和音に選ばれているのも理にかなっている。

この転調は一度きりではない。Interlude で Bm に戻ると、曲は D major へ帰る。Bm は D major の vi であり、F# major から見ても iv（同主短調から借りた IV）にあたるので、ここでも二重の機能を持つ和音が継ぎ目になる。2 番の Verse で再び同じ 3 つのピボットを踏み、もう一度 F# へ蹴り出す。

## SUPER の 5 連呼を支える G#（V/V）

F# major のフックは、3 段ロケットのように組まれている。

```
F# → F#/C# → B                  「ARE YOU READY？めちゃんこ…」
G# → G#/F#(G#7)                 「SUPER SUPER SUPER SUPER SUPER MOMMY」
C#                              「Hey！ CUTE WINK LOVE」
F# → F#/C# → B                  「GO GO READY GOING MY WAY…」
G# → G#/F#(G#7)                 「どこでもいける…」
C#                              「ずっとあそぼう」
```

第 1 段は F# から F#/C# のトニックの安定、第 2 段は B（IV）のサブドミナントの高揚、第 3 段は G# から G#7 を経て C# へ、ダブルドミナント（V の V）からドミナントへの解決だ。G# は F# major で最も緊張感のある和音で、そこに「SUPER」の 5 連呼が置かれる。二重の緊張が「SUPER」の過剰さとシンクロしている。

G#/F# は、II の和音の下にトニックの F# をベースとして敷いた形だ。低音は安定しているのに上声は張りつめている。地に足をつけたまま飛ぶような構造で、それを C# が「CUTE WINK LOVE」「ずっとあそぼう」で解決へ導く。

## 楽曲を追う

### Intro（バナナン）

```
Bm           「バナナン ナナナン ナン Hey！Hey！」（×2）
```

vi の単一コード。192 の速度と vi の暗さで、緊張感のある幕開けを作る。

### Chorus A（ARE YOU READY）

前述の vi7↔vi シャトル。キーは D major。

### Verse（この世界はきっとそうだ）

```
G → A → Bm → D       「この世界はきっとそうだ…」
A → D → F#           「怖がって迷ってる暇は…」「飛び越えちゃおう」
G → A → Bm → D       「つないだ夢も…」
A → B                「オモシロければ無敵…」
C#                   「GET A KICK KICK」
```

前半は IV-V-vi-I、王道進行を IV から始めるローテーションだ。A→D→F# で V→I→III（V/vi）と進み、A→B では本来 Bm が来るべきところを B major（VI）に置き換えて、ピカルディ終止のように明るく塗り替える。そして C# で F# major へ蹴り出す。

### Hook A（ARE YOU READY?）

前述の I→I/5→IV→II→II7→V の 3 段ロケット。キーは F# major。

### Chorus B（SUPER MOMMY GIRLS）

```
B                    「SUPER MOMMY GIRLS…」
A# → D#m → C#        「SUPER MOMMY FRIENDS…」
B → C#               「SUPER MOMMY GIRLS（不可能はない）」
F#                   「この世界はオモシロイ」
```

IV→III→vi→V→IV→V→I。A# は F# major のダイアトニックなら A#m だが、ここでは長三和音にして D#m（vi）を呼ぶ二次ドミナント（V/vi）にしている。A#→D#m→C# と vi を経由してドミナントへ向かい、「FRIENDS」という仲間の言葉を vi の切なさが彩る。最後は B→C#→F# の最もオーソドックスな完全終止で、「不可能はない」から「オモシロイ」へ着地する。

### Interlude〜Verse 2（自分越えて信じていこう）

```
Bm                   （Interlude）
Bm → G               「自分越えて信じていこう」
A → Bm → D           「この宇宙だときっと…」
A → D → F#           「マジマジ歌って…」
G → A → Bm → D       「言葉と心で…」
A → B                「何万回でも無敵…」
C#                   「GET A KICK KICK」
```

前述のとおり Bm で D major に戻り、Verse 1 と同じ構造で IV-V-vi-I、V-I-III（ピボット）、IV-V-vi-I、V-VI、VII（ピボット）と進む。「何万回でも」の B から C# へ、再び F# major へ蹴り出す。

### Cantabile（ナー ナー ナー）

```
F# → F#/C# → B → B/A# → G# → G#/F# → C#    「ナー ナー ナー バナナー…」
F# → F#/C#           「点とか線とか…」
B                    「バナナナナンでも…」
G# → G#/F#           「明るく ほら…」
C# → N.C.            「デコでボコで…歩いていける」
/F#（ベースのみ）     「ARE YOU READY? WHAT'S UP！」
```

Hook A と同じ和声だが、B/A#（IV の下に A# を敷いた形）が加わり、ベースが F#、C#、B、A#、G#、F# とはっきり降りていく。「バナナナナンでもよく見たら自由」は「バナナ」と「なんでも」の駄洒落で、それを IV の安定した和音に乗せる。そして「歩いていける」の直後に全楽器が止まり、F# のベースだけが残る。決意の言葉を最小の編成で放つ瞬間である。

### Chant（ブレイク）

```
N.C.                 「ARE YOU READY? WHAT'S UP！」「BABY BABY BABY…」「BABY BABY KICK OF NOW」
```

和声を完全に排した、コール＆レスポンス専用の区間。192 のリズムだけが残る。直前のベースのみのブレイクから続く「真空」が、再開したときの爆発を最大化する。

### Final Chorus B

```
B → C#               「SUPER MOMMY GIRLS（不可能はない）」
F#                   「この世界はオモシロ オモシロ オモシロイ」
```

IV→V→I の完全終止に、「オモシロ」の 3 連呼を重ねて着地する。

## カタログの中で

B（VI）のように、短三和音のはずの vi を長三和音にする手は NNBS. 作品に繰り返し現れる。7777777 の F、もちぷるの C#、恋するとちゅうの C（Eb major の VI）がそうで、本作ではそれを転調の接着剤として使った。同じ NNBS. でも、HELLO!! Hey!! WORLD!! が転調なしで I-ii-iii-V の上行ウォークを反復し、♭VII を一点だけ差すのとは対照的に、本作は D major での III・VI・VII、F# major での II・III と、非ダイアトニックの長三和音を 5 種も使う。

それでいて複雑さのスコアは 3.2 にとどまる。使う手は多くても、一つ一つの進行は王道で、聴いて難しさを感じさせないということだろう。クール 6.8、お祭り感 7.4、疾走感 6.8。「暗いミニマル」と長 3 度の転調という二層の設計が、格好良さと盛り上がりを両立させている。のちの POJI POJI GO が E と G のあいだを B7 一つで往復するのに対し、本作は 3 つのピボットを積み上げて遠い調へ渡る。転調そのものを一つの物語として見せる作りである。

## 総評

vi の上で明暗を揺らす 2 音色の助走、3 つのピボットを踏んでの長 3 度の跳躍、SUPER の 5 連呼を支えるダブルドミナント、そして全楽器が止まる真空。どの仕掛けも、「GET A KICK KICK」と蹴って限界を飛び越える歌詞のために置かれている。テレビのエンディングで初めて聴いた人をも一瞬で連れ去る、NNBS. の高速曲の中でも構成の妙が光る一曲だ。
