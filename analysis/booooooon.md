# BOOOOOOON — 楽曲分析

「どんな君だって いいんじゃない」。日常のすべてを肩の力を抜いて肯定するこの曲は、Ab→Eb→Bb のたった 3 コードを軸に回る。それでいて調号は F minor。明るい平行調とのあいだを揺れ動き、プレサビの一瞬だけ Fm が F に化ける。ゆるさの中に仕込まれたその揺らぎが、この曲の聴きどころだ。

## 3 コードの循環と、F minor と Ab major のあいだの揺れ

曲の核は Intro とサビで回る Ab→Eb→Bb のループである。曲はいきなりサビから始まる。

```
Ab → Eb      「どんな君だって いいんじゃない…」
Bb           「一緒にいたいよ…」
Ab → Eb      「明日なんてただの 次の日だ…」
Bb           「変わらなくたって ビューティフルデイだ」
Ab           「Hey! Hey! Hey!」
```

この 3 コードは、見る位置によって意味が変わる。F minor から見れば III→VII→IV、平行調の Ab major から見れば I→V→II だ。サビは Ab から始まり、Fm は一度も鳴らないので、耳には明るい Ab major のポップ循環として届く。たった 3 コードの明快なループで「いいんじゃない」を繰り返すから、中毒性が生まれる。

一方、ヴァースでははっきりと Fm に着地する。

```
Eb → Bb → Fm      「昨日のベットで…」
Ab → Bb → Eb      「寝坊したら…」
Bb → Fm           「やっぱ君と一緒…」
Ab → Bb           「とりあえず 何かはじめよう」
```

VII→IV→i→III→IV→VII。「ふにゃ ふにゃで」の Fm への着地が、脱力した感じをそのまま音にしている。サビは Ab の明るさ、ヴァースは Fm の落ち着き。**短調とその平行調のあいだを行き来する調性の曖昧さ**が、深刻にも能天気にもならない、この曲独特のゆるい温度を作っている。

## プレサビで一瞬だけ差す F major

ゆるい循環の中で、和声がいちばん動くのが「RA PA」のプレサビだ。

```
Eb/G → Ab → Bb/D → Eb     「RA PA 今すぐ…」
Eb/G → Ab                 「飛んでも跳ねても…」
Bb/D → Eb                 「なんだか変でも ブギウギ」
Bb → Cm                   「少しずつ BOOOOOONってなる」
Ab → Eb/G → Fm → F        「声にだすのも…回るのも」
Bb                        「わるくない！」
```

前半は転回形（根音以外の音をベースに置いた和音）が効いている。Eb/G の G から Ab へ、Bb/D の D から Eb へ、ベースはどちらも半音上がって次の和音に滑り込む。

後半で現れるのが、**Fm から F への同主調交替**である。同じ F を根音にした短三和音が、3 度の Ab を A♮ に半音上げて長三和音に変わる。i から I への一瞬の転換で、「メロディーも 回るのも」の一節にぱっと明るさが差し、その勢いのまま Bb の「わるくない！」へ届く。Bb→Cm→Ab→Eb/G→Fm→F→Bb と、Cm や F を挟み込んだこの数小節は、3 コードを基本とするこの曲で最も色彩豊かな部分だ。

## Cm がだんだん居場所を広げていく

この曲には、聴き進めるほどに Cm（F minor の v）が存在感を増していくという設計がある。

冒頭の先出しのサビに Cm はない。2 回目のサビ（Chorus A）では、末尾の「ビューティフルデイだ HEY!」で初めて Cm が加わり、v の着地が次のセクションへの緊張を作る。続く「I DON'T JUST TOO CUTE」のセクション（Chorus B）では、Cm→Ab→Eb→Bb と Cm が循環の先頭に立ち、「Hey! Hey! Hey!」のコールに力を与える。そしてブリッジでは Ab→Eb→Bb→Cm と、Cm を含む 4 コードの循環が丸ごと一つのセクションを支える。

3 コードで始まった曲が、少しずつ 4 つ目の和音を受け入れていく。タイトルの擬音どおり、「少しずつ BOOOOOONってなる」ように、テンションがじわじわ膨らんでいく構造である。

## 楽曲を追う

### Intro

```
Ab → Eb → Bb    （×2）
```

III→VII→IV（Fm から見て）の明るい 3 コードループで始まる。

### サビ（先出し / どんな君だって）

前述の Ab→Eb→Bb。最後は Ab の「Hey! Hey! Hey!」で締める。

### Verse 1（昨日のベットでガーンと悩んだ）

前述の VII→IV→i→III→IV→VII。ベッドで悩んだ大きなことが、寝坊したら小さくなる。日常の些細な出来事を肯定する歌詞が、Fm の落ち着いた着地とともに語られる。

### Pre-chorus（RA PA）

前述の転回形のベースと、Fm→F の同主調交替。

### Chorus A（どんな時だって）

```
Ab → Eb      「どんな時だって…」
Bb           「簡単なことさ…」
Ab → Eb      「明日なんてただの…」
Bb → Cm      「変わらなくたってビューティフルデイだ HEY!」
```

先出しのサビとほぼ同じだが、末尾に Cm が加わる。

### Chorus B（I DON'T JUST TOO CUTE）

```
Ab → Eb      「I DON'T JUST TOO CUTE 跳ねよう…」
Bb → Cm      「ここで全部ブチ上げちゃお！っと」
Ab → Eb      「I DON'T JUST TOO CUTE 揺らそう…」
Bb           「片手あげて…」
Cm → Ab → Eb → Bb    （×2）「Hey! Hey! Hey!」
```

「かわいいだけじゃない」という宣言のセクション。「跳ねよう」「ブチ上げ」「揺らそう」と身体を動かす言葉が続き、最後は v→III→VII→IV の Cm 始まりの循環でコールになる。

### Verse 2（ムム ムっと余裕がなく）

```
Eb → Bb             「ムム ムっと…」
Fm → Ab → Bb        「悲しんでても お腹は 鳴る」
Eb → Bb
Fm → Ab → Bb        「素敵に出会った…」
```

VII→IV→i。1 番以上に Fm への着地がはっきりする。「悲しんでても お腹は 鳴る」という生活の実感が、この曲の日常肯定をよく表している。

### Pre-chorus 2 → Chorus A → Chorus B

1 番と同じ構造。プレサビの歌詞は「凹んでも泣いても ブギウギ」「このままゆくのも変わりゆくのも」と、変わることも変わらないことも同じように肯定する。

### Bridge（まだ辿り着けてない 大きな場所とか）

```
Ab → Eb → Bb → Cm    （×3）「まだ辿り着けてない…」「バラバラなトゲトゲ…」
Ab → Eb → Bb → Cm    「欲張りな 夢を信じて 君と見よう」
```

III→VII→IV→v の循環。歌詞は曲中でいちばん内省的になる。バラバラなトゲトゲも集めれば星になれる、適当な嘘で自分を騙してもそりゃ悲しい。「トゲトゲが星になる」という、痛みを光に変える比喩がここで歌われる。

### Final Chorus A → Final Chorus B〜Outro コール

```
Cm → Ab → Eb → Bb    「Hey! Hey! Hey!」（NA NA NANA… / RA PA PARA PA…）
```

同じ構造のサビの後、「NA NA NANA」「RA PA PARA PA」のコールが重なる。

### Outro（N.C.）

```
N.C.     「どんな君だって いいんじゃない…」「一緒に見たい景色があるんだ」
```

最後はコードを外し、ノーコードのアカペラに近い形で着地する。和音の支えをなくした声が「いいんじゃない」のメッセージを裸で届け、「一緒に見たい景色があるんだ」が余韻として残る。

## カタログの中で

songs.json の調表記で見る限り、NNBS. が作曲した 21 曲のうち短調で書かれているのは本作だけである。カタログ全体でも F minor の曲は、ほかに Tickey Luppy Doo と SUMI-HAJI があるのみだ。ただし本作の短調は、サビを平行調の明るさに預けることで、暗さよりもゆるさを生む方向に使われている。

BPM 140 はカタログ 36 曲中 30 位。リリース時点では NNBS. の作品で最も遅く、現在でも夜空ウィズユー（100）に次いで 2 番目に遅い。疾走感 2.9、バンド 3.2 と、打ち込みで軽く跳ねるグルーヴの曲だ。疾走感を除けばスコアはどの軸も 3〜5 台に収まり、Map A と Map C ではほぼ中央に位置する。

和音を絞るミニマルな手法は、のちの 7777777 の 2 コードループにつながっていく。「ブギウギ」という言葉も 7777777 で再び歌われる。また、曲の締めで和音を消して声だけを残す手法は、HELLO!! Hey!! WORLD!! の「僕らとキミとね」の沈黙にも通じる。

## 総評

3 コードの循環、F minor と Ab major のあいだの揺れ、一瞬だけの F major、そして少しずつ居場所を広げる Cm。どれも大げさな仕掛けではないが、「いいんじゃない」「わるくない！」と力を抜いて肯定する歌詞に、ちょうど見合った温度で効いている。最後に和音まで手放して「一緒に見たい景色があるんだ」と歌う結末は、飾らないことを肯定するこの曲らしい幕切れだ。
