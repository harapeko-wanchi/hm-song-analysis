# Summer land — 楽曲分析

しえりーほが書いた夏の恋の歌は、ポップスで最も普遍的な I-V-vi-IV を真ん中に据えた、誰もが一緒に歌える曲である。だがその周りには、増三和音の陽炎、同主調への暗転、ルートの半音下行が仕込まれている。聴きどころは、夏の終わりを惜しむようなアウトロだ。マイナーの影から半音ずつ這い上がり、最後にメジャーの光へ帰っていく。

## 基本情報

| 項目 | 値 |
|------|-----|
| リリース | 2023-08-19 |

キーは A major と示されることもあるが、和声の働きからみて主調は E major である。

## 王道循環と全音階ウォークの二段構え

サビ（とイントロ直後のフック）は二つの部分からできている。

```
E → B → C#m → A    （×2）        「O!DO!RE! Summer land…」
F#m → G#m7 → A → B → (E)         「世界で一番！超好き！」
```

前半は I→V→vi→IV。ポップスで最も愛されてきた循環で、「みんなで歌え」と呼びかける歌詞にこれ以上ふさわしい選択はない。「lala lala」のリフレインもこの上に乗り、会場の全員が歌えるメロディになる。後半は ii→iii→IV→V→I と、ルートが音階を一段ずつ駆け上がる。**感情の高まりをそのまま音程の上昇に置き換えた**ウォークで、「超好き！」の頂点へ一気に運ぶ。最も普遍的な循環で安心させ、その上に階段を積んで盛り上げる、二段構えの設計である。

2 番のサビでは「O!DO!RE!」が「HA!SHA!GE!」に替わり、「出会えてよかった！」で最高潮を迎える。進行は同じで、言葉だけが変化をつくる。

## 陽炎と影 — Eaug、同主調切替、半音下行

明るい循環の周りには、夏の光と影を描く細工がいくつもある。まず Aメロの内声だ。

```
E → Eaug → E6 → Eaug → G#m7     「太陽 海の声…」
C#m7 → F#m7 → B                 「向日葵が無邪気に…」
```

E→Eaug→E6 で、和音の 5 度が B→B#（C）→C# と半音ずつ上がる。増三和音（5 度を半音上げた、宙に浮くような和音）の不安定さから、6 度を足した安定へ。その振れ幅が、海面に照り返す陽炎の揺らめきのように聴こえる。Eaug は G#m7（iii7）へ自然に流れ、行末の C#m7→F#m7→B でドミナントの B にたどり着いて、次への期待を残す。

間奏では、夏のど真ん中にふと影が差す。

```
E → Em → A → F#/A#
B → G#/C → A/C# → Am/C → B/D# → E
C#m → E/G#
F#m7 → G#m7 → A → B → C → D
```

E→Em は同主調（同じ主音の短調）への切り替えで、メジャーの輝きが一瞬だけ翳る。続いてベースが A#→B→C→C#→C→D# と半音でさまよい、上のトライアドが次々に色を変える。夏の景色が万華鏡のように移り変わる場面だ。途中の Am/C は E minor から借りた iv で、一瞬の切なさを添える。最後の A→B→C→D（IV→V→♭VI→♭VII）は、ルートが全音・半音・全音と上がっていくクロマティックな上行で、CANDY POP の Cメロでも使われたしえりーほの署名である。本作ではプレサビのリプライズでもう一度現れ、曲の背骨として働く。

ブリッジにはもう一つの影がある。

```
E/B → C#M7sus4 → C#m          「かき氷 頬張る…」
Cm → Bm7 → E7 → AM7
G#m7
F#m7 → G#7                    「2人 夢中になるから」
```

C#M7sus4 で vi の位置の和音が一瞬メジャーに輝き、すぐ C#m に戻る。そこから C#m→Cm→Bm7 と、ルートが 3 つ続けて半音ずつ滑り落ちる。かき氷が溶けるように、照れも心の距離も溶けていく情景だ。E7 は I を属七にした IV への二次ドミナントで AM7 へ解決し、G#7（vi への二次ドミナント）が次の C#m への伏線を張る。

## 夏の終わりを描くアウトロ

この曲の本当のクライマックスはアウトロにある。

```
E → Em → A → F#/A#
B → G#/C → A/C# → Cdim → Bsus4 → Bbm7-5
A → Gdim
F#m7 → G#m7 → Am7 → D7
Em7 → D → D# → E
```

出発点は間奏と同じ素材だが、後半が違う。Cdim→Bsus4→Bbm7-5 でルートが C→B→B♭ と半音で下り、夏の終わりが近づく足音になる。A→Gdim では不安定な減三和音が一瞬よぎる。そして Am7→D7。Am7 は E minor から借りた iv7、D7 は ♭VII7 で、**二重の借用和音**が「もう夏が終わってしまう」という切実さを凝縮する。

最後の 1 小節、Em7→D→D#→E が見事だ。短調の i から ♭VII の D を経て、D# を半音の経過音のように挟み、E major のトニックへ滑り込む。寂しさの底から半音ずつ這い上がり、光の中に帰っていく。夏は終わるが、思い出は輝き続ける。曲のテーマが、この 1 小節に結晶している。

## 楽曲を追う

### Intro

```
Em7
```

主調の短調側の和音で始まる。霧のかかった、夏の夢の中へ引き込まれるような導入だ。

### フック〜Aメロ（太陽 海の声）

フックは前述のサビと同じ二段構え。Aメロは前述の Eaug の陽炎である。

### Bメロ（甘い妄想 急接近で）

```
AM7 → B                                 「甘い妄想…」
G#m7 → C#sus4(b13)/G# → C#7/G#
F#m7 → E
A → F# → Bsus4 → B                      「ずっとこんな日を 待ってた！」
```

C#sus4(b13)/G# は、sus4 の F# と ♭13 の A を同時に含む複合テンションの和音だ。C#7/G# へ解決して F#m（ii）へ向かう二次ドミナントの働きをするが、その手前の宙吊りの響きが独特の浮遊感を生む。後半の F#（II）はドミナントへのドミナント（V/V）で、B への接続を強める。「待ってた！」で Bsus4→B と解決し、サビへの推進力を最大にする。

### サビ（O!DO!RE! Summer land）

前述の I-V-vi-IV と ii-iii-IV-V-I。フックと同じ進行で、王道であることがそのまま強みになっている。

### 間奏〜セリフ①

前述の同主調切替と半音のベースウォーク、A→B→C→D の上行を経て、和声が止まり、「浮き輪がひっくり返ったら…」「これって夢？！」とコミカルなセリフが入る。映画のような場面転換である。

### ブリッジ（かき氷 頬張る）

前述の C#m→Cm→Bm7 の半音下行。

### プレサビのリプライズ（もう少しで 届きそう）

```
AM7 → B                       「もう少しで 届きそう」
EM9 → C#sus4(b13) → C#7
F#m → E
A → B → C → D                 「恋が始まる気がした」
```

Bメロと同じ骨格だが、EM9 が加わって輝度が増す。最後は再び A→B→C→D の上行が「恋が始まる気がした」を大きく持ち上げる。

### 2 番サビ〜セリフ②

```
A → G#m → E → F#m             「めっちゃ好きだけん！」
```

「HA!SHA!GE!」のサビの後、IV→iii→I→ii の上で「めっちゃ好きだけん！」と叫ぶ。下っては上がるダイアトニックの動きに乗せた、告白の瞬間だ。

### アウトロ

前述の、二重借用から Em7→D→D#→E への帰還。

## カタログの中で

しえりーほのカタログ提供曲は 3 曲で、本作は CANDY POP に続く 2 作目にあたる。A→B→C→D のルート上行は両作に共通する署名で、翌年の ICE PARTY ではその末尾の G→A だけが切り出される。ただし色合いは対照的で、CANDY POP が B major の打ち込み主体のキュートなポップなのに対し、本作はギターとピアノの温かい編成で鳴る E major のサマーポップだ。バンド 6.8 は、しえりーほ作品の中で最も高い。

BPM 155 はカタログの中速帯で、BEACH! BEACH! と同じテンポである。セリフパートの挿入も特徴で、「浮き輪が…」「めっちゃ好きだけん！」と和声が止まる・変わる箇所に置かれた語りが、ライブでのコール＆レスポンスの起点になる。

## 総評

I-V-vi-IV という誰もが知る循環を中心に置きながら、増三和音、同主調、二重の借用、半音の上行と下行で、夏の眩しさとその儚さの両方を描き切っている。とりわけマイナーの影から半音ずつ這い上がって E に帰るアウトロは、Hey!Mommy! のカタログでも印象に残るエンディングだ。みんなで歌える夏曲でありながら、聴き終えたあとに少しだけ切なさが残る。その余韻こそがこの曲の核心である。
