## 構成とコード進行

### Intro
```
Em7
```
- マイナー・トニック変形で始まり、夏の夢の中に引き込まれるような霧がかった導入。

### Hook（O!DO!RE! Summer land）
```
E → B → C#m → A                ×2   … I-V-vi-IV（究極のポップ進行）
F#m → G#m7 → A → B → (E)            … ii-iii-IV-V-I（全音階上行ウォーク）
```
- **I-V-vi-IV** はポップス史上もっとも普遍的な循環進行。"みんなで歌え(Hey!) ほら 騒げ(Whoo〜!)" にこれ以上ない選択。
- **ii-iii-IV-V-I** の全音階上行ウォークで「世界で一番！超好き！」へ一気に駆け上がる。ステップワイズの上昇がテンションの高まりをそのまま音程化。

### Aメロ（太陽 海の声）
```
E → Eaug → E6 → Eaug → G#m7
C#m7 → F#m7 → B
```
- **E → Eaug → E6**：5th が B → B#(C) → C# とクロマティックに上行する内声ライン。
  - aug が夢見がちな浮遊感、6th が夏の眩しさを表現。太陽が海面をきらめく描写にぴったり。
- **Eaug → G#m7**：増三和音は iii7 へ自然に解決。
- 「向日葵が無邪気に」の C#m7 → F#m7 → B で属和音 B に辿り着き、次のセクションへの期待感を作る。

### Bメロ（甘い妄想 急接近で）
```
AM7 → B
G#m7 → C#sus4(b13)/G# → C#7/G#
F#m7 → E
A → F# → Bsus4 → B
```
- **C#sus4(b13)/G#**：sus4 = F#、b13 = A を含む複合テンション。C#7/G# への解決で V7/ii 的機能（F#m への指向）を持つが、その手前の sus4+b13 が独特の浮遊感を生む。
- **F# (II)**：= V/V（ドミナントのドミナント）。B への接続を強化。
- 「ずっとこんな日を 待ってた！」で Bsus4 → B に解決し、サビへの推進力を最大化。

### サビ（O!DO!RE! Summer land）
```
E → B → C#m → A     ×2       … I-V-vi-IV
F#m → G#m7 → A → B → (E)     … ii-iii-IV-V-I
```
- Hook と同一進行。王道であることが強み。
- "lala lala lalalala la〜♪(Yeah!)" のリフレインは I-V-vi-IV の上に乗り、観客全員が歌えるユニバーサルなメロディ。

### 間奏①（E → Em 同主調切替 〜 クロマティック・ベースウォーク）
```
E → Em → A → F#/A#
B → G#/C → A/C# → Am/C → B/D# → E
C#m → E/G#
F#m7 → G#m7 → A → B → C → D
```
- **E → Em**：同主調切替。メジャーの輝きからマイナーの翳りへ。「夏の儚さ」の瞬間的な暗転。
- **F#/A# → B → G#/C → A/C# → Am/C → B/D#**：ベースが A# → B → C → C# → C → D# とクロマティックに彷徨う。和声の上ではトライアドが次々と色を変え、夏の景色が万華鏡のように移り変わる。
  - **Am/C**：iv 借用（E マイナーからの借用）。一瞬の切なさ。
- **A → B → C → D** = **IV → V → ♭VI → ♭VII**：クロマティック上行する全音ステップ。CANDY POP の Cメロ「A → B → C → D」と同一テクニック。**しえりーほの作家シグネチャー**。

### セリフ①
> 「浮き輪がひっくり返ったら気持ちを伝えようか…なーんて考えてたのに！」
> 「ちょっと待って？！」「え？！まさかの　これって夢？！えええぇ？！」

- 和声が止まり、語りが入ることで映画的な場面転換。コミカルなセリフとのコントラスト。

### ブリッジ（かき氷 頬張る）
```
E/B → C#M7sus4 → C#m
Cm → Bm7 → E7 → AM7
G#m7
F#m7 → G#7
```
- **C#M7sus4 → C#m**：VI が一瞬メジャー（C# major）に輝き、すぐ minor に戻る。かき氷の冷たい甘さのような一瞬の煌めき。
- **C#m → Cm → Bm7**：**半音下行スライド** C# → C → B。ルートが滑り落ちるように3音連続で下降。切なさと儚さが凝縮された瞬間。
- **E7 → AM7**：I が7化し V7/IV として機能。AM7 に解決するセカンダリードミナント。
- **G#7**：V7/vi。次のセクションの C#m への伏線。
- 「照れるじゃん！って」「2人 夢中になるから」── 氷が溶けるように心の距離も溶けていく。

### Pre-chorus リプライズ（もう少しで 届きそう）
```
AM7 → B
EM9 → C#sus4(b13) → C#7
F#m → E
A → B → C → D
```
- Bメロと同構造だが、**EM9** が加わりさらに輝度が増す。
- 再び **A → B → C → D** のクロマティック上行が「恋が始まる気がした」を大きく持ち上げる。

### 2nd サビ（HA!SHA!GE! Summer land）
- O!DO!RE! が HA!SHA!GE! に変化。同一進行でバリエーションを生む歌詞の工夫。
- 「出会えてよかった！超好き！」で最高潮。

### セリフ②〜Pre-final
```
A → G#m → E → F#m     … 「めっちゃ好きだけん！」
```
- IV → iii → I → ii：叫びのセリフに載せて疾走するダイアトニック下行→上行。告白の瞬間。

### アウトロ（最重要セクション）
```
E → Em → A → F#/A#
B → G#/C → A/C# → Cdim → Bsus4 → Bbm7-5
A → Gdim
F#m7 → G#m7 → Am7 → D7
Em7 → D → D# → E
```
- 間奏と同じ素材から出発するが、後半が異なる：
  - **Cdim → Bsus4 → Bbm7-5**：C → B → Bb のクロマティック下行。夏の終わりが近づく足音。
  - **A → Gdim**：IV → ♭iiidim。不安定な diminished が一瞬よぎり…
  - **Am7 → D7**：**iv7 → ♭VII7 のダブル・モーダルインターチェンジ**。Am7 は E マイナーからの借用 iv、D7 は ♭VII7。二重の借用和音が「もう夏は終わってしまう」という切実な感情を凝縮。
  - **Em7 → D → D# → E**：**マイナー i → ♭VII → クロマティック半音 → メジャー I への最終解決**。
    - Em7 の寂しさから D を経由し、D# が半音のパッシングノートとして E メジャーへ滑り込む。
    - **「夏は終わるけど、思い出は永遠に輝く」**── この1小節にテーマが凝縮される。

## 楽曲の特徴

### 1. I-V-vi-IV × ii-iii-IV-V-I：究極のポップ二段構え
サビは「世界で最も愛されるコード進行」I-V-vi-IV で安心感とキャッチーさを確保し、その直後に ii-iii-IV-V-I の全音階上行ウォークで盛り上がりをさらに加速する。最も普遍的な循環の上に積み重ねるステップワイズの上昇が、「超好き！」の感情的クライマックスを建築的に支えている。

### 2. E → Eaug → E6：陽炎の内声クロマティック
Aメロで展開される B → B#(C) → C# の内声上行は、太陽が海面を照りつける揺らめきを音で描く。aug → 6th という移行は、不安定（増三和音）→ 安定（付加六）の振れ幅が "ドキドキ" と "キラキラ" を交互に感じさせる仕掛け。

### 3. E → Em 同主調切替と Am/C：夏の光と影
間奏での E → Em は、夏のど真ん中にふと影が差すような瞬間。Am/C（iv 借用）もエオリアンからの借用で、一瞬の翳りが逆に全体のハッピーを引き立てる。

### 4. A → B → C → D：しえりーほシグネチャー
IV → V → ♭VI → ♭VII のクロマティック全音上行は CANDY POP でも使われた作家シグネチャー。等間隔で上昇するルートラインが問答無用のカタルシスを生む。本曲では間奏とプレコーラスの2箇所で使用され、曲の構造的な背骨として機能。

### 5. C#m → Cm → Bm7：半音下行スライド
ブリッジでの3和音連続半音下行は、氷が溶けるように心が溶けていく情景を和声で描写。直前の C#M7sus4（メジャー化した一瞬の煌めき）からの落差が切なさを増幅。

### 6. Am7 → D7 → Em7 → D → D# → E：アウトロの二重借用〜クロマティック解決
楽曲の真のクライマックスはアウトロ。iv7 と ♭VII7 のダブル・モーダルインターチェンジで「夏の終わり」の切なさを最大限に描き、Em7 → D → D# → E の半音クロマティック上行で最終的にメジャー・トニックへ回帰する。「夏は終わるけど思い出は永遠に光る」── 曲のテーマそのものが和声に宿っている。

### 7. セリフパートの演劇的効果
「浮き輪がひっくり返ったら…」「これって夢？！えええぇ？！」「めっちゃ好きだけん！」── コード進行が止まる/変化する箇所に挿入されるセリフが、ライブでのコール＆レスポンスの起点となり、アイドル楽曲としての参加性を最大化。

## Hey!Mommy! 楽曲群での位置づけ

**Summer land** は、7777777 と並ぶ「子供心×夏」ラインの楽曲だが、7777777 の「夢の中のファンタジー」に対して Summer land は「リアルな夏の恋」を描く。I-V-vi-IV という最もユニバーサルな進行を軸に据えることで、ライブ会場全体が一体になれる「みんなの夏曲」としてのポジションを確立。

作家しえりーほの **A → B → C → D クロマティック上行**が CANDY POP と共通するシグネチャーであり、2曲は「しえりーほ作品」として作家性のペアリングが可能。ただし CANDY POP が Bmaj のクールなダンスチューン寄りであるのに対し、Summer land は E メジャーの眩しいサマーポップとして対照的な色彩を持つ。

アウトロの **Em7 → D → D# → E** は、マイナーからクロマティック半音を経てメジャーに帰還する「夏の記憶の結晶化」であり、Hey!Mommy! 楽曲群の中でも屈指の美しいエンディング処理。
