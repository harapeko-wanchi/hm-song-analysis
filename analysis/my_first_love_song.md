# MY FIRST LOVE SONG — 楽曲分析

BPM 220。リリース時点でカタログ最速を更新したこの曲は、全編英語で「言葉が足りない」と歌い続け、最後に日本語で本音を打ち明けるラブソングである。サビに入る瞬間に C major から Ab major へ長 3 度下へ飛び、間奏では半音ずつ駆け上がって元の調へ戻る。聴きどころは、転調と言語の切り替えという二つの「跳躍」だ。

## G から Eb へ — 一撃で切り替わる調

Aメロと Bメロは C major で進み、プレサビの終わりで調が切り替わる。

```
Em → Am                   「Only I say it…」
F → G → Eb                「Are you ready…」「My first love, let's go」
```

F→G（IV→V）と C major のドミナントを鳴らした直後に、Eb が来る。C major から見れば ♭III、外の和音だ。しかしこの Eb は、次に来る Ab major の V（ドミナント）でもある。**一つの和音が二つの調をまたぐピボットとなり、転調が一撃で完了する**。G から Eb へは長 3 度下（短 6 度上）。理屈の上では遠い関係で、V が解決するはずの I を裏切って ♭III に飛ぶ感覚は、体感としては劇的な跳躍になる。

そしてこの切り替えは、「My first love, let's go」の言葉と同時に起こる。歌詞と和声の転換点がぴったり一致している。2 番のプレサビでも同じピボットで、ふたたび Ab major へ飛ぶ。

## 半音で駆け上がる帰り道

1 番のサビが終わると、間奏で逆方向の跳躍が起こる。

```
Ab → Eb → E → Fm → Gb → G
```

Ab major の V（Eb）から、E、Fm、Gb、G と半音ずつ上がっていく。最後の G は C major の V で、そのまま 2 番の C major に戻る。プレサビの G→Eb が C から Ab への入口なら、この間奏の Gb→G は Ab から C への出口である。**行きは長 3 度の跳躍、帰りは半音の階段**。二つの転調が鏡像の関係をなし、サビの Ab major の温かさから、Aメロの C major の切なさへと聴き手を引き戻すワープ装置になっている。

2 番のサビの後の間奏では、もう C major には戻らない。Ab major に留まったまま Dメロに入り、最後まで走り切る。

## 英語では足りない — 日本語の Dメロ

この曲はほぼ全編が英語で歌われる。そのなかで「Words aren't enough」（2 番 Aメロ）、「Too few words」（2 番サビ）と、言葉が足りないことが繰り返し語られる。その末に、Dメロで突然日本語が現れる。

```
Db → Ab(add9)             「切なさ増すこの時間が」
Bbm → Ab → Ab7            「キミに届けばいいな」
Db → Eb → C7 → Fm         「恥ずかしいとかなんて考えず」
Bbm → Db → Eb             「素直に届けるよ」
```

和声もここで色を変える。Ab(add9) は主和音に 9 度を足し、切なさの中に透明感を加える。Ab7 は主和音に短 7 度を加えた I7 で、Db（IV）へのドミナント（V7/IV）として働き、次の行へ引っ張る。そして「考えず」で **C7（V7/vi、Fm への二次ドミナント）**が鳴り、Fm に力強く解決する。Ab major の iii である Cm をメジャーにした和音で、恥じらいを振り切る瞬間を和声が押し出す。最後は Bbm→Db→Eb（ii→IV→V）で「素直に届けるよ」を送り出す。

英語で「足りない」と言い続けた主人公が、母語で本音をさらけ出す。言語の切り替えそのものが表現の手段になっている。続くラストサビも同じ進行を日本語で歌い、英語の「I know I love you」が「どんな時もキミが好きだよ」に置き換わる。

## 楽曲を追う

### Intro（Love...）

```
C
```

C major のワンコードで幕を開け、「Love...」の一言だけを置く。BPM 220 の疾走が始まる前の静けさである。

### Aメロ（I said goodbye with a smile）

```
C                         「I said goodbye…」
F → C                     「Can't touch you…」
（コード変化なし）         「I know it Nothing stays…」
F → C                     「I give you love…」
```

C（I）と F→C（IV→I）の往復だけでできている。BPM 220 の上でコードを絞り、歌詞とリズムに集中させる構造だ。IV→I のプラガルな動きが、切なさの中に温かさを残す。「(I know it Nothing stays)」「(Time goes on, miss you)」の括弧のエコーがコーラスワークとして響く。2 番の Aメロも同じ構造で、歌詞は「miss you」から「done with this」「scared」へと深まっていく。

### Bメロ（C'mon, yeah）

```
Em                        「C'mon, yeah…」
Am → F                    「A brand new new day…」
G                         「Call your name…」
```

iii→vi→IV→V。3 度ずつ下りてから IV→V でドミナントを準備する。「C'mon, yeah」の掛け声でギアが入り、Aメロの往復から一気にコードが動き出す。2 番では「Do you remember」と過去の回想に入り、「You changed me」と相手への感謝が語られる。

### プレサビ（Are you ready）

前述の G→Eb のピボット転調。

### サビ（Through the night）

```
Ab → Eb → Fm → Cm         「Through the night…」
Db → Ab → Bb → Eb         「You make my heart…」
Ab → Eb → Fm → Cm         「I know, I know…」
Db → Eb → Ab → Eb         「I can't stop saying…」
Db → Eb → Ab              「Right now now…」
```

I→V→vi→iii、IV→I→II→V。カノン進行を変形した形である。Bb（II）はダイアトニックの ii（Bbm）をメジャーにした和音で、Eb（V）への二次ドミナント（V/V）として解決の力を強め、サビの推進力を増す。後半の Db→Eb→Ab（IV→V→I）は王道のカデンツで、2 回目の「Love with I Love you」で Ab に帰着する。フレーズを重ねるごとに終止感が強まる構成だ。2 番のサビは同じ進行に「My heart on fire」と燃え上がる言葉が乗る。

### 間奏

前述のクロマティックな帰還。2 番の後の間奏は Ab major に留まる。

```
Ab → Eb → Fm → Eb
Db → Eb → Cm → Fm         （×2）
Db → Eb → Fm → Ab
```

I-V-vi-V、IV-V-iii-vi の循環で、iii（Cm）が哀愁を添える。3 回目で Fm→Ab（vi→I）に変わり、Dメロへの着地を用意する。

### Dメロ〜ラストサビ

前述の日本語パート。ラストサビの最後は「止められない」で Db→Eb（IV→V）、「LOVE WITH I LOVE YOU」で Ab（I）に着地する。止められない感情が、和声の解決とそのまま重なる。

### Outro（LaLaLa I love you）

```
Ab                        「LaLaLa I love you」
Eb → Fm                   「Dakara Singing for you」
Cm → Db → Ab → Bbm → Eb   「My first love…」
Db → Eb                   「Love you Love you…」
Db → Eb → Ab              「…Love... Love song」
```

「LaLaLa I love you」はメロディをラララに乗せたシンガロングで、2 回目は括弧のエコーが付くコール＆レスポンスになる。Cm→Db→Ab→Bbm→Eb（iii→IV→I→ii→V）では、サビで Bb（II）だった和音が **Bbm（ii）に戻っている**。メジャーの II の攻撃的な推進力が、ダイアトニックの ii の穏やかさに解ける。告白の激しさが、「歌う」ことの優しさに変わる瞬間だ。最後は Db→Eb→Ab（IV→V→I）で「My first love Love... Love song」と曲名を回収する。「Love...」で始まり「Love song」で終わる、環状の構造である。

## カタログの中で

BPM 220 は、リリース時点では Hey! get up kids（210）を 10 上回るカタログ最速だった。NNBS. が自分の記録を塗り替えた形で、のちに Happy Go Round が同じ 220 で並び、現在は最速タイである。疾走感 8.8 はビスケットケースと並ぶ 3 位タイ、バンド 7.8 は 4 位で、ビスケットケースのギターロックの路線を継いでいる。

ただし向かう先は対照的だ。エモ 7.8 は Next Story、SUMI-HAJI、MAGNET に次ぐカタログ 4 位で、子供心 2.6 と合わせて、大人っぽく感情的な側に位置する。ビスケットケースが楽しい全力疾走なら、MY FIRST LOVE SONG は切ない全力疾走。同じ NNBS. の高速バンドロックでも、感情のベクトルは正反対を向く。

長 3 度の転調は、古橋勇紀が書いた START RUSH!! の Ab→C（長 3 度上）と鏡像の関係にある。本作は C→Ab と長 3 度下へ、しかも同じ Ab と C の 2 つの調の間を行き来する。のちに NNBS. は Happy Go Round でも G→E の短 3 度下転調を山場に置いており、3 度関係の転調は NNBS. の高速曲の見せ場として定着していく。

Dメロの Ab7（I7 を V7/IV として使う手法）は、AILI がご機嫌マミーはご機嫌ガールで多用した和音でもあり、NNBS. 自身も GALAXY! GALAXY!、POJI POJI GO、PLAYFUL ROMANTIC で I7 を署名のように使ってきた。ほぼ全編英語の詞という点では Hey! get up kids に続くが、英語から日本語へ切り替えることを仕掛けにした曲は、分析ファイルを見渡すかぎり本作だけである。

## 総評

C から Ab への跳躍、半音の階段での帰還、そして英語から日本語への切り替え。この曲は、何かを「飛び越える」瞬間を三度用意している。そのどれもが、初めての恋を言葉にしようとしてうまく言えない、という一つの主題に結びついている。220 の速度で走りながら、最後に残るのは「LaLaLa」という言葉にならない歌だ。言葉が足りないなら歌えばいい。曲そのものが一通のラブレターになっている。
