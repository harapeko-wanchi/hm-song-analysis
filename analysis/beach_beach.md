# BEACH! BEACH! — 楽曲分析

ビーチバレージャパンの応援ソングとして書かれたこの曲は、I-V-vi-IV というポップスの黄金進行を、ほぼ全編にわたって正面から鳴らし続ける。その中で NNBS. が仕掛けたのは、ベースだけが滑り台のように降りていくフックと、「大きな壁なんて トバソー」の一瞬だけ調の外へ踏み出す和音だ。ストレートさの中に置かれた、その二つの例外を聴きたい。

## 黄金進行の全編支配

サビの「BE THE ONE」は、Eb→Bb→Cm→Ab、つまり **I-V-vi-IV** を 2 小節ずつ反復する。ポップスで最もよく使われる進行を、何の加工もせずにそのまま使う。

```
Eb → Bb → Cm → Ab    「BE THE ONE」（×2）
```

続く Post-Chorus も、Verse も、同じ 4 つの和音の組み替えでできている。Post-Chorus は I-V-vi-IV から I-V-V7 と伸ばし、末尾の Bb7 で次のセクションの I へ強く引き戻す。Verse は前半で I-V-vi-IV、後半で IV-I-V-V7 と、IV から始まる変形を見せる。終盤の「OH OH OH」と Final Verse は、Ab から始めて IV-I-V-vi とローテーションさせる。同じ和音群のまま、入り口を IV にするだけで、力まない柔らかな導入になる。

こうして Chorus A、Post-Chorus、Verse、そしてコールのセクションまでが、すべて I-V-vi-IV かそのローテーションで書かれている。この和音群から外れるのはブリッジだけだ。応援ソングとして、誰もがすぐ乗れる和声を選んだのだと思われる。

## 滑り台のように降りるベース — JUMPING のフック

その王道の中で、最大の仕掛けがフックの「JUMPING JUMPING」に置かれている。

```
Eb → Eb/D            「JUMPING JUMPING 声にだして…」
Cm → Eb              「せーの せーの ATTACK ATTACK…」
Ab → Eb/G            「JUMPING JUMPING 飛び越えていこう…」
Eb/F → Bb7           「ラララララ ラララ 1.2.3.で」
```

上声は Eb の響きを保ったまま、ベースだけが階段を降りる。第 1 波は Eb、D、C と、I から I/7（7 度をベースにした転回形）を経て vi へ、半音と全音で下る。第 2 波は Ab、G、F と IV から I/3、I/2 を経て、Bb7（V7）へ着く。

歌詞は「JUMPING」と跳び上がっているのに、ベースは二度にわたって降りていく。**上へ跳ぶ言葉と、下へ滑るベースの逆向きの動き**が、単純な和音の繰り返しに立体感を与えている。転回形でベースラインに変化をつけるこの手法は、2〜4 コードのミニマリズムとは別の、NNBS. のもう一つの引き出しといえる。

## 壁を越える瞬間だけ、和声も壁を越える

ブリッジで曲は初めて、黄金進行の外へ出る。

```
Cm                   「眩しすぎる太陽も」
AbM7                 「強く吹く風も」
Bb                   「同じ色で夢をつなぐ…」
Cm                   「何度でも立ちあがろう」
AbM7                 「思い切り飛び跳ねよう」
F → Bb               「大きな壁なんて トバソー」
```

vi→IVM7→V→vi→IVM7→II→V と進む。AbM7 は、通常のセクションで硬く鳴っていた IV に長 7 度（G）を足したもので、「強く吹く風」「思い切り飛び跳ねよう」に浮遊感を与える。

そして最後の F。Eb major のダイアトニックなら Fm のところを長三和音にした II で、Bb（V）への二次ドミナント（V/V）にあたる。この曲で調の外にある和音は、この F ただ一つだ。それが「大きな壁なんて トバソー」の決定的な瞬間に置かれ、F から Bb への解決とともに壁が越えられる。ダイアトニックの純度が極めて高い曲だからこそ、**「壁を越える」瞬間に和声も壁を越える**という一点の逸脱が効いてくる。

## 楽曲を追う

### Intro

```
| Ab |
```

IV の一発で入場し、サビ前の高揚を予感させる。

### Chorus A（BE THE ONE）

前述の I-V-vi-IV。2 小節を反復して「BE THE ONE」を刻み込む。

### Post-Chorus（GOING ON）

```
Eb                   「GOING ON GOING ON KNOCK ON…」
Bb → Cm              「これからの夢中は…」
Ab → Eb              「GOING ON GOING ON 夢の続きを？」
Bb → Bb7             「ここからもどこまでも…DEAR BEACH AND SKY」
```

I-V-vi-IV-I-V-V7。黄金進行を引き延ばし、末尾の V7 でターンアラウンドする。V7 が次のセクションの I へ解決しようとする力が、セクション間の推進力になる。

### Verse（声も流される）

```
Eb → Bb → Cm → Ab    「声も流される砂浜で…」
Ab → Eb → Bb → Bb7   「昨日の自分を越えて…」
```

前半は王道進行、後半は IV から始まる変形。IV から I へ、プラガル（IV から I への穏やかな終止）の方向から出発して安定の I を経由し、V7 で再び加速する。

### Bridge（眩しすぎる太陽も）

前述の vi-IVM7-V-vi-IVM7-II-V。

### Pre-Chorus（Let's BE EASY EASY）

```
Eb                   「Let's BE EASY EASY」
```

I の一発だけ。力みを抜く呼吸の間を作り、フックへ渡す。

### Hook（JUMPING JUMPING）

前述の二波の下行ベース。

### Post-Hook（ほんとの名場面を）

```
Eb → Eb/D            「ほんとの名場面を…」
Cm → Eb              「NEVER NEVER ATTACK ATTACK…」
Ab → Eb/G            「最高な最後まで…」
Fm → Bb7 → Eb        「ジャジャジャジャン…C'MON C'MON」
```

JUMPING と同じ構造だが、最終行が Fm→Bb7→Eb、ii→V7→I の完全終止に変わる。Fm（ii）はこの箇所にしか登場しない。「ジャジャジャジャン」のリズミックなブレイクと完全終止が重なり、ii の重みが曲のクライマックスを担う。

### OH OH OH〜Final Verse（強く光る日差しと）

```
Ab → Eb → Bb → Cm    「OH OH OH OH…Hey!」（×2）
Ab → Eb → Bb → Cm    「強く光る日差しと…」「熱い日々が…」
Ab → Eb              「声をあげていこう…」
```

前述の IV-I-V-vi のローテーション。IV で柔らかく始まり、Cm（vi）で切なさを加え、また Ab へ戻る。8 小節の反復はコール＆レスポンスのための設計で、そのまま最後のメッセージも同じ「裏始動」の王道進行で歌われる。

### Outro（WINING WINING）

```
Bb                   「WINING WINING WINING WINING」「Hey!」「Let's BE EASY EASY」
（BE THE ONE → GOING ON）
Bb → Bb7             「DEAR BEACH AND DANCE AND…」
Eb                   「SMILE」
```

V の Bb だけで「WINING」を連呼し、ドミナントの緊張を引っぱる。サビと Post-Chorus を経て、最後は Bb から Bb7 へ。いつもは「DEAR BEACH AND SKY」と歌う箇所を「DANCE AND SMILE」に差し替え、最後の Eb（I）で完全に着地する。

## カタログの中で

同じ時期までの NNBS. 作品と並べると、本作の和声の作りの特徴が見えてくる。

| | 7777777 | HELLO!! Hey!! WORLD!! | BIRD TRIP | もちぷる | BEACH! BEACH! |
|---|---|---|---|---|---|
| リリース | 2023-05 | 2023-11 | 2023-12 | 2024-04 | 2024-08 |
| Key | Ab | B | Ab | E | Eb |
| BPM | 145 | 175 | 180 | 198 | 155 |
| 主な循環 | I-IV | I-ii-iii-V | I-V-II-iii | I-IV（サビ）／I-V（Verse） | I-V-vi-IV |
| 調の外の色 | F（VI） | A（♭VII） | Bb（II） | C#（VI） | F（II） |
| テーマ | パーティー | グループアンセム | 飛翔・夢 | はちゃめちゃ | スポーツ応援 |

どの曲も、調の外の和音を一点だけ差して色をつけるという点では共通している。違いは、その周りの和音の量だ。本作は 11 種のコードを使いながら、そのうち調の外にあるのは F（V/V）だけ。数を減らして純度を保つのではなく、Eb/D、Eb/G、Eb/F といった転回形でベースラインを動かして変化を作る。

スコアの面では、9 軸のどれもが極端に振れていない。いちばん高いのがハッピー 6.6、クール 6.3 で、どのマップでも中央付近に位置する。誰に向けても開かれた、全方位型の Hey!Mommy! サウンドだ。

## 総評

黄金進行という誰もが知る和声を、てらいなく全編に鳴らす。その潔さがあるからこそ、ベースが降りていくフックと、壁を越える一瞬の F が際立つ。「勝てるとしかもう思わない」と歌い切る応援ソングにふさわしく、迷いのない直線の上に、ほんの二つだけ見せ場を置いた曲である。
