# LOVE ME DO DO — 楽曲分析

キュート 8.8 とバンド 8.2。かわいさの極みとギターロックの力強さを同居させた、照れくさい片思いの歌である。ギターリフとエンディングの大サビを、一週間前に出たビスケットケースと共有する姉妹曲でもある。聴きどころは、サビで滑らかに降りていくベースラインと、終盤で全音上へ跳ね上がる転調だ。

## 一段ずつ降りるベースが運ぶ「MAKE ME LOVELY」

サビの核は、後半の G→D/F#→Em7→A にある。

```
D → F#m          「MAKE ME LOVELY…」
Bm → D           「ちゃんと 約束して欲しくて」
G → D/F# → Em7 → A    「キミとのこの 距離が…」
A → A7           「TAKE ME」
D → F#m          「BABY BABY…」
Bm → D           「ちょっと余裕 でいられなくて」
G → D/F# → Em7 → A    「今頃は どこで…」
Em → G → A       「いくつものLOVE（OH BABY）」
Bm → D           「こころを ギュッとさせる」
G → A            「おしてくれBABY」「POP DAY 夢中で」
```

G→D/F#→Em7→A では、ベースが G→F#→E と一段ずつ降りてから A へ上がる。D/F# は D の 3 度 F# をベースに置いた転回形で、G と Em7 のあいだをつなぐ経過のベースとして働く。**この滑らかな下行が、「距離が不安になる」「どこで誰といるのかな」という揺れる気持ちを運んでいく**。

前半の D→F#m→Bm は I→iii→vi。D と F#m、D と Bm はそれぞれ 2 つの音を共有する 3 度関係の和音で、甘い響きのまま切れ目なく移り変わる。「MAKE ME LOVELY」「BABY BABY」と洋楽風の甘い言葉が、この柔らかな動きに乗る。

サビの入り口を作るのは、プレサビの終わりの A→A7（V→V7）だ。

```
A → A7      「LOVE LY！」
```

V7 の 3 度 C# が D への導音になり、ドミナントの引力でサビへ引き込む。2 番ではこの「LOVE LY！」が 3 回繰り返され、期待をさらに高める。

## 「ねねね」の ♭VII と、階段を登るブリッジ

1 番のサビの後、曲は「ねねね」と甘えるセクションに入る。

```
D        「ねねね ちょっとわがまま…」
A        「ねねね はしゃいで…」
G → C → D    「キミがいちばんスキだと…」
```

ここで鳴る C は、D major から見た **♭VII**、D ミクソリディアン（7 度を半音下げた旋法）からの借用和音である。G→C→D（IV→♭VII→I）の C の意外性が、「ポンとして」「なんかして」というおねだりの可愛らしさを引き立てる。

続くブリッジは、2 番へ向けたビルドアップだ。

```
G → A → D → Bm       「側にいてくれるだけで…」
Em → F#m → G → A     「そんな存在が 前向きをくれる」
```

Em→F#m→G→A は ii→iii→IV→V。ベースが E→F#→G→A と一段ずつ登っていく。サビで降りていったベースが、ここでは登っていく。「前向きをくれる」という歌詞どおりの上昇である。

## 全音上の E major へ — ビスケットケースと共有する大サビ

タイトルフレーズを畳み掛けるセクションの後、曲は**全音上の E major へ転調**する。

```
A → E → B → C#m      「I WANNA BE…」
A → E → B → C#m      「GOOD GOOD DAYだから…」
A → E → B → C#m      「遊ぼう ボクと一緒に」
A → B → C#m7         「どこまでも いつまでも」
A → E → B → C#m      （×3）「HAPPYが…」…
A → B → C#m7         「誰よりも 素敵だね」
A → B → C#m7         「キミがいて ボクがいて」
A → B                「FALLIN LOVEだ」
B7 → E               「これから…」
```

E major の IV→I→V→vi の循環で、最後は B7→E の完全終止で締める。転調でキーが上がることで、曲のエネルギーが最大になる。

この大サビは、ビスケットケースの最後のサビと、コード進行だけでなく歌詞まで同じだ。2 つの曲は同じ NNBS. の作品で、リリースは 1 週間違い。D major の本作が E major に転調してたどり着く場所は、E major で書かれたビスケットケースの終着点そのものである。姉妹曲としての結びつきを、これほど明確に示す仕掛けはない。

## 楽曲を追う

### Intro（ギターリフ）

```
guitar (loop): ラシミレ（A-B-E-D）
A → E7      （×16 小節）
B
```

ビスケットケースと同じギターリフと A→E7 のループで始まる。E major のビスケットケースではこのループは IV→I7 だが、D major の本作では V→II7（V への二次ドミナント）として鳴る。同じリフが、調が変わるだけで別の機能を帯びている。

### Intro riff（歌入り / LOVE ME DO DO）

```
D → G → G9 → G → G → F#m → Em → A      「LOVE ME」
D → G → G9 → G → G → F#m → Em → A      「DO DO」
```

I→IV→IV9→IV→iii→ii→V。G から F#m、Em へとベースが降りていく。G9 の 9 度（A）が爽やかな彩りを添える。

### Verse 1（パッとさ 目の前にほら）

```
D → A → G → D      「パッとさ…」
Bm → D → G → A     「テレテレの キミいたね」
D → A → G → D      「ちょっとはさ…」
Bm → D → G → A     「前よりも 大人だよね」
```

I→V→IV→I、vi→I→IV→V。D、A、G の三和音の往復に、Bm がエモーショナルなアクセントを添える。

### Pre-chorus 1（この世界は たまには）

```
G → D             「この世界は…」
G → Bm → A        「素敵なコトが…」
G → A → Bm → D    「言葉にしたら…」
Em → G → D        「ここはいつも マルだ」
```

IV を中心にした浮遊感のある進行。IV→V→vi→I の循環から ii→IV→I で着地し、「マルだ」の D が温かい解決になる。

### Chorus A（MAKE ME LOVELY）

前述の I→iii→vi→I と、G→D/F#→Em7→A の下行ベース。

### 「ねねね」セクション

前述の IV→♭VII→I。「ポンとポンとポンと」「なんか なんか」と、おねだりの言葉が弾む。

### Bridge

前述の ii→iii→IV→V の上行。

### Verse 2 / Pre-chorus 2（やっぱりさ目の前にほら）

1 番と同じ進行。「キミいないとね」「照れるよね」と、歌詞は少しずつ距離を縮める。プレサビは「ドキドキが あふれた」で着地し、「LOVE LY！」が 3 回繰り返されてサビへ。

### Chorus A（2 番）

1 番と同じ進行。「スキといわれたくて」「よそ見して いるのを 気づかないふりで」と、不安は嫉妬の色を帯びていく。「こころを ギュッとさせる」は「ブンとさせる」に変わる。

### Interlude 2

Intro riff の再現。

### Verse 3 / Pre-chorus 3（いつも 自分がほら）

同じ進行で、「隣いても いいですか？」と一歩踏み込む。1 番の「マルだ」に対して、3 番のプレサビは「やっぱちょっと バツだ」で終わる。○と×で気持ちを判定する、子供っぽくも可愛らしい言葉遊びだ。

### Chorus A（3 番）

```
G → D → Em → A      「よそ見して…」
```

同じ進行だが、最後の行だけ G→D/F#→Em7→A が G→D→Em→A に簡略化される。

### LOVE ME DO セクション

```
D               「LOVE ME DO」
F#m → Bm        「LOVE ME DO DO」
D → G           「LOVE ME DO（DO）」
G → D/F#        「LOVE ME LOVE ME…」
Em7 → A         「LOVE ME DO DO DO」
```

I→iii→vi→I→IV→I/3→ii7→V。サビの進行を圧縮した形で、タイトルフレーズを畳み掛ける。

### Final Chorus（大サビ）

前述の E major への転調と、B7→E の完全終止。

### Outro

```
Em → G → A     「いつだって LOVE（OH BABY）」
Bm → D         「今も声 聞きたいよ」
G → A          「おしてくれBABY」「POP DAY 夢中で」
```

元の D major に戻り、サビの後半を再現する。

### Outro riff

```
A → E7      （×16 小節）「GO GO GO… HEY HEY HEY…」
D → G → G9 → G → G → F#m → Em → A      「LOVE ME」
D → G → G9 → G → G → F#m → Em → A → D  「LOVE ME DO DO」
```

ビスケットケースと同じ「GO GO」「HEY HEY」の掛け声をギターリフに乗せ、Intro riff を再現して D で終わる。

## カタログの中で

キュート 8.8 はもちぷるに次ぐカタログ 2 位、クール 1.2 は同じくもちぷるに次いで 2 番目に低い。それでいてバンドは 8.2 でカタログ 3 位。キュートの上位 5 曲のうち、バンドが 7 を超えるのは本作だけである。かわいい歌詞をギターロックの力強さで鳴らすギャップが、この曲の個性だ。

姉妹曲ビスケットケースとの共通点と違いは、次のようにまとめられる。

| | ビスケットケース | LOVE ME DO DO |
|---|---|---|
| リリース | 2022-07-08 | 2022-07-15 |
| Key | E major | D major → E major |
| BPM | 206 | 176 |
| キュート / バンド | 6.1 / 8.8 | 8.8 / 8.2 |
| ギターリフ（ラシミレ）と A→E7 ループ | IV→I7 | V→II7 |
| 大サビ | A→E→B→C#m、B7→E で終止 | 同じ進行と歌詞（E major へ転調して到達） |
| アウトロ | GO GO / HEY HEY | GO GO / HEY HEY |

ビスケットケースが仲間と弱さの肯定を 206 の速度で駆け抜けるのに対し、本作は 176 に落として、片思いのテレテレした気持ちを歌う。同じ素材から、元気の歌と恋の歌を作り分けた二部作といえる。恋の歌という点では、半年あまり後に出た恋するとちゅうと並んで、NNBS. のラブソングを代表する一曲である。

## 総評

降りていくベースで不安を運び、♭VII でおねだりを可愛らしく彩り、登っていくベースで前向きになり、最後は全音上の E major で姉妹曲と同じ場所にたどり着く。テレテレした片思いの歌を、和声の上がり下がりで丁寧に描き分けたギターロックである。キュートとバンドという、カタログの中でも両立しにくい二つの数字を高い水準で並べた、Hey!Mommy! らしいギャップの一曲だ。
