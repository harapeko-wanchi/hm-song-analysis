## 構成とコード進行

### Intro
```
| B BM7 B7 | B BM7 B7 | B BM7 B7 | F#7sus4 F#7 |
```
- **B → BM7 → B7 内声クロマティック下行**: 内声 — → A# → A♮
- I → Imaj7 → I7 でトニック内部が "溶けていく"
- B7 = V7/IV（Eへの暗示）だが解決せず — 未解決の甘さ

### Chorus（今日は ICE! PARTY!）
```
| C#m7     | F#       | D#m7  G# | C#m7  F#7  B |
  今日は ICE!  PARTY!     GIRLS   POWERは 無限大
| C#m7  F#7 | B       |
  ちゃんと味  わってね！
```
- 基本循環: **ii7 → V → iii7 → VI → ii7 → V7 → I**
- **G#（VI）= ピカルディ式借用** — ダイアトニックvi（G#m）を長三和音化
- 一部コーラスでは B → G# で終止（I → VI リフト）

### Chorus B（ねぇちょっと！）
```
| B    G#  | C#m  F#  B |
  もっと！    ねぇちょっと！
| G#       |
 (LOVE LOVE YOU)
```
- B → G# → C#m → F# → B = **I → VI → ii → V → I** の変形カデンツ
- VI が ii への "上方経由" を作る

### Post-Chorus（ICE! ICE!）
```
| C#m7 F#7 | D#m7 G#m | C#m7 F#7 | B  G  A  |
  ICE! ICE!   ICE! ICE!   ICE! ICE!  ICE! ICE! ICE!
```
- 前半: ii7 → V7 → iii7 → vi（ダイアトニック）
- 後半: ii7 → V7 → **I → ♭VI → ♭VII**
- **G → A = しえりーほ署名** ♭VI → ♭VII モーダル借用
  - CANDY POP: A→B→C→D（♭VII→I→♭II→♭III）
  - Summer land: A→B→C→D（IV→V→♭VI→♭VII）
  - ICE PARTY: G→A（♭VI→♭VII）— 署名の末尾2音を抽出

### Verse（秘密基地で / ELEGANTな）
```
| B  F#/A# | G#m  B/F# | E   B  | C#m  F#  |
  秘密基地で    お泊まり会     うちらしか   LOVE STORY
| B  F#/A# | G#m  B  B7 |
  とびっきり    持ち寄って
```
- **Bass: B → A# → G# → F#**（I度から V度へのステップワイズ下行）
- B7 が次セクションへの橋渡し（V7/IV の暗示）

### Verse 後半
```
| EM7      |                  | Bsus4 | C#m7  F#7  B |
  SHAREしてこ？                  隠し味は  CHERRY フィルター🍒
```
- **EM7（IVmaj7）** — ヴァース唯一のテンション、"SHARE" の浮遊感
- Bsus4 → C#m7 → F#7 → B で cadential resolution

### Pre-Chorus（酸いも甘いも / ワクワクも）
```
| C#m7 F#7 | D#m7 G#m | C#m7 F#7 | B  F#7sus4/C#  Bdim/D  B/D# |
  酸いも        甘いも      知ってる関係  って  おいし    い    でしょ？
| C#m7 F#7 | D#m7 G#m |
  経験したら     コクがある
| AM7   A6 | Aadd9    |
  フレーバーに    （フレーバーに）
| F#7sus4 F#7 | G#sus4 G# |
  大歓声
```

#### F#7sus4/C# → Bdim/D → B/D#（半音上行バス）
- Bass: **C# → D → D#**（クロマティック上行）
- Bdim/D = 減三和音パッシングコード（C#とD#を滑らかに接続）
- "おいしいでしょ？" の "いい" で半音が滑り上がる

#### AM7 → A6 → Aadd9（♭VII変容 — "フレーバー" の和声的具現）
| コード | 構成音 | B major由来の音 |
|--------|--------|----------------|
| AM7 | A C# E **G#** | G# = vi度音（6th） |
| A6 | A C# E **F#** | F# = V度音（5th） |
| Aadd9 | A C# E **B** | B = I度音（tonic） |

- 同一 ♭VII ルート上で上部構造が **6→5→1** と変化
- 異質な ♭VII コードが段階的に **主調の DNA** を吸収する
- 歌詞 "フレーバーに" でまさに "味変" が起きる — 和声とリリックの完全同期

#### F#7sus4 → F#7 → G#sus4 → G#
- V系sus4解決 → VI系sus4解決のペア
- G#sus4 → G#: 非ダイアトニックVI へのsus4準備 = コーラスへの "味の決め手"

### Outro
```
| B BM7 B7 | B BM7 B7 | B BM7 B9 | F#7sus4 F#7 |
  ICE! ICE!    ICE! ICE!   ICE! ICE!  ICE! ICE!
...
| B BM7 B9 | C#m7 F#7 B |
  ICE! ICE!    ICE! ICE!)
```
- Intro の再現 + **B9**（9th = C# 追加）でジャジーな色彩を加えてフェードアウト
- 最終小節で C#m7 → F#7 → B の ii-V-I 正格終止

### ラストライン
```
| C#m7  N.C. | B |
  明日も愛してね♡  ね♡ ね♡ ね♡！？
```
- **N.C.（ノーコード）→ B**: 沈黙の間を挟んでからトニック解決
- "味わう" ための "間" — アイスが舌に触れる瞬間の静寂

## 楽曲の特徴

### 1. B → BM7 → B7 — "溶ける" トニック
イントロ/アウトロの看板進行。内声が A# → A♮ とクロマティック下行し、トニック和音の内部が溶けていく。B7（= V7/IV）は E（IV）へ解決する力を持つが、永遠に解決しない — **溶けかけのアイスが固まらない甘さ**。アウトロで B9 が追加されるのは、最後のひと舐めで新しいフレーバーが見つかる演出。

### 2. AM7 → A6 → Aadd9 — ♭VII が主調を "味見" する
同じ A ルート（♭VII）を3回繰り返しながら、上部の特性音が G#（vi度）→ F#（V度）→ B（I度 = トニック）と変化。異質だった ♭VII コードが回を追うごとに **ホームキーの成分** を吸収していく。歌詞がまさに「フレーバーに（フレーバーに）」— **和声が文字通り "味変" する**。しえりーほの和声設計力が凝縮された3小節。

### 3. G#（VI）ピカルディ借用 — GIRLS POWER の主張
ダイアトニック vi（G#m）を長三和音 G# に差し替え。増3度（B# = C♮）が加わることで、"GIRLS POWERは無限大" の歌詞に **明るく断定的な響き** を付与。chorusのD#m7→G#は iii→VI の平行長調化で、通常の iii→vi より華やか。

### 4. G → A（♭VI → ♭VII）— しえりーほ署名の断片
Post-chorus のみに出現する ♭VI → ♭VII のモーダル借用。CANDY POP と Summer land で確立された A→B→C→D クロマティック上行の **末尾2音を切り出した凝縮形**。ICE! ICE! の連呼の中に埋め込まれた暗号的署名。

### 5. B → A# → G# → F# 下行バスライン — "クリーミー" な導線
ヴァースの B → F#/A# → G#m → B/F# で、ベースが I から V へ4度かけてステップワイズ下行。滑らかで途切れない歩み = **アイスクリームのなめらかなテクスチャー**。

### 6. C# → D → D# 半音上行バス — 和声の "トッピング"
Pre-chorus の F#7sus4/C# → Bdim/D → B/D# で、ベースが半音ずつ上昇。Bdim は減三和音のパッシングコードで本来キーに属さない — **ちょっとだけ "禁断の味" を足すスプリンクル**。

### 7. 大歓声 → 大変身 → 大賛成 — リリックギミック
プレコーラスの終結が毎回「大＿＿＿」の異なる合成語で締まる。同一の和声フレーム（F#7sus4 → F#7 → G#sus4 → G#）の上で、**歌詞だけが "フレーバーチェンジ"** する構造。曲全体のアイスクリーム・メタファーが歌詞構造にまで浸透。

## Hey!Mommy! 楽曲群での位置づけ

### しえりーほ3部作の比較

| | CANDY POP | Summer land | ICE PARTY |
|---|-----------|-------------|-----------|
| Key | B | E | B |
| BPM | 170 | 155 | 137 |
| ♭VI→♭VII | A→B→C→D (full) | A→B→C→D (full) | G→A (abbreviated) |
| 特殊技法 | F#→G半音上行 | E→Eaug→E6内声 | AM7→A6→Aadd9変容 |
| テーマ食べ物 | キャンディ | 夏（間接） | アイスクリーム |
| 共通キー | B major | — | B major |

ICE PARTY は BPM が最も遅く（137）、しえりーほ作品群で唯一の **ミドルテンポ**。4連クロマティック上行の代わりに **♭VII の "味変"（AM7→A6→Aadd9）** という横展開を選択。同じ B major でも CANDY POP が "駆け抜ける甘さ" なら、ICE PARTY は **"味わう甘さ"**。

テンポを落として "味わう" 時間を確保したことで、内声クロマティック（B→BM7→B7）や ♭VII変容といった **微細な和声の色彩変化** が聴取可能になっている。しえりーほの作曲アプローチが "速度とエネルギー" から **"テクスチャーと味覚"** へ進化した一曲。
