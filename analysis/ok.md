# OK — 楽曲分析

BPM 125 のミドルテンポに、ラップの Verse とヘンドリクス・コードを抱えた AILI の自己肯定アンセムである。「わたしはわたしなの」と言い切る態度を、解決を拒む和音、顔を変えずに足元だけが歩くベース、二つの循環を交互に回すサビで組み立てた。かわいさではなく、格好良さで自分を肯定する一曲だ。

## ヘンドリクス・コードが解決を拒む — Dm9 と E7(#9) の往復

この曲の最大の聴きどころはプレサビだ。Dm9 と E7(#9) の 2 つの和音が、ほぼそれだけで往復し続ける。

```
Dm9 → E7(#9) → Dm9 → E7(#9) → Dm9    「怖くないの…」
E7(#9) → Em7/A → CM7                 「噛みつきたい…」
Dm9 → E7(#9) → Dm9 → E7(#9)          「寝ても覚めても…」
Dm9 → E7(#9) → Em7/A                 「ひとまず言わせて?…」「I say I say」
```

E7(#9) は Jimi Hendrix の「Purple Haze」（1967）で知られる、いわゆる**ヘンドリクス・コード**である。E-G#-B-D に #9 の G♮ を重ねた和音で、長 3 度の G# と、短 3 度と同じ音である G♮ が同時に鳴る。メジャーでもマイナーでもない第三の色だ。ロックの象徴のようなこの和音を、アイドルソングのプレサビに置く大胆さがまずある。

C major の中で E7 は Am（vi）への二次ドミナント（V7/vi）にあたり、本来なら Am に解決する「べき」和音だ。ところが E7(#9) は Am へ進まず、柔らかく開いた Dm9（ii9、D-F-A-C-E）へ戻ってしまう。解決を拒み続けるこの往復の上で歌われるのが「怖くないの 言わせない」「わたしはわたしなの」である。**カテゴリーに収まらない和音と、他人の定義を拒む言葉が一致している**。

往復を断ち切るのは Em7/A だ。A をベースに置いた Em7 で、機能としては A9sus4 に近い。ドミナントを持たないまま宙に浮く響きで「I say I say」を支え、そのままサビ頭の Am へ落ちる。ここで初めて、E7(#9) が向かうはずだった vi への到着が成立する。

## 顔を変えずに足元だけ歩く — ラップを支える Em の歩行バス

Verse はラップで、和声はさらに奇妙な作りになっている。

```
Em → Em/F → Em/G → Em → Em/F    （1 行ごとにループ）「それな！って…」
```

上声は Em の三和音（E-G-B）に固定されたまま、ベースだけが E→F→G と歩く。Em/F は F-E-G-B で実質 FM7 の響き、Em/G は G-E-G-B で実質 G6 の響きになる。つまり iii の「顔」を保ったまま、足元では IV、V の機能がほのめかされる二重構造だ。コードは変わらないのに和声の色だけがずれていく浮遊感が、ラップのフロウの下に敷かれている。この繊細な声部の動きは、125 というミドルテンポだからこそ聴き取れるものだろう。

ラップの言葉は攻撃的だ。1 番では「キラキラよりギラギラしてたい」と、アイドルソングの定番語である「キラキラ」を自ら退け、2 番では「ぶっ飛んでて何が悪い」「Bye エナジーバンパイア」と毒を強める。進行は 1 番と 2 番で変わらず、言葉だけが鋭くなる。

## 二つの 3 コード循環と、最後まで取っておいた vii°

「OK」を連呼するサビは、2 種類の 3 コード循環を交互に回す。

```
Am → G → C           「OK OK OK」
Dm → Em → F          「OK OK OK とりあえず…」
Am → G → Cadd9       「OK OK OK」
Dm → Em7 → FM7       「OK OK OK こみこみで…」
Am → G → Cadd9       「Ei E Ei 舞い上がれ」
F → G → Am9          「Ei E Ei 乗りこなせ」
```

奇数行は vi→V→I と下りながらトニックへ、偶数行は ii→iii→IV と 2 度ずつ上がる。同じ「OK」の反復に違う方向の和声が乗るので、同じ言葉でも少しずつ違う OK に聴こえる。2 回目以降は Cadd9、Em7、FM7 と和音に色が足されていく。

最後の行で着地先が変わる。「舞い上がれ」までは I に着地していたのが、「乗りこなせ」では F→G→Am9 と vi に降りる。Am9（A-C-E-G-B）の 9 度の B は、Intro の Ebaug に含まれる B と同じ音で、明るいサビの終わりに冒頭の暗い響きが一瞬よみがえる。

二つの循環で C major のダイアトニック和音 7 つのうち 6 つが出そろう。残る vii°（Bm♭5）は、サビでは使わずにブリッジまで温存されている。この計算については後で述べる。

## 楽曲を追う

### Intro

```
Em → Ebaug    （×2）
```

iii から ♭IIIaug へ。Em（E-G-B）から Ebaug（Eb-G-B）への動きは、G と B を保ったままルートだけが半音下がる、最小限の動きだ。それでいて完全 5 度が増 5 度に変わるので、浮遊と不安が同時に立ち上がる。Ebaug は異名同音で G augmented（G-B-D#）とも読める多義的な和音で、何かが始まる予感を作る。この 2 和音はブリッジ後にも戻ってきて、明るいサビを挟む暗い額縁になる。

### Verse（それな！って）

前述の Em の歩行バス。1 行ごとに Em→Em/F→Em/G→Em→Em/F がループする。

### プレサビ（怖くないの 言わせない）

前述の Dm9 と E7(#9) の往復。CM7（IM7）へ抜ける 2 行目を挟み、最後は Em7/A の宙吊りでサビへ渡す。

### サビ（OK OK OK）

前述の vi-V-I と ii-iii-IV の二重循環。最終行だけ vi9 に着地する。

### ブリッジ（自由になれ）

```
F → G → Am → Bm♭5 → C     「自由になれ 何度だって」
G/B → F                    「ラララ…」
G → Am → Bm♭5 → C → G/B    「叫べばいい 心の底から」
```

定番の IV→V→vi に、vii°→I の解決をつないだ形だ。Bm♭5（B-D-F）は C major のダイアトニックな減三和音で、ポップスでは省かれがちな影の和音である。その B が導音として半音上の C へ解決する。古典和声の終止そのものの動きを、「何度だって」「心の底から」という決意の言葉に充てている。サビで vii° を使わずに取っておいたのは、この瞬間のためだと聴こえる。

ベースも効いている。Am→Bm♭5→C→G/B と進むことで、A→B→C→B と順次に動くラインが生まれ、G/B（V の第 1 転回形）が余韻を残す。

### Intro 回帰〜Verse 2

ブリッジの直後、Em→Ebaug が戻り、サビの明るさから一気に Intro の暗いクロマティックへ引き戻される。続く Verse 2 は 1 番と同じ歩行バスで、ラップの内容だけがより攻撃的になる。

### プレサビ 2（傷付いたら）

1 番と同じ Dm9↔E7(#9) の往復で、歌詞は「秒で塞ぐわ」「強度上げて」と、自己防衛と自己肯定が表裏になった言葉に変わる。

### ラストサビ

通常のサビを 1 回歌ったあと「OK」を挟んでブリッジを再現し、Em→Ebaug を経てサビが再開する。再開後のサビは通常の 6 行に 2 行が加わり、Dm→Em7→FM7（乗りこなせ）、Am→G→Cadd9（舞い上がれ）と「舞い上がれ」と「乗りこなせ」の応酬が増えてから、F→G→Am9 で終わる。最後は vi9 の余韻の上に、単独の「OK」がひとつ浮かんで曲が閉じる。

## カタログの中で

コードの種類は 19 種に及ぶ。リリース時点では DIAMOND JET の 21 種に次ぐ多さで、のちに Hey!Yummy! が 35 種で大きく更新した。Em/F、Em/G の転回形、E7(#9) のテンション、Dm9・Am9・FM7・CM7 の 7th・9th が、テンションの豊かな和声を作っている。非ダイアトニックの和音として際立つのは E7(#9)、Ebaug、そして F をベースに置いた Em/F だ。

ヘンドリクス・コードについては、START RUSH!! にも経過的な E7#9/G# が現れ、のちに Hey!Yummy! が G7(#9) を Cm7（vi）へ正規に解決させている。セクションの核に据え、しかも解決させないという使い方は、本作ならではのものだ。ラップについても、SUMI-HAJI の語り、SCP! のラップの Cメロ、CANDY POP のラップ調の Aメロといった先例がある。OK では Verse を 2 回ともラップが担い、曲の性格そのものを決めている。

同じ AILI の自己肯定ソングであるご機嫌マミーはご機嫌ガールと並べると、対照がはっきりする。

ご機嫌マミーはご機嫌ガールが「かわいい自己肯定」なら、OK は「かっこいい自己肯定」である。Map A の x 座標は正反対の側に出る。一方で、どちらもコードの種類が多く、テンションを積極的に使う点は共通している。AILI は和声の語彙で曲を作るタイプの作家だ。その延長に、和音を削ぎ落とした Next Story（2025-12）が来るのが面白い。

1 週間前にリリースされた GALAXY! GALAXY! には「コタエはOK!」という一節があり、本作と呼応するように聴こえる。

## 総評

解決を拒むヘンドリクス・コード、iii の顔のまま歩くベース、vi と I を行き来するサビの着地、そして取っておいた vii° による決意の解決。どの仕掛けも「定義されることを拒み、自分で着地点を決める」という一点に向かっている。Hey!Mommy! の「かわいい＋パワフル」に、「かっこいい＋アティテュード」という新しい軸を加えた曲である。
