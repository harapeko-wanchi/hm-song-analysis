# HELLO!! Hey!! WORLD!! — 楽曲分析

ほぼ一つの和声進行だけで、Aメロもサビも Bメロも押し切ってしまうグループアンセムである。B→C#m→D#m→F# と一段ずつ登って最後に跳ぶ上行ウォークを延々と回し、色彩を添える和音は終盤の ♭VII と 7th の数小節だけに取っておく。聴きどころは、その一点豪華な和音が鳴る瞬間と、和音が消える沈黙だ。

## 一歩ずつ登って最後に跳ぶ、I-ii-iii-V の上行ウォーク

曲の背骨は B→C#m→D#m→F#、**I→ii→iii→V** の進行である。ルートは B→C#→D# と全音ずつ階段を登り、そこから短 3 度跳んで F# に至る。一歩ずつ登って、最後にジャンプする。冒険を歌う曲の身体感覚が、そのまま和声の動きになっている。

ポップスの定番である I-IV-V や I-V-vi-IV と違うのは、IV を飛ばして iii を通る点だ。iii の D#m は短三和音なので、I と V の長三和音が作る明るさの中に、ほんのわずかな翳りが差す。この翳りがあるから、同じ進行を何十小節も繰り返しても一本調子に聴こえない。

驚くべきは、この進行が Aメロ、サビ、Bメロのすべてで同じだということである。セクションを分けているのは和声ではなく、歌詞とメロディの表情だけだ。「子ども心で」という曲のテーマ宣言も、この同じ進行の上で歌われる。反復はやがてマントラのような性格を帯び、和声の単純さそのものが「子ども心の純粋さ」を体現する。

## ♭VII と沈黙 — 解決しない「僕らとキミとね」

ほぼダイアトニックで組まれたこの曲で、調の外にある和音は Cメロ・Dメロに現れる A だけである。

```
E → B/D#           「VERY GOODって…」
C#m → B
A → C#m/G#         「ぶっちょな…」
F# → B
A → N.C.           「僕らとキミとで」→「僕らとキミとね」
```

A は B major から見た **♭VII**、B ミクソリディアン（7 度を半音下げた旋法）からの借用和音だ。全音下の長三和音が、温かく、どこか懐かしい色を添える。「ぶっちょな」「グッピーなGO」といった脱力系の言葉と、♭VII の力の抜けた温もりがよく合う。

この Cメロは曲中でいちばん和声が動くセクションでもある。冒頭の E→B/D# は IV から I の第一転回形（3 度の D# をベースに置いた形）へ進み、ベースが E→D# と半音下がってなめらかにつながる。A の後の C#m/G# は ii の第二転回形で、G# のベースが vi（G#m）を暗示しながら ♭VII からの接続を滑らかにする。最後は F#→B の完全終止で一度着地する。

ところが、セクションの締めくくりでもう一度 A が鳴ると、今度はトニックに解決しないまま音楽が止まる。「僕らとキミとで」は ♭VII の上で歌われ、「僕らとキミとね」は無音の中に放たれる。理論的にはモーダルな終止の変形だが、効果はもっと情緒的だ。**解決しない和声が、終わらない関係を語っている**。完結ではなく、この先も続いていく。そのメッセージを、和音の不在が伝える。この構造は Cメロと Dメロの 2 回とも使われ、曲の感情的な錨になっている。

## 7th が鳴るのは、たった一度だけ

それまでトライアドだけで押してきた曲は、落ちパートで初めて 7th の和音を使う。

```
EM7 → F# → G#m7 → B/F#      「なんだかキュートに…」「単純な言葉と…」
```

IVM7→V→vi7→I/5th、つまり IV-V-vi-I を豊かにした形だ。IVM7 の夢見るような浮遊感、vi7 の切なさ、5 度をベースに置いた I の落ち着き。チャントの興奮が収まったところでこの和音が鳴り、「そばにいるよ」と歌われる。単純な言葉ほど温かい和音が必要になる、ということだろう。音の温度がここで一段上がることが、終盤の感情的なクライマックスを構造の面から支えている。

## 楽曲を追う

### Intro

```
B
```

トニック一発で開幕する。

### Hook / Interlude / Outro（oh oh oh）

```
B → C#m → F# → (B → F#)      「oh oh oh」
```

I→ii→V の 3 コードのループ。ii→V のドミナントの動きが繰り返されることで、終わらない高揚感が生まれる。Intro、Interlude、Outro に繰り返し現れ、曲の「枠」として機能する、開放的なチャントの器である。

### Aメロ（声 出した すぐさま NATTO）

```
B → C#m → D#m → F#    （×2）「声 出した…」
B → C#m → D#m
F# → B → C#m → D#m → F#      「Dancing in the CHUCHU…」
```

前述の I-ii-iii-V。「NATTO」「CHUCHU」と、意味より響きを優先した言葉が次々に乗る。

### サビ（ここが運命 出会い 一撃 夢中）

Aメロとまったく同じ進行。「プリプリ」「Dancing in the 超超」と、言葉とメロディの表情だけでサビに切り替える。

### Bメロ（子ども心（ここ ろ）で WA WAWAO）

同一進行がさらに続く。「子ども心で」というテーマ宣言はここで歌われる。

### Ready? セクション（どこか いこか あっち こっち）

```
B（トニックペダル）           「どこか いこか…」
B                             「あっち こっち…」
B → 1.2.3.GO
```

B のペダルポイント（同じベース音を保ち続ける手法）で和声は完全に静止し、ボーカルの掛け合いだけが動く。「どっち？ こっち！」のコール＆レスポンスが繰り返される間、エネルギーは動かない和声の下に圧縮され、「1.2.3.GO」のカウントで一気に解き放たれる。シンプルだが、ライブで沸かせるための仕掛けとしてよくできている。

### Cメロ（VERY GOODって 超 飛んでいこう）

前述の E→B/D#、C#m→B、A→C#m/G#、F#→B。最後は A→N.C. で止まる。

### Dメロ（HELLO! HELLO! WORLD! 夢みちゃお）

```
E → B/D# → C#m → B → A → C#m → F# → B      「HELLO! HELLO! WORLD!…」
A → N.C.                                     「僕らとキミとね」
```

Cメロとほぼ同じ構造で、「DON'T DON'T WORRY」「どんな未来も冒険しよう」と前を向く言葉が並ぶ。そして再び ♭VII から沈黙へ落ちる。

### Interlude 2 / 落ちパート（かわいい振り振り 楽しいから）

前述の EM7→F#→G#m7→B/F#。曲で唯一 7th の和音が鳴る区間で、「巨大なキラキラ」「そばにいるよ」「WE ARE WE ARE MAMAMA」が、この温かい和声に包まれる。

## カタログの中で

Hey!Mommy! には「グループアンセム」と呼べる曲の系譜がある。MAGNET が闘う決意の絆を、START RUSH!! が夢への全力疾走を歌うのに対し、本作のテーマは子ども心で世界とつながる喜びだ。キュートとクールがともに 5.1 で、どちらにも振り切らない中立的なアンセムといえる。

複雑さ 2.6 は、カタログ 36 曲の中で 7777777、もちぷる、CANDY POP、ICE PARTY に次いで 5 番目に低い。I→ii→iii の上行自体は、NNBS. の初期作ビスケットケースの Verse にも E→F#m→G#m→A として現れるが、あちらは iii から IV へ素直に進む。IV を飛ばして V へ跳ぶのが本作の独自性だ。翌月に出た同じ NNBS. の BIRD TRIP は I→V→II→iii と IV を排除した 4 コードで勝負しており、どちらも少ない和音で組みながら、アプローチは正反対である。

同じ B major で冒険を歌う AILI の Voyage! と比べても違いは鮮明だ。Voyage! が IV-vi-V-I と半音転調で大航海のスケール感を描くのに対し、本作は同じ進行の反復で、子ども心をそのまま差し出す。

## 総評

子ども心に複雑な和声はいらない。必要なのは「1.2.3.GO」のカウントと、みんなで叫ぶ「HELLO! HELLO! WORLD!」だけだ。上行ウォークの反復でセクションの区別さえ消し、♭VII と 7th の和音は「僕らとキミとね」と「そばにいるよ」の瞬間のためだけに取っておく。シンプルの中に一点だけ豪華な和音を置く設計が、この曲をただの明るいアンセム以上のものにしている。
