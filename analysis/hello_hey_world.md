## 構成とコード進行

### Intro
```
B
```
- トニック一発で開幕。

### Hook / Interlude / Outro（oh oh oh）
```
B → C#m → F# → (B → F#)    … I → ii → V
```
- 3コードの **I-ii-V ループ**。シンプルで開放的な「oh oh oh」チャントの器。
- ii → V のドミナントモーションが反復することで、終わらない高揚感を生む。
- Intro・Interlude・Outroで繰り返し現れ、曲の「枠」として機能。

### Aメロ（声 出した すぐさま NATTO）
```
B → C#m → D#m → F#    ×2    … I → ii → iii → V
B → C#m → D#m
F# → B → C#m → D#m → F#
```
- **I-ii-iii-V 上行ダイアトニックウォーク** — 曲の背骨。
- ルートが B → C# → D# と全音・全音で上行し、F# へ跳躍。「一歩ずつ登って最後に跳ぶ」動き。
- IV (E) を飛ばして iii (D#m) を経由する点がユニーク。D#m はマイナーコードなので、全体のメジャー感に薄い翳りを添え、一本調子を防いでいる。
- 「カラフル ベイベー フリフリ ベイベベイベ」「Hey! Hey! Hey!」「Dancing in the CHUCHU Hey! Mommy!」

### サビ（ここが運命 出会い 一撃 夢中）
```
B → C#m → D#m → F#    ×2    … I → ii → iii → V
B → C#m → D#m
F# → B → C#m → D#m → F#
```
- Aメロと同一進行。**同じ和声を歌詞とメロディの表情で差別化する構造**。
- 「カラフル プリ プリハンズアップ プリプリ」「Dancing in the 超超 Hey! Mommy!」
- 反復が曲のマントラ的性格を強化。

### Bメロ（子ども心（ここ ろ）で WA WAWAO）
```
B → C#m → D#m → F#    ×2    … I → ii → iii → V
B → C#m → D#m
F# → B → C#m → D#m → F#
```
- さらに同一進行が続く。「子ども心で」という曲のテーマ宣言がこの進行の上で歌われる。
- 「ニコちゃん ベイベー フリフリ ベイベベイベ」
- 「Dancing every body Hey! Mommy!」

### Ready? セクション（どこか いこか あっち こっち）
```
B（トニックペダル）
B
B → 1.2.3.GO
```
- **Bペダルポイント** — 和声が完全に静止し、ボーカルの掛け合いだけが動く。
- 「どこか いこか どこか いこか / あっち こっち どっち？ こっち！」のコール＆レスポンス。
- 和声的な静止がかえってテンションを蓄積し、「1.2.3.GO」のカウントダウンで一気に解放。ライブで最も盛り上がる仕掛け。

### Cメロ（VERY GOODって 超 飛んでいこう / HAPPY ROAD 楽しんでいこう）
```
E → B/D#                    … IV → I/3rd
C#m → B                     … ii → I
A → C#m/G#                  … ♭VII → ii
F# → B                      … V → I
```
- **曲中最も和声的に冒険するセクション。**
- **E → B/D#**：IV → I の第一転回形。ベースが E → D# と半音下行し、なめらかなヴォイスリーディング。開放的な IV の響きが「VERY GOODって」の高揚に合致。
- **A (♭VII)**：**Bミクソリディアンからの借用和音** — 曲中唯一のノンダイアトニックコード。全音下の A メジャーが温かく懐かしい色彩を添える。「ぶっちょな ぶっちゃな グッピーなGOで」の脱力系ワードと ♭VII の力の抜けた温もりがシンクロ。
- **C#m/G#**：ii の第二転回。G# ベースが vi (G#m) を暗示し、♭VII からの接続を滑らかに。
- **F# → B**：V → I の完全終止で着地。

### A → N.C.（僕らとキミとで → 僕らとキミとね）
```
A                            … ♭VII
N.C.                         … 沈黙
```
- **♭VII → 沈黙のモーダル終止** — 曲の最重要ポイント。
- A (♭VII) がトニック B に解決せず、そのまま音楽が止まる。「僕らとキミとで」のフレーズが ♭VII の上で歌われ、「僕らとキミとね」は無音の中に放たれる。
- **解決しない和声 = 終わらない関係**。「これは完結じゃない、続いていくんだ」というメッセージが、和声の不在によって語られる。
- 2回のCメロ/Dメロの両方でこの構造が使われ、曲の感情的アンカーとなっている。

### Dメロ（HELLO! HELLO! WORLD! 夢みちゃお / いけるよ DON'T DON'T WORRY）
```
E → B/D# → C#m → B → A → C#m → F# → B
```
- Cメロとほぼ同構造。「運命の出会いさ やったね」「LOVE YOUでLOVE YOUで 目が合うよね」。
- 「DON'T DON'T WORRY一緒 一緒踊ろう」「どんな未来も冒険しよう」「昨日よりも今日がMommyで」「これからも これからも ずっとずっと」
- 再び **A → N.C.** で「僕らとキミとね」。

### Interlude 2 / 落ちパート（かわいい振り振り 楽しいから）
```
EM7 → F# → G#m7 → B/F#     … IVM7 → V → vim7 → I/5th
```
- **曲中唯一の7thコードセクション。**
- それまでの raw なトライアド連打から一転、M7/m7 の温かいヴォイシングが初めて現れる。
- **IVM7 → V → vim7 → I/5th** は IV-V-vi-I のリッチ版。7th の付加が夢見心地の浮遊感を生む。
- チャントの興奮が収まった後、このセクションで：
  - 「なんだかキュートに わっちゃちゃしちゃう」
  - 「単純な言葉と 想い強く」
  - 「巨大なキラキラ 手を伸ばすよ」
  - 「すきなことは 繋いでいくよ」
  - 「どんなときでも めちゃくちゃしよう」
  - 「HELLO! HELLO! WORLD! そばにいるよ」
  - 「WE ARE WE ARE MAMAMA」
- **曲のエモーショナルコア**が、最も豊かな和声に包まれている。単純な言葉ほど、温かい和音が必要になる。

## 楽曲の特徴

### 1. I-ii-iii-V：跳躍する上行ウォーク
曲の大半を支配する B → C#m → D#m → F# (I-ii-iii-V) は、ポップスではかなり珍しいプログレッション。通常の I-IV-V-vi や I-V-vi-IV と異なり、IV を飛ばして iii をフィーチャーする。ルートが全音ステップで上行し、最後に短3度跳躍で V に至る動きは、「一歩ずつ階段を登って、最後にジャンプ！」という身体的な感覚を和声で実現。冒険テーマとの一致は見事。

### 2. D#m (iii) の存在感
iii コードがポップスの主要プログレッションにこれほど組み込まれるのは極めて稀。D#m はマイナーコードであり、I (B) と V (F#) のメジャーのハッピーの中で微かな翳りを落とす。この翳りが曲をただの「明るい曲」から「明るいけれど深みのある曲」に昇格させている。

### 3. ♭VII (A) — 唯一の色彩和音
33小節にわたる I-ii-iii-V / I-ii-V の反復の中で、A (♭VII) が現れる瞬間のインパクトは絶大。ミクソリディアンからの借用が、曲に「ここではないどこか」への憧れ ── ノスタルジーと冒険心の混合 ── を注入する。使用箇所がCメロ/Dメロの「ぶっちょな」「冒険しよう」に限定されているため、その効果は最大限に保たれている。

### 4. A → N.C.：沈黙で語る絆
♭VII → 無音は、楽曲理論的にはモーダル終止の変形だが、情感的にはもっと深い。トニックへの解決を拒み、沈黙の中に「僕らとキミとね」を残す構造は、**終わらない物語の暗示**。ライブではこの瞬間に客席が静まり、直後の楽器再開で爆発する — 構造そのものがライブ演出として機能。

### 5. EM7 → F# → G#m7 → B/F#：7thコードの特別枠
曲の99%がトライアドで構成される中、このセクションだけが7thヴォイシングを使う。この「音の暖かさの段差」が、曲終盤の感情的クライマックスを構造的に支えている。IVM7 の夢見心地、vim7 の切なさ、I/5th のペダル的安定感 — 言葉以上に「そばにいるよ」を伝えるアレンジ。

### 6. Bペダルの蓄積と解放
Ready? セクションのトニックペダルは、和声的変化を完全に排除することで「まだ動き出していない」緊張感を生む。「どこか いこか」の問いかけが反復する間、エネルギーはペダルポイントの下に圧縮され、「1.2.3.GO」で爆発的に放出。シンプルだが、ライブでの興奮設計として最適解。

### 7. ナンセンスワードの洪水
「NATTO」「CHUCHU」「WA WAWAO」「ぶっちょな」「ぶっちゃな」「グッピーなGO」「わっちゃちゃ」「MAMAMA」— 意味を超えた音の快楽。「子ども心で」というテーマ宣言の通り、言葉の意味ではなく音の響きで体を動かすことを求める楽曲設計。

## Hey!Mommy! 楽曲群での位置づけ

**HELLO!! Hey!! WORLD!!** は、Hey!Mommy! の「グループアンセム」ラインの中核。MAGNET が「闘う決意の絆」、START RUSH!! が「夢への全力疾走」を歌うのに対し、本曲は **「子ども心で世界と繋がる喜び」** をテーマとする。

Map A で x = 0.0（中央）は、cute にも cool にも振り切らない **ニュートラルなアンセム性** を示す。Hey!Baby! (x = −0.5) やSCP! (x = 0.5) とほぼ同じ「中央ポップ」エリアだが、y = 3.0 は7777777 (y = 3.5) に次ぐ高さで、ポップ度の極端な高さが際立つ。

Map B では Voyage! (2.0, 1.5) と同座標。両曲とも「子ども心×冒険」テーマだが、Voyage! が「大航海のスケール感」を IV-vi-V-I + 半音転調で描くのに対し、HELLO!! Hey!! WORLD!! は **I-ii-iii-V の同一進行を延々と反復することで「子ども心の純粋さ」を和声の単純さそのもので体現する** アプローチ。

和声的には曲群中で最もシンプルな部類だが、そのシンプルさこそがテーマと完全に一致している。子ども心に複雑な和声は要らない — 必要なのは「1.2.3.GO」のカウントと、みんなで叫ぶ「HELLO! HELLO! WORLD!」だけ。唯一の色彩和音 ♭VII (A) が「僕らとキミとね」の瞬間だけに現れる設計は、シンプルの中の一点豪華主義。
