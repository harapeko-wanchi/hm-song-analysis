# BIRD TRIP — 楽曲分析

Ab、Bb、Cm、Eb。この曲は、たった 4 つの根音だけで最初から最後まで書かれている。ポップスの土台であるはずの IV と vi を締め出し、着地する場所を持たないまま飛び続ける和声で、「飛べるのかな」と問いかける鳥の旅を描いた。聴きどころは、同じ 4 つの和音がサビと Verse で鏡のように逆順に並ぶ構造と、一度だけ規則が破られる「立ちたい景色を」の瞬間だ。

## IV のない旅 — 着地しない鳥

Ab major の曲なのに、IV の Db も、vi の Fm も一度も鳴らない。I-IV-V-vi というポップスの基本から IV と vi を抜き取った、極めて特殊な和声設計である。

IV は和声の「安息」や「帰還」を担う和音だ。それが一切ないので、この曲は**構造的に着地することができない**。BIRD TRIP という飛び続ける旅が、タイトルの段階で和声の設計に刻まれている。

vi の不在も意味を持つ。ふつうポップスで切なさを担うのは vi だが、ここではその役割を iii の Cm が引き受ける。iii は vi より根音が高く、切なさに「上を向く力」が混ざる。振り返る切なさではなく、夢を追う切なさだ。

そして II の位置には、ダイアトニックなら Bbm のところを、一貫して Bb の長三和音が置かれる。Bb は Eb（V）への二次ドミナント（V/V）で、V へ向かう引力を二重にする。V/V から V、V から I へとドミナントの連鎖が常に働くので、曲のエネルギーは絶えず前へ向かう。「STAY I WILL BE THERE」の確信は、この和声の前進力に支えられている。

## サビと Verse は鏡像 — 同じ 4 和音の逆再生

サビは Cm7→Bb6→AbM7→Eb、iii→II→I→V と並ぶ。Aメロからの Verse は Ab→Eb→Bb→Cm、I→V→II→iii と並ぶ。**同じ 4 つの和音が、ちょうど逆順になっている**。

```
Cm7 → Bb6 → AbM7 → Eb     サビ（iii → II → I → V）
Ab → Eb → Bb → Cm         Verse（I → V → II → iii）
```

サビが C、Bb、Ab と下ってから V へ跳ぶのに対し、Verse は根音が Ab から Eb へ、Eb から Bb へと 5 度ずつ上がり、最後に全音上の Cm へ着く。ポップスの進行は 5 度ずつ下がるのがふつうだが、ここでは真逆の方向に、上へ上へと積み上がる。飛翔のメタファーとして聴こえる動きだ。下りて跳ぶサビと、上って着く Verse。離陸と着陸、表と裏のように、4 コード縛りの中で最大の構造的な変化を引き出す知的な設計である。

## トライアドから 7th へ — ヴォイシングで変わる温度

Intro のトライアドの循環と、サビの循環は、根音がまったく同じだ。違うのは、サビで 7th や 6th が加わること。Cm7 の切なさ、Bb6 の浮遊感、AbM7 の夢見心地が、トライアドにはない温かみと奥行きを生み、「浮かぶ 星と信じ あえた」の世界を包む。

根音の選び方ではなく、ヴォイシングの工夫だけで、同じ和声にまったく別の感情を持たせる。最小限の素材から最大限の感情の幅を引き出す、NNBS. の真骨頂といえる。

## 楽曲を追う

### Intro / Interlude

```
Cm → Bb → Ab → Eb         （iii → II → I → V）
```

トライアドの 4 コードの循環。iii から C、Bb、Ab と下行し、V へ跳ぶ。「oh oh oh」のチャントの器で、曲の始まりも終わりもこの循環になる。

### サビ（浮かぶ 星と信じ あえた）

```
Cm7 → Bb6 → AbM7 → Eb     （×8）「浮かぶ 星と信じ あえた」…「飛べるのかな」
```

Intro と同じ根音に 7th と 6th を足した循環を 8 回。「あの日よりもこの道を」から「輝く夢の場所へ」「飛べるのかな」まで、問いかけで閉じる歌詞をつむいでいく。

### Aメロ（ここが ずっと超超 良き良きだね）

```
Ab → Eb → Bb → Cm         （×2）
```

前述のサビの逆順。上行 5 度の連鎖で、上へ向かって飛び立つ。

### Bメロ（言葉 ずっと ココロ ずっと）

```
Ab → Eb → Bb → Cm         （×2）「LET'S LET'S PUNKY LET'S LET'S CHU PUNKY」…
```

Aメロと同じ進行に、「LET'S LET'S PUNKY」のフックが乗る。「キミと僕で みにいこう」と、約束の場所へ誘う。

### Cメロ（STAY I WILL BE THERE）

```
Ab → Eb → Bb → Cm         （×2）
```

さらに同じ進行。「自分で自分を誇れたら」と歌うこのセクションで、同じ和声の反復はマントラのように働き、「STAY I WILL BE THERE」の宣言を強める。

### Dパート（ひとりに しないよ）

```
Ab → Eb → Bb → Ebadd9     「ひとりにしないよ」…「立ちたい景色を」
```

曲中で唯一、和声が変わる場所である。いつもの Cm が Ebadd9 に置き換わる。add9 の F の音を含んだ V の和音は、着地すべき iii に届かずに浮遊する。4 コード循環という全曲の規則が、ここでだけ破られる。**規則が破られることで、「まだ到達していない」ことを和声が告白する**。まだ見ぬ場所への焦がれが、和声の不解決に宿る。「立ちたい景色を」のためだけに存在する和音だ。

2 回目の Dパートでは Cm に戻り、「言葉 響かせる」と歌う。覚悟が和声の着地を取り戻す。

### Bメロ 2nd（ヤホ JUMP LET'S 1.2.1.2 GO カモカモ）

```
Ab → Eb → Bb → Cm         （×2）「ヤホ JUMP LET'S…」「LET'S DANCE DANCE HAPPY WORLD」…
```

「カモカモ」「ヤホ」と NNBS. らしいナンセンスワードが、上行 5 度の推進力に乗る。「冒険にさぁ身を任せて」と、旅はさらに先へ進む。

### Dメロ（I WILL BE THERE）

```
Ab → Eb → Bb → Cm         （×2）「自分のこと信じて」「STAY GOLD I WILL BE THERE」…
```

同じ進行の上で、「STAY GOLD」の宣言が重なる。

### ブリッジ（あの場所が 遠く見えて）

```
Cm7 → Bb6 → AbM7 → Eb     （×2）「あの場所が 遠く見えて」…「自由に強がるよ」
```

サビと同じ 7th のヴォイシング。「何度も小さくつまづいて」という挫折と立ち上がりを、サビの和声で歌う。夢の場所への道のりそのものが、サビと同じ感情なのだと示している。

### Pre-final〜Final Chorus（星 と歌と）

```
Eb → Bb                   「星と歌と 夢と信じ あえた」
Cm7 → Bb6 → AbM7 → Eb     （×8）
```

V と II の 2 コードでつなぎ、そのまま最後のサビへ。8 回の循環で全編の歌詞を回収する、曲の集大成だ。

### Outro（声を聞かせてよ 僕らと）

```
Cm → Bb → Ab → Eb         （×2）「声を聞かせてよ 僕らと」「多分 それがきっと 羽になる」
```

Intro と同じトライアドの循環に戻る。ファンの声が羽になり、鳥が飛べる。NNBS. が Hey!Mommy! とファンの関係を最もストレートに言葉にした一節で、アイドルソングとしての核心だ。循環は止まらないまま、曲は消えていく。この旅は終わらない。鳥は着地しない。

## カタログの中で

1 か月前に出た NNBS. の HELLO!! Hey!! WORLD!!（B major）と並べると面白い。どちらも 4 つほどの和音の中で勝負する曲だが、アプローチは正反対だ。HELLO!! Hey!! WORLD!! は I-ii-iii-V の上行ウォークを反復し、♭VII を一点だけ差して彩る。BIRD TRIP は I-V-II-iii の上行 5 度で進み、IV を締め出すという構造的な禁欲を貫く。HELLO!! Hey!! WORLD!! が「世界に HELLO」とドアを開ける曲なら、BIRD TRIP は「飛べるのかな」と翼を広げて空に問いかける曲である。

Map A では SCP! のすぐ近くに位置する。どちらも夢、仲間、冒険をテーマにする曲だが、SCP! が疾走してスターを目指す攻めの姿勢なのに対し、BIRD TRIP は問いながら飛び続ける揺れる確信を描く。子供心 4.1 は SCP! の 4.7 よりも低い。ナンセンスワードは豊富でも、「何度もつまづいて」の経験が、少し大人寄りのニュアンスを添えているのだろう。ハッピー 4.1 は NNBS. の 21 曲の中で最も低く、エモ 6.3 がそれを上回る。明るい言葉遊びの多い作家の作品群にあって、本作は切なさの側に重心を置いた一曲だ。

## 総評

4 つの根音、IV と vi の不在、鏡像の構造、そして一度だけの Ebadd9。制約をここまで厳しく課しながら、それをテーマの表現にまで昇華している。着地する和音を持たないから、鳥は飛び続けるしかない。その和声の宿命が、「声を聞かせてよ」とファンに呼びかけ、声を羽にして飛ぼうとする歌詞と一つになる。NNBS. の作品の中でも、構造と言葉が最も深く結びついた曲の一つである。
