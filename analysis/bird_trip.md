## 構成とコード進行

### 全体構造 — 4コード完結

曲の全体が **Ab, Bb, Cm, Eb の4つのコードルートだけ** で構成される。IV (Db) も vi (Fm) も一切登場しない。ポップスの基本 I-IV-V-vi から IV と vi を排除した、極めて特殊な和声設計。

### Intro / Interlude / Outro
```
Cm → Bb → Ab → Eb        … iii → II → I → V
```
- トライアドの4コード循環。iii から下行し (C→Bb→Ab)、V へ跳躍。
- oh oh oh チャントの器。曲の始まりも終わりもこの循環。

### サビ（浮かぶ 星と信じ あえた）
```
Cm7 → Bb6 → AbM7 → Eb    ×8    … iiim7 → II6 → IM7 → V
```
- Intro と **同じ4コード** だが、**7th/6th のエクステンションが付加**。
- Cm7 の切なさ、Bb6 の浮遊感、AbM7 の夢見心地 — トライアドにはない温かみと奥行きが「浮かぶ 星と信じ あえた」の世界を包む。
- 8回の循環で「あの日よりもこの道を / 今もずっとここで歌って / 追いかけるよこの想いを / 大きくてきれいな / 心もって / 輝く夢の場所へ / 飛べるのかな」を紡ぐ。

### Aメロ（ここが ずっと超超 良き良きだね）
```
Ab → Eb → Bb → Cm    ×2    … I → V → II → iii
```
- **サビの逆順**。サビが iii→II→I→V ならヴァースは I→V→II→iii。**構造的レトログラード。**
- ルート Ab→Eb (5度上)→Bb (5度上)→Cm (全音上) = **上行5度の連鎖**。
- 通常のポップス (下行5度が主流) とは真逆の方向。上へ上へ飛ぶ運動 — 飛翔のメタファー。

### Bメロ（言葉 ずっと ココロ ずっと / LET'S LET'S PUNKY）
```
Ab → Eb → Bb → Cm    ×2    … I → V → II → iii
```
- Aメロと同一進行。「LET'S LET'S PUNKY LET'S LET'S CHU PUNKY」のフックが載る。
- 「キミと僕で みにいこう / あの日描いた約束を」

### Cメロ（STAY I WILL BE THERE）
```
Ab → Eb → Bb → Cm    ×2    … I → V → II → iii
```
- さらに同一進行。「自分で自分を誇れたら」「今よりも輝けてるから」
- 同じ和声の反復が**マントラ**のように機能し、「STAY I WILL BE THERE」の宣言を強化。

### Dパート（ひとりに しないよ）
```
Ab → Eb → Bb → Ebadd9
```
- **曲中唯一の和声変化**。最後の Cm が **Ebadd9** に置き換わる。
- add9 (F音) が加わった V 和音は、着地すべき iii (Cm) に到達せず浮遊する。
- 「立ちたい景色を」— まだ見ぬ場所への焦がれが、和声の不解決に宿る。
- 2回目のDパートでは Cm に戻り「言葉 響かせる」— 覚悟が和声の着地を取り戻す。

### Bメロ 2nd（ヤホ JUMP LET'S 1.2.1.2 GO カモカモ）
```
Ab → Eb → Bb → Cm    ×2    … I → V → II → iii
```
- 「LET'S DANCE DANCE HAPPY WORLD」「素敵が聞こえてくる」「冒険にさぁ身を任せて」
- NNBS. 特有のナンセンスワード洪水（カモカモ、ヤホ）が上行5度の推進力に乗る。

### Dメロ（I WILL BE THERE / STAY GOLD I WILL BE THERE）
```
Ab → Eb → Bb → Cm    ×2    … I → V → II → iii
```
- 「自分のこと信じて」「STAY GOLD I WILL BE THERE」「踊っていこうよ ね」

### ブリッジ（あの場所が 遠く見えて）
```
Cm7 → Bb6 → AbM7 → Eb    ×2
```
- サビと同じエクステンデッド・ヴォイシング。
- 「何度も小さくつまづいて / けどなんかキラキラな手 / 自由に強がるよ」
- 挫折と立ち上がりをサビの和声で歌うことで、「夢の場所」への道のり自体がサビの感情なのだと示す。

### Pre-final（星 と歌と）
```
Eb → Bb
```
- V → II の2コードで「星と歌と 夢と信じ あえた」のブリッジ。
- そのまま最終サビへ突入。

### Final Chorus（Cm7 → Bb6 → AbM7 → Eb ×8）
- 全楽曲の集大成。8循環で全歌詞を回収。

### Outro（声を聞かせてよ 僕らと）
```
Cm → Bb → Ab → Eb    ×2
```
- Intro と完全同一のトライアド循環に戻る。
- 「声を聞かせてよ 僕らと / 多分 それがきっと 羽になる」
- **「ファンの声が翼になる」** — アイドルソングとしての究極の宣言。循環が止まらないまま曲が消えていく。鳥は着地しない。

## 楽曲の特徴

### 1. IV (Db) の不在 ── 着地しない鳥
ポップスの基本機能和音 I-IV-V から、サブドミナント IV が完全に排除されている。IV は和声の「安息」「帰還」を象徴する和音であり、それが一切ないことで曲は **構造的に着地できない**。BIRD TRIP = 飛び続ける旅。タイトルが和声設計に刻印されている。

### 2. vi (Fm) の不在 ── Cm (iii) が代理
通常ポップスで「切なさ」を担う vi (Fm) も不在。代わりに iii (Cm) がその役割を負う。iii は vi より根音が高く、切なさに「上を向く力」が混ざる。夢を追う切なさは、振り返る切なさとは違う。

### 3. Bb (II = V/V) ── サブドミナント位置の「推進エンジン」
ダイアトニックなら Bbm (ii) のところを一貫して Bb メジャー。V/V として Eb (V) への指向性を二重にする。V/V → V → I のドミナント連鎖が常に機能し、曲のエネルギーは絶えず **前方へ** 向かう。「STAY I WILL BE THERE」の確信はこの和声の前進力に支えられている。

### 4. 構造的レトログラード ── サビとヴァースの鏡像
- サビ: **iii → II → I → V** (Cm → Bb → Ab → Eb)
- ヴァース: **I → V → II → iii** (Ab → Eb → Bb → Cm)

同じ4和音が逆順で並ぶ鏡像構造。サビが「下行して V で跳ぶ」ならヴァースは「上行して iii に着く」。朝と夜、離陸と着陸、表と裏 — 4コード縛りの中で最大の構造的変化を生み出す知的な設計。

### 5. エクステンションの「温度差」
トライアド (Intro/Verse) がエクステンデッド (Chorus) になるだけで、同じ和声がまったく別の感情を持つ。M7 の夢見心地、6th の浮遊感は、ルート音の選び方ではなくヴォイシングの工夫で実現される。最小限の素材から最大限の感情幅を引き出すNNBS. の真骨頂。

### 6. Ebadd9 ── 唯一の割れ目
全曲の律則（4コード循環）の中で唯一の逸脱。Cm → Ebadd9 の置き換えは、**規則が破られることで「まだ到達していない」ことを和声的に告白する** 瞬間。「立ちたい景色を」のためだけに存在する和音。

### 7. 「声を聞かせてよ 僕らと 多分 それがきっと 羽になる」
アイドルソングの核心。ファンの声が羽になって鳥が飛べる — NNBS. が Hey!Mommy! とファンの関係を最もストレートに和声化した一節。Outro の循環が止まらないまま消えていくのは、「この旅は終わらない」という宣言。

## Hey!Mommy! 楽曲群での位置づけ

**BIRD TRIP** は、NNBS. 作品群の中で **最も和声的に制約された曲** （4コード完結）であり、同時に **最もメタフォリカルな構造** を持つ。

Map A で SCP! (0.5, 1.5) の近傍に位置し、両曲とも「夢・仲間・冒険」テーマだが、性格は異なる。SCP! は「疾走してスターを目指す」攻めの姿勢、BIRD TRIP は「飛べるのかな」と問いながら飛び続ける **揺れる確信** を描く。

Map B では SCP! (1.5, 2.0)、Voyage! (2.0, 1.5) の近傍。3曲とも NNBS./AILI の「子供心×パワフル」ラインだが、BIRD TRIP は childlike のスコアが最も低い — ナンセンスワードは豊富だが、「何度もつまづいて」の経験値がやや大人寄りのニュアンスを添えている。

HELLO!! Hey!! WORLD!! (同じく NNBS.、B major 4コード中心) との対比が面白い。HHW が **I-ii-iii-V の上行ウォーク + ♭VII の一点豪華** なら、BIRD TRIP は **I-V-II-iii の上行5度 + IV排除の構造的禁欲**。どちらも4コードの中で勝負するが、そのアプローチは正反対。HHW が「世界にHELLO」とドアを開ける曲なら、BIRD TRIP は「飛べるのかな」と翼を広げて空に問いかける曲。
