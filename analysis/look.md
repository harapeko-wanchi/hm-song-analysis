# LOOK!! — 楽曲分析

山崎あおいが書き、鶴﨑輝一が編曲したこの曲は、「Look me!! Look me!!」と自分を見ろと突きつける、クールな自己肯定のシンセポップである。BPM 125 とカタログでも遅い部類のテンポで、急がず、堂々と歩く。全編を貫く A→A7/G のリフと、要所で一瞬だけ差す Dm の影が聴きどころだ。

## A → A7/G — ランウェイを歩くリフ

曲の背骨は、イントロから鳴る A→A7/G→A のリフである。

```
A → A7/G → A      （リフの繰り返し）
A → A7/G → A      「根拠のない確信は天性」
A → A7/G → A      「でもだってステキでしょね?」
```

主和音の A に 7 度の G を加え、その G をベースに置く。ベースが A から G へ全音下がって戻るだけの動きだが、属七の響きが加わることで、トニックに居座りながらも前へ進む推進力が生まれる。和音を大きく動かさず、ひとつの場所で胸を張り続ける。**「根拠のない確信は天性」と言い切る歌詞**に、これほど似合う伴奏はない。リフはプレサビの「I'm a STAR!!」でも鳴り、最後は「ド真ん中です！」の E→A→A7/G→A で曲を締める。ブリッジでは A→A7→A と、ベースを動かさない形に変わって現れる。

## 自信に一瞬だけ差す Dm の影

全体は明るく開放的な A major だが、要所で Dm が顔を出す。

```
Bm     「…That's alright」
Dm     「まあきっとナンとかなんじゃない?」
E      「ためらわないで」
```

Dm は A major の IV である D を短三和音にしたもので、同主調の A minor から借りた和音（モーダル・インターチェンジ）だ。D の第 3 音 F# が F に半音下がるだけで、明るい自信に一瞬の陰りが差す。「ナンとかなんじゃない?」と楽観を口にする瞬間、和音は少しだけ不安を漏らしているわけだ。サビの「よそ見しないで」でも Dadd9→Dm と同じ借用が使われ、「私だけ見て」という強気の裏にある、見てもらえないことへの怖れをほのめかす。

プレサビにも同じ発想の陰影がある。

```
D → A                         「無敵なモードで…」
Am → Amadd9 → Am → Am7        「誰も惑う魅力…」
D/A → Dm/A → A                「知らぬうちにハマる」
```

ここでは主和音そのものが Am に替わり、add9 の浮遊感をまといながら揺れる。D/A→Dm/A→A では、A のペダルの上で D が Dm に翳り、また A の光に戻る。

## 楽曲を追う

### Intro

前述の A→A7/G→A のリフ。

### Aメロ（根拠のない確信は天性）

イントロと同じリフの上で、自己肯定の言葉が始まる。

### プレサビ（無敵なモードで）

前述の Am と Dm/A の陰影を経て、「控えめなフリして…」の D から、「I'm a STAR!!」の A→A7/G→A→A7/G へ戻る。

### サビ A（手の中夢が光ってる）

```
Bm7 → Eadd9      「手の中夢が光ってる」
AM7 → DM7        「いくつ叶えられるかな」
Bm               「…That's alright」
Dm               「まあきっと…」
E                「ためらわないで」
```

ii7→Vadd9→IM7→IVM7 と、メジャー 7th と add9 の和音を連ねる。どれも洗練された、都会的な響きの和音だ。Eadd9 の 9 度がタグにもある「add9 の爽やかさ」を担う。そこから前述の Dm の影を経て、E（V）で次へ渡す。

### サビ B（Look me!! Look me!!）

```
A → A/C#          「Look me!! Look me!!…」
Dadd9 → Dm        「ちょっとちょっと…」
A → E/G#          「涙コンプレックス」
F#m → E → D       「さえも武器にTry」
E                 「負ける気しないね」
```

A→A/C# でベースが A から C# へ上がり、E/G# が経過のベースとして F#m へ滑らかにつなぐ。Dadd9→Dm の借用がここにもある。2 回目は「最上級のイメージで」「困難もエンジンに」と言葉を替え、最後は「ここがド真ん中です」で E に止まる。

### ブリッジ（保障のない未来も歓迎）

```
A → A7 → A        「保障のない未来も歓迎」
D → A             「油断してたら…」
Am                「だめだって良いじゃない…」
D → A             「楽しめたらSo Good!!」
```

リフが A→A7→A の形に変わり、「本気って楽しいでしょね?」と前向きな言葉が続く。ここでも Am の一瞬の翳りを挟んで、「So Good!!」で A に戻る。

### 2 番サビ A〜サビ B

サビ A は「心にいつもあこがれ」で同じ進行を繰り返し、「怖がらないで」の E へ。サビ B も同じ構成である。

### It's me!! セクション

```
A → A/C#          「It's me!! It's me!!…」
Dadd9 → Dm        「まだまだ10%も知らない?」
A → E/G#          「最大のパワーで」
F#m → E → D       「私なりの正解」
E                 「探してゆくのです」
```

サビ B と同じ進行の上で、「Look me!!」が「It's me!!」に替わる。他人に見てもらう歌から、自分で自分を探す歌へ。和声を変えずに、主語の向きだけを変えている。

### 間奏

```
D → C# → F#m7 (×3) → Bm7 → Bm7/E
F#m11 → D → D/E (×3) → F#m11 → F#m7/E → D → A
```

D→C#→F#m7 は、vi への二次ドミナントの C# を経て F#m7 に落ちる動き。F#m11 の 11 度がジャジーなテンションを添え、D/E や Bm7/E のようにベースだけを E に置いた和音が、解決を先延ばしにしながら最後のサビへの助走をつける。

### ラストサビ

サビ B と同じ構成で、最後は E→A→A7/G→A。「ド真ん中です！」で冒頭のリフに帰って幕を閉じる。

## カタログの中で

山崎あおいがカタログに提供したのは、SUMI-HAJI（2021）と本作の 2 曲で、いずれも初期の作品だ。SUMI-HAJI が F minor でテンションコードを多用し、若さの痛みを描いたのに対し、本作は A major で痛みすら武器に変えてみせる。BPM は 128 と 125 でほぼ同じ、クールも 7.4 と 7.1 で近い。同じ作家、同じテンポ帯で、マイナーの焦燥とメジャーの自信という表裏を書き分けた格好である。

BPM 125 は OK と並んでカタログで 3 番目に遅く、疾走感 1.8 も Tickey Luppy Doo、OK に次いで低い。一方でクール 7.1 と、お祭り感 2.3 は、沸かせるよりも見せつけるタイプの曲であることを示している。速さで煽るのではなく、遅いテンポの余裕で煽る。「ドヤ感」というタグがふさわしい。

## 総評

ひとつの和音に居座る A→A7/G のリフで揺るぎない自信を描き、借用の Dm でその裏にある一瞬の陰りを覗かせる。それでも曲は必ず A の光に戻り、「ド真ん中です」と言い切って終わる。痛みも不安も否定せず、全部抱えたまま主役の座に立つ。Hey!Mommy! の初期を代表する、セルフプロデュースの宣言のような一曲である。
