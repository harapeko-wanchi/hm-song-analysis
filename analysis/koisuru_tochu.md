# 恋するとちゅう — 楽曲分析

バレンタインデーに届けられた胸きゅんのラブソングは、見た目のキュートさに反して、意外なほど凝った和声を持つ。ヴァースの Ab major からサビで属調の Eb major へ移り、間奏ではさらに F major へ踏み込む。恋が進むにつれて居場所そのものが移っていく、その調の旅路が聴きどころだ。

## Ab から Eb へ — 恋の進展を調の移動で描く

ヴァースは Ab major、サビは Eb major。曲の中心にあるのは、この**属調（5 度上の調）への転調**である。

転調の準備は Cメロの終わりで行われる。

```
Db → DbM7 → Db7 → Gb       「ちょいおこらせた時も…」
Gb → Fm → Bb               「すぐゴメンね言えなくて…」
Eb → Ab → Bb → Eb Eb7      「いつもよりカワイク なれちゃうよ」
```

Bメロと同じ出だしから、後半で Eb→Ab→Bb→Eb→Eb7 に展開する。「いつもよりカワイク なれちゃうよ」で Eb7 が鳴ると、その V7 一発で調の重心が Ab から Eb へずれる。続くフックの Ab→Bb→Eb→Cm は、Eb major の IV→V→I→vi。転調の完了を宣言する、明快な進行だ。

曲は間奏 1 で一度 Ab major に戻るが、ラストサビは再び Eb major で歌われ、アウトロも Eb に着地する。始まりの Ab から、最後は Eb へ。恋の始まりから関係の深まりまでを、**居場所が移るという調性の構造で表現している**のである。

## 根音を保ったまま 7 度が降りる、移調される動機

この曲には、形を変えずに二度現れる和声の動機がある。

```
Db → DbM7 → Db7 → Gb       （Bメロ）「小さいボクの世界で…」
Eb → EbM7 → Eb7 → Ab       （ブリッジ）「ずっと探してた…」
```

Bメロの Db→DbM7→Db7 は、根音 Db を保ったまま、上で鳴る音が Db→C→Cb と半音ずつ降りていく。長 7 度が短 7 度に下がる瞬間に切なさが滲み、Db7 は Gb（♭VII）への二次ドミナント（V7/♭VII）として解決する。

ブリッジでは、これがそのまま全音上に移されて Eb→EbM7→Eb7→Ab となる。今度は Eb→D→Db と降りて、Ab へ解決する。同じ動機を異なる調で再利用する手つきは、作曲としての統一感を生むと同時に、「ずっと探してた」という歌詞に、Bメロで芽生えた気持ちの続きであるという響きを与える。

Bメロにはもうひとつ、Bb の仕掛けがある。Ab major のダイアトニックなら Bbm になる ii を長三和音にした II で、V への二次ドミナント（V/V）として働く。「想いは伝えられないけど」の「けど」で鳴る Bb が、控えめな決意をそっと押し出す。

## 三つ目の調と、要所で光る長三和音

2 番の後の間奏 2 で、曲は三つ目の調へ踏み込む。

```
Bb → F → Dm → C       （×4）
Gm → Am → Bb
```

Bb→F→Dm→C は F major の IV→I→vi→V。Ab から属調の Eb へ、そこからさらに全音上の F へと、調は上へ上へと移っていく。最後の Gm→Am→Bb は ii→iii→IV の上行で、次のブリッジへなめらかに橋を架ける。

Eb major の中でも、長三和音のすり替えが要所で光を差す。フックの最後で Cm（vi）の代わりに鳴る C は、トニック Eb と短 3 度離れた長三和音、いわゆるクロマティック・メディアントだ。「MAKE IT MAKE IT」のビルドアップに輝きと推進力を与え、サビの「ボクの知らないナニか」でも再び現れる。

## 楽曲を追う

### Intro

```
Gb → Ab
```

♭VII→I のシンプルな導入。ミクソリディアン（7 度を半音下げた旋法）の色を冒頭から示す。

### Aメロ（ここでクルクル巻いて）

```
Gb → Fm         「ここでクルクル巻いて…」
Bbm → Db        「ピンでとめてOK…」
Gb → Fm         「チクタクチクタク…」
Ebm → Ab        「さぁでかけよう 会えたらいいな」
```

♭VII→vi→ii→IV→♭VII→vi→v→I。Gb を多用する Ab ミクソリディアン風の枠組みに、同主調 Ab minor から借りた Ebm（v）が加わり、I への解決に柔らかな陰りを添える。身支度に焦る「今日もヒールは無理」という等身大の描写が、ここで歌われる。

### Bメロ（小さいボクの世界で）

```
Db → DbM7 → Db7 → Gb    「小さいボクの世界で…」
Gb → Fm → Bb            「やっとキミを見つけたんだ…」
Ebm → Ab
```

前述の内声下行と、二次ドミナントの Bb。

### Cメロ（ちょいおこらせた時も）

前述のとおり、Eb7 で Eb major への転調を準備する。

### フック（NA NA NA / POOGIE POOGIE）

```
Ab → Bb → Eb → Cm    （×2）「NA NA NA…」「わちゃわちゃ…」
Ab → Bb → Eb → C     「MAKE IT MAKE IT…」
```

Eb major の IV→V→I→vi。「わちゃわちゃ」「POOGIE」という無邪気なコールが乗り、最後の C で輝きを増して、「いちばんスキはキミにキミにキミに」から Ab→Bb→Eb へ着地する。

### サビ（恋してる世界が 続くように Hey!）

```
Eb → Gm → Cm → Eb7       「恋してる世界が…」
Ab → Gm / F → Bb
Eb → Gm → Cm → Eb7
Ab → Gm → C              「ボクの知らないナニか…」
Fm → Bb → Eb → Eb7       「キミとみつけたいんだ」
Fm → Bb → Eb → Eb7       「キミにトキメキなんだ」
Ab → Bb
Eb                       「恋してみたいな」
```

I→iii→vi→I7 から IV→iii、II→V へ。Eb7（I7）はトニックに 7 度を足して IV への二次ドミナント（V7/IV）に変えたもので、I に着いた瞬間に次への緊張を作り出す、サビの推進エンジンだ。F（II）は V/V として Bb へ力強く解決する。後半の Fm→Bb→Eb→Eb7 は ii→V→I→I7、ジャズ的な解決で、「みつけたいんだ」「トキメキなんだ」と韻を踏んだ核心の 2 行を支える。最後は「ほんとはちょっと キミとなら」から「恋してみたいな」へ、控えめな告白で柔らかく着地する。

### 間奏 1

```
Gb Ab Bbm Db | Gb Ab Db Gb Ab
```

Aメロの素材を使って Ab major に戻る。

### 2 番（小さなことでちょっぴり）

Aメロからサビまで 1 番と同じ進行。サビの歌詞は「恋してる世界が 広がるように」に変わり、最後は Eb→Ebsus4 から「恋してみたい NA NA NA」へ。

### 間奏 2

前述の F major の IV-I-vi-V と、ii-iii-IV の上行。

### ブリッジ（ずっと夢中を ラララ）

```
C
Eb → EbM7 → Eb7 → Ab     「ずっと探してた…」
Ab → Gm                  「昨日よりも 今日よりも…」
F → Bb                   「明日はオモシロイかな」
```

前述の移調された動機。2 回目は「明日はピカピカ」と明るく解決し、Eb→Ebadd9 の add9 で余韻を残す。

### ラストサビ（おおきな夢と ボクらをつなぐ Hey! BABY）

```
Eb → Gm → Cm → Eb7
Ab → Gm / F → Bb
```

サビと同じ進行で、「叶えるために歌うのさ」「世界が広がるように」とスケールを広げた歌詞が歌われる。

### アウトロ（ほんとはずっと ずっとずっと ね）

```
Ab → Bb → Eb → Adim → Ab → Eb7
Eb                       「一緒にいたいな」
```

Adim は経過的な減三和音である。構成音 A-C-Eb は、Ab の三和音（Ab-C-Eb）の根音だけを半音上げたもので、最小限の動きで一瞬の緊張と解放を作る。半音の揺れが「ずっとずっと」の切なさを凝縮し、「一緒にいたいな」の本音とともに Eb に着地する。

## カタログの中で

キュート 7.4 はカタログ 5 位。上位 5 曲の中でエモが 6.8 と突出して高く、かわいさと切なさを同時に抱えた曲であることが分かる。Map A ではかわいい側かつ聴かせる側にあり、同じ象限に置かれた LOVE ME DO DO とともに、NNBS. の恋の歌を代表する一曲だ。

転調の多さでは、先に出た START RUSH!!（Ab から C への長 3 度上の転調などを含む）と並ぶ。根音を保って 7 度を降ろす動きは、後に しえりーほ の ICE PARTY でも B→BM7→B7 として現れるが、一つの曲の中で調を変えて再現している点は本作ならではだ。7777777 のサビに隠れた全音階の下行も、この内声下行を大きく広げたものと聴ける。

「POOGIE」は、ビスケットケースの「パクパク」や CANDY POP の「ラタタ」に連なる、Hey!Mommy! の造語コールの系譜に属する。意味が分からないからこそキュートで、ライブでの一体感を生む言葉だ。

## 総評

ミクソリディアンの ♭VII で身支度を始め、二次ドミナントで決意をにじませ、属調の Eb で恋を歌い、F major まで足を延ばしてから Eb に帰り着く。一曲の中で三つの調を巡りながら、聴き手に難しさを感じさせないのは、「わちゃわちゃ」「POOGIE」のコールと甘いメロディがその旅をくるんでいるからだ。キュートな表情の下に、恋の進展を調の移動で描くという大胆な設計を隠した、NNBS. の初期を代表するラブソングである。
