## 構成とコード進行

### Intro
```
Gb → Ab
```
- **♭VII → I** のシンプルな導入。Mixolydian カラーを冒頭から提示

### Aメロ（ここでクルクル巻いて / ピンでとめてOK）
```
Gb → Fm
Bbm → Db
Gb → Fm
Ebm → Ab
```
- **♭VII-vi-ii-IV-♭VII-vi-v-I** — Ab Mixolydian 風に ♭VII (Gb) を多用する個性的なフレーム
- **Ebm (v minor)** = Ab minor からの同主調借用。I への解決に柔らかな陰りを加える
- 「チクタクチクタクもうヤバい 今日もヒールは無理」— 身支度の等身大キュートさ
- 「さぁでかけよう 会えたらいいな」で Ab に着地

### Bメロ（小さいボクの世界で / やっとキミを見つけたんだ）
```
Db → DbM7 → Db7 → Gb
Gb → Fm → Bb
Ebm → Ab
```
- **Db → DbM7 → Db7** = IV の**内声クロマティック下行**
  - Db(F) → DbM7(F) → Db7(Cb=B) — 7度が M7→dom7 に下がる瞬間で切なさが滲む
  - Db7 は **V7/♭VII** として Gb に解決
- **Bb (II major)** = Bbm(ii) ではなく**メジャーの II**！二次ドミナント V/V として機能
  - 「想いは伝えられないけど」の「けど」で Bb が鳴り、ほんのりの決意

### Cメロ（ちょいおこらせた時も / すぐゴメンね言えなくて）
```
Db → DbM7 → Db7 → Gb
Gb → Fm → Bb
Eb → Ab → Bb → Eb Eb7
```
- Bメロと同じ出だしだが、後半で **Eb → Ab → Bb → Eb → Eb7** に展開
- **Eb7 (V7)** が「いつもよりカワイク なれちゃうよ」で鳴り、Eb major サビへの**属調転調**を準備
- V7 一発で調性が Ab → Eb にシフトする鮮やかな転調

### フック（NA NA NA / ズルズル一途に / POOGIE POOGIE）
```
Ab → Bb → Eb → Cm（×2）
Ab → Bb → Eb → C
```
- **Ab(IV)-Bb(V)-Eb(I)-Cm(vi)** = Eb major の **IV-V-I-vi** — 転調完了を宣言する明快な進行
- 「わちゃわちゃ わちゃわちゃ」「POOGIE POOGIE POOGIE POOGIE」の無邪気なコール
- ラスト **C major (VI in Eb)** = **クロマティックメディアント**。Cm(vi) ではなく C major にすることで
  「MAKE IT MAKE IT MAKE IT MAKE IT」のビルドアップに輝きと推進力が生まれる
- 「いちばんスキはキミにキミにキミに」→ Ab-Bb-Eb で着地

### サビ（恋してる世界が 続くように Hey!）
```
Eb → Gm → Cm → Eb7
Ab → Gm / F → Bb
Eb → Gm → Cm → Eb7
Ab → Gm → C
Fm → Bb → Eb → Eb7
Fm → Bb → Eb → Eb7
Ab → Bb
Eb
```
- **Eb(I)-Gm(iii)-Cm(vi)-Eb7(I7)** → **Ab(IV)-Gm(iii) / F(II)-Bb(V)** — Eb major の王道×装飾
- **Eb7 (I7)** = V7/IV として Ab に向かうセカンダリードミナント。I から即座に緊張を作る妙技
- **F major (II)** = V/V — 二次ドミナントで Bb(V) に力強く解決
- **C major (VI)** = 「ボクの知らないナニか」で再び登場するクロマティックメディアント
- **Fm → Bb → Eb → Eb7** = ii-V-I-I7 — ジャズ的な解決。「キミとみつけたいんだ」「キミにトキメキなんだ」
- 「ほんとはちょっと キミとなら / 恋してみたいな」で柔らかく着地

### 間奏1（Ab major 帰還）
```
Gb Ab Bbm Db | Gb Ab Db Gb Ab
```
- Aメロの素材を使って Ab major に帰還

### 2番（小さなことでちょっぴり / 少し少し強引に）
```
（Aメロ・Bメロ・Cメロ・フック・サビ — 1番と同一進行）
```
- Bメロ: 「何だかいつもこっちに 合わせてくれるどうしたって？」「どんな時もふわふわで」
- Cメロ: 「やさしい笑顔 守りたくて」
- サビ2回目は「恋してる世界が **広がるように** (Hey!)」に変化
- ラスト: Eb → Ebsus4 → 「恋してみたい NA NA NA」

### 間奏2（F major 転調）
```
Bb → F → Dm → C（×4）
→ Gm → Am → Bb
```
- **Bb-F-Dm-C = IV-I-vi-V in F major** — 3つ目の調性圏に大胆転調！
  - Ab major(verse) → Eb major(chorus) → **F major(interlude)**
  - 全音ずつ上がる転調設計（Ab → 属調Eb → さらに全音上 F）
- **Gm → Am → Bb** = ii-iii-IV の上行進行で次セクションへスムーズにブリッジ

### ブリッジ（ずっと夢中を ラララ / ずっと探してた）
```
C
Eb → EbM7 → Eb7 → Ab
Ab → Gm
F → Bb
```
- **Eb → EbM7 → Eb7 → Ab** = Bメロの **Db→DbM7→Db7→Gb を全音上に移調**した同一技法！
  - 内声: G → G# → Gb(Db) の微妙な動きが「ずっと探してた」の切なさを描写
  - IV のクロマティック内声下行という統一モチーフを異なる調性で再利用 — 作曲の巧みさ
- 「昨日よりも 今日よりも / 明日はオモシロイかな」
- 2回目: 「明日は**ピカピカ**」で明るく解決
- Eb → Ebadd9 の add9 で余韻を残す

### ラストサビ（おおきな夢と ボクらをつなぐ Hey! BABY）
```
Eb → Gm → Cm → Eb7（サビ同一進行）
Ab → Gm / F → Bb
```
- 「叶えるために歌うのさ」「世界が広がるように YEAH YEAH」— スケールアップした歌詞
- 「いつだって ボクらが向かう (Hey! BABY)」— ファンとの一体感

### アウトロ（ほんとはずっと ずっとずっと ね）
```
Ab → Bb → Eb → Adim → Ab → Eb7
Eb
```
- **Adim** = **パッシング減和音**。Ab → A(dim) → Ab の半音上行→帰還で一瞬の緊張と解放
  - Adim の構成音 A-C-Eb は Ab のルートを半音上げただけ — 最小限の動きで最大の効果
- 「一緒にいたいな」で Eb に着地
- 曲全体を通じて Ab → Eb へ「居場所が移った」構造 — 恋の始まりから関係の深まりを調性で表現

## 楽曲の特徴

### コード面
1. **Ab major → Eb major 属調転調** — ヴァースは Ab、サビは Eb。恋の進展を「調の移動」で表現
2. **Db→DbM7→Db7 / Eb→EbM7→Eb7** — IV のクロマティック内声下行を2つの調で再利用する統一モチーフ
3. **F major 間奏** — 3つ目の調性圏への大胆な転調。Ab→Eb→F と上昇する調設計
4. **C major (VI)** — Eb major 内のクロマティックメディアント。MAKE IT のビルドアップと「ボクの知らないナニか」で輝きを差す
5. **Gb (♭VII)** / **Ebm (v)** — Mixolydian 借用と同主調借用がヴァースの柔らかなカラーを形成
6. **Bb (II)** / **F (II in Eb)** — 二次ドミナントが要所で推進力を発揮
7. **Adim** — アウトロのパッシング減和音。半音の揺れが「ずっとずっと」の切なさを凝縮
8. **Eb7 (I7)** — I → I7 の即座のセカンダリードミナント化がサビの推進エンジン

### リズム・サウンド面
- **167 BPM** のギター＋シンセ。テンポは速いが跳ねるビートで「ときめき」の軽やかさを表現
- バレンタインデーリリースにふさわしい、キラキラしたシンセとギターの混成サウンド
- 「ラタタ」系リズムではなく「わちゃわちゃ」「POOGIE」のオノマトペでグルーヴを形成

### 歌詞面
- 「**ここでクルクル巻いて ピンでとめてOK**」— 身支度シーンのリアルな描写
- 「**チクタクチクタクもうヤバい 今日もヒールは無理**」— 等身大の焦り
- 「**小さいボクの世界で やっとキミを見つけたんだ**」— 恋の始まり
- 「**いつもよりカワイク なれちゃうよ**」— 恋の魔法
- 「**POOGIE POOGIE POOGIE POOGIE**」— 造語のコール。意味不明だからこそのキュートさ
- 「**わちゃわちゃ わちゃわちゃ**」— 無邪気の極み
- 「**MAKE IT MAKE IT MAKE IT MAKE IT**」— ビルドアップ
- 「**いちばんスキはキミにキミにキミに**」— ストレートな告白
- 「**恋してる世界が続くように**」— メインテーマ
- 「**キミとみつけたいんだ / キミにトキメキなんだ**」— 韻を踏んだ核心
- 「**ほんとはちょっと キミとなら 恋してみたいな**」— 控えめな告白で締め
- 「**明日はピカピカ**」— 未来への期待
- 「**一緒にいたいな**」— 最後の本音

## Hey!Mommy! 楽曲群での位置づけ

- **バレンタインデー (2/14) リリース**の恋うた。恋愛曲としては LOVE ME DO DO と双璧
- Map A では LOVE ME DO DO (-3.5, 2.0) と CANDY POP (-3.0, 3.0) の近くに配置。**「かわいい」ゾーンの3曲**だが、恋するとちゅうは**エモ寄り (y=0.5)** で最も「切なさ」を含む
- **3つの調性圏を横断** (Ab → Eb → F) する構造は START RUSH!! (Ab → C → E/Dbm → Ab) に匹敵する転調の多さ。キュートな見た目に反して構造は高度
- **Db→DbM7→Db7 → Eb→EbM7→Eb7** の「IV 内声下行モチーフの移調再現」は全楽曲中ユニークな技法
- 「**POOGIE**」は Hey!Mommy! 楽曲の造語コール系（ビスケットケースの「パクパク」、CANDY POP の「ラタタ」）の中でも最もキュートかつ意味不明で、ライブでの一体感を生む
- 「キミとみつけたいんだ / キミにトキメキなんだ」の韻は NNBS. 作品らしい言葉遊びの巧みさ
