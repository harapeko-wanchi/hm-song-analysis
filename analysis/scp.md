# SCP! — 楽曲分析

NNBS. がこのカタログに残した最初の一曲である。Em に半音の影を落とすイントロで冒険の幕を開け、サビは I ではなく IV から駆け上がる。9 軸のスコアはすべて 3.4〜5.7 に収まり、その幅は BIRD TRIP に次いでカタログで 2 番目に狭い。均整のとれた曲で、その中庸さの中に、後の NNBS. の語法の芽がいくつも見える。

## 半音の影から始まる冒険

曲は G major の曲でありながら、平行調の Em で始まる。

```
Em
Em → Em7-5 → Em → Em7-5
Em → Em7-5 → Em → Em7-5     「どんなんだ巨大なキラキラ」
Em → GM7                    「キミとキミと捕まえに…」
```

Em7-5 は Em の 5 度 B を半音下げて Bb にした和音だ。Bb は G major の外の音で、B と Bb の間を半音で行き来するたびに、明るいはずの曲に不穏な緊張が走る。「巨大なキラキラ」を前にしたときの、期待と怖さが入り混じった胸騒ぎのように聴こえる。

その揺れは「キミとキミと捕まえに行くんだ」で GM7 に解決する。短調の影から、長 7 度のきらめきを帯びた I へ。**仲間と一緒に踏み出す瞬間に、曲の本当の調が姿を現す**。イントロだけで、冒険の始まりを一つの和声の動きとして描いている。

## IV から駆け上がるサビ

サビは C→D から始まる。I ではなく IV から入り、V を経て着地点を探す形である。

```
C → D → Bm → Em             「キミの星と僕らの夢が…」
C → D → Em → G → Bm         「いい感じで大きく…STAR STARじゃん」
C → D → Bm → Em             「壊れた靴でも…」
C → D → Em → G              「いつもハピハピだね」
```

1 行目と 3 行目は IV→V→iii→vi、2 行目と 4 行目は IV→V→vi→I。いわゆる王道進行の変形で、IV→V の上り坂の後、短調の Bm や Em に落ちるか、G まで上がりきるかで行ごとの表情を変えている。目を引くのは 2 行目の末尾で、「STAR STARじゃん」が G に着いた後さらに Bm（iii）へ進み、宙に浮いたまま次の行へ渡される。トニックに着ききるのは最終行の「いつもハピハピだね」だけだ。

その手前のプレサビも、サビへの助走として丁寧に組まれている。

```
CM7 → Bm7 → Em              「好奇心と歌うことブギー…」
C → D → B → Em              「色だってなんだって…」
CM7 → D                     「きっと きっと笑っちゃう」
```

CM7→Bm7→Em はメジャー 7 度系の和音を順に下りる洗練された響きで、2 行目には B が現れる。B は Em（vi）へ向かう二次ドミナント（V/vi）で、D# の音が一瞬だけエッジを立てる。最後は CM7→D と V で止め、IV から始まるサビに飛び込む。

## 「夢の途中」で止まる C→B

サビの後には短いポストサビが付く。

```
C → B → Em → D → C → D → C → D      「夢の途中 今もずっと」
```

C から B へ、IV から V/vi への半音の下降。プレサビでも使った B が、ここではルートの半音下行として現れ、明るいサビの直後に切なさのアクセントを差す。行は D（V）で終わり、トニックに戻らない。「夢の途中」という言葉どおり、和声も途中で止まったままリフへ戻っていく。

Outro はこのポストサビを「今もつづくよ」と歌い変え、C→B→Em→D→C→D→C で閉じる。コード表のうえでは最後の和音は C、つまり IV である。I に帰りきらない終わり方は、夢がまだ続いていることの表明として聴こえる。

## 楽曲を追う

### Intro

前述の Em と Em7-5 の往復から GM7 への解決。

### リフ

```
C → D → Em → G
C → D → Em → D → C → D
G → G
```

サビと同じ IV→V→vi→I を骨格にしたリフで、C→D の往復を挟んでから G に落ち着く。このリフが 1 番と 2 番の頭に置かれ、曲の区切りを示す。

### Aメロ（続かない事ばかり繰り返したけど）

```
G → C → Am → D              「続かない事ばかり…」
G → C → D → Bm → G          「ここなら変わるから…」
G → C → Am → D              「はじまると隣とか…」
G → C → D → Bm → G          「そんなこんなで…」
```

I→IV→ii→V と、I→IV→V→iii→I。Aメロは素直に I から始まり、ダイアトニックの和音だけで進む。「続かない事ばかり繰り返したけど」「ここなら変わるから」と、過去の自分と新しい居場所を対比する語りを、平明な和声が支える。

### プレサビ〜サビ〜ポストサビ

前述のとおり。CM7→Bm7→Em の下行、B（V/vi）のエッジを経て、IV 始まりのサビ、「夢の途中」の C→B へと進む。

### 2番

Aメロは「選ばれた事だけで素敵じゃないし」「今いる場所でさえもね特別だけど」と、謙虚さと前向きさを両立させる言葉に変わる。進行は 1 番と同じで、プレサビでは「あの場所とダンスだけはブギー譲れない」と、居場所への愛着が歌われる。サビ、ポストサビも同じ進行のまま、「例えばキミの歌う声が届くなら」と仲間への呼びかけに変わる。

### ラップ（Cメロ）

```
G       「YEAH YEAH ここでプチョヘンザ」…「SCP」「怒怒怒」
```

G 一発の上で、「プチョヘンザ」「ふざけ過ぎはダメダメ」と遊び心全開のラップが入る。和声を止めて言葉とリズムだけで場を沸かせる、ライブのための区間である。

### 大サビ〜Outro

1 番と同じ歌詞のサビをもう一度歌い、前述の「今もつづくよ」の Outro で終わる。

## カタログの中で

SCP! のリリースは 2022 年 2 月 11 日。NNBS. はこの後カタログに 21 曲を提供する最大の作家になるが、その最初の一曲がこれだ。1 週間後の Hey!Baby! がバンド 7.7 のギターロックに振り切ったのに対し、SCP! はバンド 5.7、疾走感 4.7、複雑さ 3.4 と、どの軸にも偏らない。3 つのマップでもx・y の値はいずれも ±1.6 の範囲に収まり、カタログの「真ん中」に立つ曲といえる。Map A で近くにいるのは同じ NNBS. の BIRD TRIP で、夢・仲間・冒険を歌う点も共通している。

和声の面では、後の NNBS. 作品に通じる要素がすでにそろっている。IV や vi から入る循環、二次ドミナントの V/vi、そして I に着ききらない終わり方である。一方で、Em7-5 のように調の外から半音の影を差す手つきは、この時期ならではの素朴な実験として聴こえる。

## 総評

半音の影を落とした Em で始まり、GM7 で調を明かし、IV から駆け上がるサビを経て、「夢の途中」の C→B で立ち止まる。どの仕掛けも控えめで、スコアの数字も中庸だが、それは曲が弱いということではない。冒険の始まりを、大げさにせず等身大で描くための均衡である。NNBS. と Hey!Mommy! の物語の出発点として、今聴き直す価値のある一曲だ。
