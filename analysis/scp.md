## コード特徴
- **Gメジャー基調**: 明るく開放的
- **Em7-5（iiø）**: イントロで使用。半音下行（B→Bb）の不穏な緊張感 → GM7で解決。冒険の始まりを暗示
- **CM7 → Bm7 → Em**: Pre-chorusのメジャー7th系下行。洗練された響き
- **B（V/vi）**: Pre-chorusで登場。Em（vi）へのドミナント、一瞬のエッジ・緊張
- **C → D → Bm → Em / C → D → Em → G**: Chorusの4コードパターン。IV→V→iii→vi / IV→V→vi→I、王道進行のバリエーション
- **C → B（Post-chorus）**: メジャーIVからマイナーV/viへの半音接続。切なさのアクセント
- **GM7**: イントロ解決コード。メジャー7thのきらめき
