## 構成とコード進行

### Intro（Oh! Oh! Oh! / ハイ！ハイ！ハイハイハイハイ！！）
```
B | G#m → B | E → B | C#m → F#
B → F# | G#m → D#m | E → B | C#m → F# → B
```
- I-vi-I-IV-I-ii-V の循環系。B major ダイアトニック内で堂々と展開
- 「Oh! Oh! Oh!」のコールと「ハイ！ハイ！ハイハイハイハイ！！」の応酬がライブ映えする構造
- 「follow me! follow me! CANDY!」のキメで着地

### Aメロ（へこたれそうな日も bedで寝れなくても）
```
B（ワンコード）
```
- **B のワンコード**上でラップ調ボーカル
- コードを動かさないことでリズムと歌詞の勢いに集中させる手法
- 「Z世代に着いてきて！」のセリフ挿入がアクセント

### Bメロ（そんなの余裕だし / へっちゃらだし！）
```
Bsus4 → Bm → Bsus4 → Bm（繰り返し）
```
- **Bsus4 ↔ Bm** の交互 — B major の曲中に**同主調マイナー (Bm)** が突如出現
- sus4(E) → m(D) = **D#→D のわずか半音**だけの変化
- 「余裕だし」「へっちゃらだし！」の**揺れる自信**を、sus4↔minor の不安定さで音響的に描写
- この同主調マイナー借用が CANDY POP 最大の個性ポイント

### Cメロ（強がって言っても 誰も1人じゃダメなの）
```
F#m7 → B → G#m7 → C#
A → B → C → D
```
- **F#m7** = v minor。B major の V (F#) がマイナー化した珍しい響き。柔らかい切なさが滲む
- **G#m7 → C#** = vi7 → II。C# は二次ドミナント (V/V) 的な機能
- **A → B → C → D** = **♭VII → I → ♭II → ♭III のクロマティック上行**
  - A (♭VII) は Modal Mixture 借用
  - C (♭II) と D (♭III) は完全にノンダイアトニック
  - ルートが A→B→C→D と**全音・半音で駆け上がる**壮大なビルドアップ
  - 「あなたのおかげなんです」の感情爆発と完璧にシンクロ
  - J-POP でも珍しい、攻めたハーモニック処理

### サビ（CANDY CANDY kiss me now / うちら最高）
```
B → F# → G#m → D#m
E → B
C#m → F#sus4 → F#
```
- **I-V-vi-iii-IV-I-ii-V** — **カノン進行の変形**
- ベースライン B→(A#)→G#→(D#)→E が下行→上行の弧を描く
- 1回目「うちら最高（さいこう）」/ 2回目「うちら最強（さいきょう）」のダジャレ的変化がキュート
- **F#sus4 → F#** のサスペンション解決が「笑顔さ あ行こう」の句読点
- 2コーラス目は「POPPING CHERRY kiss me now」に歌詞差し替え→「うちらが幸せあげる」

### 間奏（ギターソロ）
```
B G#m E F# | B G#m E F#
```
- **I-vi-IV-V** のシンプルな循環上でギターソロ
- 打ち込み主体の楽曲中に唯一のバンド的サウンドが差し込まれるコントラスト

### 2番 Aメロ（badもgood 混ざったらno way!）
```
B（ワンコード）
```
- 1番同様。「あなたの安心感」

### 2番 Bメロ（移り気なんて ダメダメなんです / 拗ねちゃうんです）
```
Bsus4 → Bm → Bsus4 → Bm → Bsus4 → Bm
```
- 同一パターン。「拗ねちゃうんです」の歌詞で Bsus4↔Bm の揺れが**ツンデレ感**を演出

### 2番 Cメロ（ぶつかること たまにあっても / teamって素晴らしいんです）
```
F#m7 → B → G#m7 → C#
A → B → C → D
```
- 1番と同一進行。「悔（くや）しくて泣いても」→「teamって素晴らしいんです」

### ラストサビ前（Oh! Oh! Oh! / もっとこっち来てよ！）
```
B → BM7
G#m9 → B | E → B | C#m → F#
B → F# | G#m → D#m | E → B | C#m → F#
```
- Intro の再現だが 2つの**装飾和音**が追加:
  - **BM7** = I に長7度を付加。キラキラした展開感
  - **G#m9** = vi に9th を付加。より洗練された響き
- 「もっと こっち来てよ！」のパンチラインで最終サビへ突入

### ラストサビ（JUMPING JUMPING kiss me now / うちら最強）
```
B → F# → G#m → D#m
E → B
C#m → F#sus4 → F#
```
- 「CANDY CANDY」→「**JUMPING JUMPING**」に歌詞アップグレード
- 「ラタタ」→「**ワチャチャ**」にも変化 — エネルギーレベル上昇
- 「うちらが幸せ上げる」→「ラタ ラタタ ラタタ ラタタ」→「あなたを守（まも）ってあげる」で大団円

### Outro
```
B G#m E F# | B G#m E F# → B
```
- I-vi-IV-V 循環 → I 着地。最短距離の明るいクロージング

## 楽曲の特徴

### コード面
1. **Bsus4 ↔ Bm 同主調交替** — Major の曲中で minor に切り替わる Bメロが最大の個性。半音（D#→D）だけの変化で「揺れる自信」を演出
2. **A → B → C → D クロマティック上行** — ♭VII→I→♭II→♭III の驚異的ビルドアップ。J-POP 離れしたハーモニック処理
3. **F#m7 (v minor)** — ドミナント V をマイナー化した異色の響き
4. **カノン進行変形** (I-V-vi-iii-IV-I-ii-V) — 王道だが F#sus4→F# のサスペンション解決が効いている
5. **BM7 / G#m9** — ラスト前にのみ登場する装飾和音。リピーターを音で飽きさせない仕掛け
6. **Aメロのワンコード** — あえてコードを動かさず、リズムと歌詞の勢いに全振り

### リズム・サウンド面
- **170 BPM** の打ち込み系。Voyage! と同じ BPM・同じ Key (B) だが、こちらは**甘キュート路線**
- シンセベースとパッド主体だが、間奏で**ギターソロ**が入る折衷スタイル
- 「ラタタ ラタタ」「ワチャチャ」のオノマトペがリズムパターンの一部として機能

### 歌詞面
- 「**CANDY CANDY kiss me now**」「**POPPING CHERRY kiss me now**」— お菓子モチーフの甘いフック
- 「**うちら最高**」「**うちら最強**」— さいこう/さいきょうの韻
- 「**follow me! follow me!**」「**もっとこっち来てよ！**」— 積極的な呼びかけ
- 「**Z世代に着いてきて！**」— 世代感を掲げるセリフ
- 「**強がって言っても 誰も1人じゃダメなの / あなたのおかげなんです**」— 仲間への感謝
- 「**teamって素晴らしいんです**」— グループのチーム感
- 「**拗ねちゃうんです**」「**移り気なんてダメダメ**」— ツンデレ的な愛嬌
- 「**あなたを守ってあげる**」— ファンへの約束で締め

## Hey!Mommy! 楽曲群での位置づけ

- **Map A で LOVE ME DO DO (-3.5, 2.0) の隣に配置** — 「甘キュート×ポップ」ゾーンのツートップ
- LOVE ME DO DO が「片思いのドキドキ」なら、CANDY POP は「仲間と一緒にはしゃぐ甘さ」— ベクトルは違うがキュート度は同等
- **Voyage! と同じ Key (B) / BPM (170)** だが、Voyage! がクール寄りの冒険なのに対し、こちらは甘キュートど真ん中 — 同じテンポでもアプローチが正反対
- **しえりーほ作品**（Summer land, ICE PARTY も同作家）の中で最もキュート指数が高い一曲
- **A→B→C→D クロマティック上行**は Hey!Mommy! 楽曲群の中でも突出した攻めのハーモニック処理。甘い曲の中に仕込まれた"飛び道具"
- 「Oh! Oh! Oh!」「ハイ！ハイ！」「ラタタ」「ワチャチャ」「follow me!」とコールポイントが大量 — **ライブでの盛り上がり指数は最高クラス**
- 「teamって素晴らしいんです」「あなたを守ってあげる」は、Hey!Baby! の「Stay gold」や MAGNET の「I need you」と共通する**ファンとの絆テーマ**
