# CANDY POP — 楽曲分析

しえりーほのカタログデビュー作は、甘さを真正面から打ち出したキュートなポップである。カノン進行の変形やワンコードのラップと、骨組みはどこまでも親しみやすい。だがその中に、二つの飛び道具が仕込まれている。B major の曲に突然差し込まれる同主調の Bm と、A→B→C→D とルートを駆け上がる Cメロだ。

## 揺れる自信を描く Bsus4 と Bm

Bメロは、Bsus4 と Bm の二つの和音だけを交互に繰り返す。

```
Bsus4 → Bm → Bsus4 → Bm     「そんなの余裕だし…」「へっちゃらだし！」
```

Bm は B major の曲には本来出てこない、同主調（同じ主音の短調）の主和音だ。B major の主和音から見れば、第 3 音の D# が D へ半音下がっただけの違いである。Bsus4 は 3 度を 4 度の E に吊り上げた和音で、長調とも短調とも決まらない。その宙吊りが解ける先が、メジャーではなくマイナーなのだ。「余裕だし」「へっちゃらだし！」と言い張る歌詞の裏で、和音は明るさから半歩だけ踏み外している。**強がりの言葉と、揺れる自信**。この同主調の借用が CANDY POP 最大の個性である。

2 番の Bメロでも同じ交替が 3 回繰り返され、「拗ねちゃうんです」の歌詞と組み合わさって、ツンデレのような愛嬌を生む。

## A → B → C → D — 甘い曲に仕込まれた飛び道具

Cメロでは、曲の和声がいちばん大胆に動く。

```
F#m7 → B → G#m7 → C#       「強がって言っても…」
A → B → C → D              「あなたのおかげなんです」
```

1 行目の F#m7 は v、つまりドミナントの F# を短三和音にした和音で、柔らかな切なさがにじむ。G#m7→C# の C# は、V へ向かう二次ドミナント（V/V）の響きを持つ。

そして 2 行目。A→B→C→D は ♭VII→I→♭II→♭III で、ルートが全音・半音・全音と駆け上がっていく。A は同主短調から借りた ♭VII、C と D は B major とは無縁のノンダイアトニックな和音だ。主音の B を踏み台にして、さらに調の外へ外へと上り続けるビルドアップは、「あなたのおかげなんです」という感情の爆発と完全に重なる。J-POP のアイドル曲としてはかなり攻めた和声処理であり、この A→B→C→D の上行は、のちの Summer land、ICE PARTY にも形を変えて受け継がれる、しえりーほの署名になった。

## 楽曲を追う

### Intro（Oh! Oh! Oh!）

```
B | G#m → B | E → B | C#m → F#           「Oh! Oh! Oh!」…
B → F# | G#m → D#m | E → B | C#m → F# → B   「ハイ！ハイ！ハイハイハイハイ！！」…
```

I→vi→I→IV→I→ii→V を軸にした循環で、B major のダイアトニックの中で堂々と展開する。「Oh! Oh! Oh!」のコールと「ハイ！ハイ！」の応酬がライブ映えする構造で、「follow me! follow me! CANDY!」のキメで着地する。

### Aメロ（へこたれそうな日も）

```
B（ワンコード）       「へこたれそうな日も…」
```

B のワンコードの上で、ラップ調のボーカルが走る。コードを動かさないことで、リズムと言葉の勢いに耳を集中させる手法だ。「Z世代に着いてきて！」のセリフがアクセントになる。2 番の Aメロも同じワンコードである。

### Bメロ（そんなの余裕だし）

前述の Bsus4 と Bm の交替。

### Cメロ（強がって言っても）

前述の F#m7 と A→B→C→D の上行。2 番の Cメロも同じ進行で、「悔しくて泣いても」から「teamって素晴らしいんです」へつながる。

### サビ（CANDY CANDY kiss me now）

```
B → F# → G#m → D#m     「CANDY CANDY kiss me now」…
E → B                  「うちら最高」…
C#m → F#sus4 → F#      「笑顔さ あ行こう」
```

I→V→vi→iii→IV→I→ii→V、カノン進行の変形である。ベースは B から G#、E へと弧を描くように下り、また上がる。F#sus4→F# の掛留の解決が「笑顔さ あ行こう」の句読点になる。1 回目の「うちら最高」が 2 回目には「うちら最強」になる、さいこう／さいきょうの言葉遊びもキュートだ。2 コーラス目は「POPPING CHERRY kiss me now」に差し替えられ、「うちらが幸せあげる」へ続く。

### 間奏（ギターソロ）

```
B G#m E F# | B G#m E F#
```

I→vi→IV→V のシンプルな循環の上で、ギターソロが鳴る。打ち込み主体の曲の中に、ここだけバンドの音が差し込まれるコントラストが効いている。

### ラストサビ前（もっとこっち来てよ！）

```
B → BM7
G#m9 → B | E → B | C#m → F#
B → F# | G#m → D#m | E → B | C#m → F#    「もっと こっち来てよ！」
```

イントロの再現だが、二つの装飾和音が加わっている。I に長 7 度を足した BM7 のきらめきと、vi に 9 度を足した G#m9 の洗練だ。どちらもこの箇所にしか現れず、繰り返し聴くファンを音で飽きさせない仕掛けになっている。「もっと こっち来てよ！」のパンチラインで最後のサビへ突入する。

### ラストサビ（JUMPING JUMPING kiss me now）

サビと同じカノン変形の上で、「CANDY CANDY」が「JUMPING JUMPING」に、「ラタタ」が「ワチャチャ」に替わり、エネルギーが一段上がる。「うちら最強」を経て、「あなたを守ってあげる」で大団円を迎える。

### Outro

```
B G#m E F# | B G#m E F# → B
```

I→vi→IV→V の循環から I に着地する、最短距離の明るい締めくくりである。

## カタログの中で

キュート 8.2 は、もちぷる（9.9）、LOVE ME DO DO（8.8）に次ぐカタログ 3 位で、しえりーほの 3 作の中では最も高い。ハッピー 8.8 も、もちぷるに次ぐ 2 位だ。Map A でも LOVE ME DO DO の近く、かわいい側に寄った位置にある。LOVE ME DO DO が片思いのドキドキをギターロックで鳴らすのに対し、CANDY POP は仲間と一緒にはしゃぐ甘さを打ち込みで描く。

Voyage! とは Key（B major）も BPM（170）も同じだが、AILI の Voyage! が冒険と航海をテーマにしたスケールの大きな曲であるのに対し、本作は甘さのど真ん中を狙っている。同じテンポ、同じ調でも、アプローチは正反対だ。

複雑さ 1.8 は 7777777、もちぷるに次いでカタログで 3 番目に低い。全体としては素直な曲であり、だからこそ A→B→C→D の上行や Bsus4↔Bm の交替が、甘い曲に仕込まれた飛び道具として際立つ。「Oh! Oh! Oh!」「ハイ！ハイ！」「ラタタ」「ワチャチャ」「follow me!」とコールポイントも多い。「teamって素晴らしいんです」「あなたを守ってあげる」と仲間やファンへ向ける言葉は、Hey!Baby! の「Stay gold」や MAGNET の「I need you」と同じく、絆をテーマにした系譜に連なる。

## 総評

カノン進行、ワンコード、I-vi-IV-V の循環と、骨格は徹底して親しみやすい。その中に、強がりの裏の揺らぎを描く同主調の Bm と、感謝の爆発を描く A→B→C→D の上行という、二つだけ強い仕掛けを置いた。入門曲として誰にでも届く甘さと、作家の個性がはっきり刻まれた和声。その両立が、しえりーほというソングライターの出発点を鮮やかに示している。
