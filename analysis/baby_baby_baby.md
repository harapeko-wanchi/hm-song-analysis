## 構成とコード進行

### Intro
```
Em7 → Cadd9 → G → D
Em7 → Cadd9 → G → D       "Hey!"
```
- **Em7→Cadd9→G→D = vi7→IVadd9→I→V** — この4コードが楽曲を貫くシグネチャー循環
- vi から始まる「泣き」のニュアンスを、add9/7th のテンションで明るく中和。BPM 200 の疾走を予感させる幕開け

### フック（ナナナ ナイロベイベー）
```
Em7 → Cadd9               "ナナナ ナイロベイベー"
G → D                     "ワッツアップワ ッツアップベイベー"
Em7 → Cadd9               "ナナ オ ドロウヨベイベー"
G → D                     "Hey! Hey! Hey! Hey! Hey!"
（繰り返し）
Em                        "Hey! Brand new sunset"

C → D → Em → G
C → D → G
```
- **vi-IV-I-V ループ**の上にナンセンスワード「ナイロベイベー」「ワッツアップ」「ドロウヨベイベー」を畳みかける
- 最後の **Em（vi）** 単独で「Brand new sunset」を着地 — トニックではなく vi で止めることで余韻と次への期待を残す
- 「C→D→Em→G（IV→V→vi→I）」のブリッジでフックからAメロへ橋渡し

### Aメロ（はじめから ワクワク そりゃ 全開エブリディ）
```
G → Bm → C → D            "はじめから ワクワク そりゃ 全開エブリディ"
Am → G → Em → C → D       "見たいこと見せたい ことたくさん"
G → Bm → C → D            "駆け抜ける頭のなか 空っぽにして"
Am → G → Em → C → D       "なんでもねつめこむ つめつめちゃおう"
```
- **G→Bm→C→D = I→iii→IV→V** — トニックから iii を経て上行する開放的な進行
- **Am→G→Em→C→D = ii→I→vi→IV→V** — ダイアトニックを駆け巡るドライブ感
- 「全開エブリディ」「つめつめちゃおう」のハイテンションをコードの細かい動きが後押し

### プレサビ（ラッキー Go / キララゲットレディ カモンベイベー）
```
CM9 → D                   "キララゲットレディ カモンベイベー"
Bm7 → Em                  "キララゲットレディ カモンベイベー"
CM9 → D                   "キララゲットレディ カモンベイベー"
Em → G                    "ピカピカで キラリ"
（2巡目）
CM9 → D                   "キララゲットレディ カモンベイベー"
Bm7 → Em                  "キララゲットレディ カモンベイベー"
CM9 → D                   "キララゲットレディ カモンベイベー"
Em → G                    "駆け抜けよう"
C → E                     "今日も最高 最高じゃじゃじゃんね"
C → D                     "いくよ"
```
- **CM9→D→Bm7→Em = IV→V→iii→vi** — **王道進行（ロイヤルロード）**！ J-POP の代名詞的な「切なくも盛り上がる」進行を、**M9/7th テンション**で煌びやかに装飾
- **E（III = V/vi）** が炸裂 — 「今日も最高」で**二次ドミナント**が鳴り、一瞬非ダイアトニックなキラめきが走る。直前まで Em（vi）だった世界が E メジャーに反転する瞬間の高揚
- 「キララゲットレディ」「ピカピカ」「キラリ」のきらめき系ワードと M9 の響きが完璧にシンクロ

### サビ（Now めっちゃ Happy / Mommy yummy Coming）
```
G → (Bm) → C → (Am)       "Now めっちゃ Happy dancing dan"
C → (Bm) → Am → D         "HAPPY YAPPY"
G → (Bm) → C → (Am)       "ハイパーハピ ヤピ ララランラン"
C → (G)                   "Mommy yummy Coming coming"
C → D → G                 "E jump jump じゃかじゃんじゃん"
（後半）
C → (G)                   "Mommy yummy Coming coming"
C → D → G                 "E じゃん jump"
Am → G                    "Hey! Happy mommy じゃん jump!"

C → D → Em → G
C → D → G
```
- 括弧内（Bm/Am/G）は経過的に挿入される**ステップ・ベースの装飾コード**
- **G→Bm→C→Am**（I-iii-IV-ii）から **C→Bm→Am→D**（IV-iii-ii-V）への下行 — ベースが段階的に降りていく構造美
- 「Mommy yummy Coming」「E jump jump」「じゃかじゃんじゃん」のコール連打を **C-D-G（IV-V-I）** の王道カデンツで着地
- 最後の **Am→G（ii→I）** で「Hey! Happy mommy じゃん jump!」— ダイアトニック ii の柔らかさでサビを締める

### 2番 Aメロ（トキメキュン やりたいこと 全開エビバディ）

```
G → Bm → C → D            "トキメキュン やりたいこと 全開エビバディ"
```

### ブリッジ（ママママ マミマミミマミ）
```
D → Ebdim7 → D → G
Ebdim7 → D                "ママママ （マー）"
Ebdim7 → D                "ミミミミミミ （ミー）"
Ebdim7 → D                "ママママ （マー）"
```

- **Ebdim7（パッシング・ディミニッシュ）** が主役 — G major では♭VI上のディミニッシュ。D（V）へ半音で滑り込む**クロマティックな経過和音**
- 「ママママ」「ミミミミ」の母音遊び（mommy → ma / mi）と、不安定なディミニッシュの宙吊り感が呼応する遊び心
- ここだけテンションを溜め、最後のフック大合唱へ向けて緊張を作る

## 楽曲の特徴

### コード面
1. **vi7→IVadd9→I→V（Em7-Cadd9-G-D）シグネチャー循環** — Intro・フック・アウトロを貫く背骨。vi始動の哀愁を add9/7th で明るく中和する
2. **王道進行 IV→V→iii→vi（CM9-D-Bm7-Em）** — プレサビの「キララゲットレディ」を支える J-POP 王道。M9/7th テンションで煌びやかに装飾
3. **E（III = V/vi）二次ドミナント** — 「今日も最高」で炸裂。vi（Em）の世界が E メジャーに反転する一瞬のキラめき
4. **Ebdim7 パッシング・ディミニッシュ** — ブリッジ「ママママ」でクロマティックに D（V）へ滑り込む経過和音。母音遊びと宙吊り感の呼応
5. **サビのステップ・ベース下行**（G-Bm-C-Am → C-Bm-Am-D） — 装飾コードでベースを段階的に降ろす構造美
6. **add9 / M9 / 7th テンションの多用**（Cadd9, CM9, Em7, Bm7） — 高速パーティーチューンにきらめく音響を付与

### リズム・サウンド面
- **BPM 200 はカタログ最速クラス** — PLAYFUL ROMANTIC（196）、POJI POJI GO（196）を上回り、MY FIRST LOVE SONG（220）に次ぐ高速域
- シンセ＋ギターの編成。ギターのカッティングとシンセのきらめきが BPM 200 の疾走を駆動
- コール＆レスポンスとオノマトペ連打を高速ビートに乗せる、ライブ最大瞬間風速型の設計

### 歌詞面
- 「**ナナナ ナイロベイベー / ワッツアップ ベイベー / ドロウヨベイベー**」— 意味より響き優先のナンセンス・コール。"baby" の連呼がタイトル「BABY BABY BABY」と呼応
- 「**キララゲットレディ カモンベイベー**」「**ピカピカ**」「**キラリ**」— きらめき系ワードの多用
- 「**Now めっちゃ Happy / HAPPY YAPPY / ハイパーハピ ヤピ ララランラン**」— 多幸感のストレートな爆発
- 「**Mommy yummy Coming coming**」「**Hey! Happy mommy じゃん jump!**」— "mommy" を織り込む Hey!Mommy! 流のセルフ・リファレンス
- 「**E jump jump じゃかじゃんじゃん**」— ジャンプを煽るライブ・コール
- 「**はじめから ワクワク そりゃ 全開エブリディ**」「**つめつめちゃおう**」— 全力・全開のポジティブメッセージ
- 「**Hey! Brand new sunset**」— 円環の節目に置かれる、新しい一日＝新しい始まりの象徴

## Hey!Mommy! 楽曲群での位置づけ

- **BPM 200 はカタログ最速クラス** — MY FIRST LOVE SONG（220）に次ぐ第2位タイ級。PLAYFUL ROMANTIC（196）・POJI POJI GO（196）を上回る超高速パーティーチューン
- **お祭り感 9.5** は PLAYFUL ROMANTIC（9.9）に迫るカタログ最高クラス。Map A 上で「沸かせる」極北に位置する
- **vi-IV-I-V のシグネチャー循環**は、I-IV-V や IV-V-vi-I を好む NNBS. の引き出しに「vi 始動ループ」を加える一手。哀愁を明るさで包む手法
- **王道進行 IV-V-iii-vi** をプレサビで使用 — NNBS. は普段ミニマルな循環を好むが、本曲ではあえて J-POP 王道を取り入れ、M9 テンションで自分色に染めている
- **E（V/vi）二次ドミナント**は、7777777 の F major（VI クロマティックメディアント）や MY FIRST LOVE SONG の C7（V7/vi）と同系統の「一瞬のキラめき」を狙う手法。NNBS. の二次ドミナント嗜好が表れている
- **Ebdim7 パッシング・ディミニッシュ**はカタログでも珍しいクロマティック経過和音。母音遊び「ママママ／ミミミミ」との組み合わせは NNBS. の遊び心の極致
- 同じ NNBS. 作でも、BPM 100 のバラード「夜空ウィズユー」とは Map B 上で正反対の位置 — NNBS. の「全力はしゃぎ！」極と「しっとりエモ」極を結ぶ振れ幅の広さを示す
- 「Mommy yummy」「Happy mommy」のセルフ・リファレンスと「jump jump」コールは、PLAYFUL ROMANTIC・POJI POJI GO と並ぶ**ライブ盛り上がり最高クラス**の設計
