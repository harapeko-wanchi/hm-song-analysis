# BABY BABY BABY — 楽曲分析

BPM 200、お祭り感 9.5。意味より響きを優先した「ナイロベイベー」のコールを、vi から始まる 4 コードの循環に畳みかける、NNBS. の全力パーティーチューンである。王道進行をテンションで飾り、二次ドミナントと減七の和音で一瞬だけきらめきを差し込む。聴きどころは、はしゃぎ続ける曲の中に仕込まれた、その「キラッ」とする瞬間だ。

## 哀愁をテンションで包む vi 始まりの循環

曲を貫くのは Em7→Cadd9→G→D、**vi7→IVadd9→I→V** の循環である。Intro、フック、ラストのフックがすべてこの 4 コードでできている。短調の vi から始まる循環には本来「泣き」の気配があるが、Em7 の 7 度と Cadd9 の 9 度がその陰りを明るく中和する。G major のトニックに届く前に、もう光が差している響きだ。

このループの上に、「ナナナ ナイロベイベー」「ワッツアップ ベイベー」「ドロウヨベイベー」と、意味を持たないコールが畳みかけられる。"baby" の連呼はそのままタイトルに重なる。フックの最後は「Hey! Brand new sunset」の Em（vi）単独で止まる。トニックに帰らずに vi で切ることで、ループの勢いが宙に放り出される。

## 王道進行を M9 で飾り、E メジャーで反転させる

プレサビは、J-POP でいう王道進行である。

```
CM9 → D                   「キララゲットレディ…」
Bm7 → Em                  「キララゲットレディ…」
CM9 → D                   「キララゲットレディ…」
Em → G                    「ピカピカで キラリ」／「駆け抜けよう」
C → E                     「今日も最高…」
C → D                     「いくよ」
```

CM9→D→Bm7→Em、つまり **IV→V→iii→vi**。切なさと高揚を同時に運ぶ定番の進行を、CM9 の 9 度と Bm7 の 7 度で煌びやかに飾っている。「キララ」「ピカピカ」「キラリ」というきらめきの言葉と、M9 の響きがよく合う。

そして 2 巡目の終わり、「今日も最高」で E が鳴る。G major の外にある和音で、Em（vi）を V に見立てたときのドミナント、すなわち **V/vi（vi への二次ドミナント）**だ。直前まで Em だった世界が、G が G# に半音上がるだけで E メジャーに反転する。**一瞬の非ダイアトニックが、「最高」という言葉に光を当てる**。

## 「ママママ」と Ebdim7 の宙吊り

```
D → Ebdim7 → D → G
Ebdim7 → D                「ママママ（マー）」
Ebdim7 → D                「ミミミミミミ（ミー）」
Ebdim7                    「マミマミミマミ」
```

ブリッジの主役は Ebdim7 である。G major では ♭VI の上に組んだ減七の和音で、D（V）との間を半音で行き来する経過和音として働く。減七はどこへでも行けるぶん、どこにも落ち着かない響きを持つ。その宙吊り感の上で、"mommy" を「ママママ」「ミミミミ」と母音に分解して遊ぶ。最後は Ebdim7 のまま「マミマミミマミ」で止め、ラストのフックへ向けて緊張を溜める。曲の中でテンションを溜めるのはここだけだ。

## 楽曲を追う

### Intro

```
Em7 → Cadd9 → G → D
Em7 → Cadd9 → G → D       「Hey!」
```

前述の vi7-IVadd9-I-V を 2 回。BPM 200 の疾走を予感させる幕開けである。

### フック（ナナナ ナイロベイベー）

```
Em7 → Cadd9               「ナナナ…」
G → D                     「ワッツアップワ…」
Em7 → Cadd9               「ナナ オ…」
G → D                     「Hey! Hey!…」
Em                        「Hey! Brand new sunset」
C → D → Em → G
C → D → G
```

循環の後、C→D→Em→G、C→D→G（IV→V→vi→I、IV→V→I）のつなぎでAメロへ渡す。

### Aメロ（はじめから ワクワク）

```
G → Bm → C → D            「はじめから…」
Am → G → Em → C → D       「見たいこと…」
G → Bm → C → D            「駆け抜ける…」
Am → G → Em → C → D       「なんでもね…」
```

G→Bm→C→D（I→iii→IV→V）はトニックから iii を経て上っていく開放的な進行、Am→G→Em→C→D（ii→I→vi→IV→V）はダイアトニックの和音を駆け巡る進行だ。「全開エブリディ」「つめつめちゃおう」のハイテンションを、細かく動くコードが後押しする。2 番の Aメロ（「トキメキュン…」）も同じ進行で、「パチパチ」「はじはじける」とオノマトペが増え、「恋してる 夢の途中」と恋のモチーフが加わる。

### プレサビ（キララゲットレディ）

前述の王道進行と、「今日も最高」の V/vi。

### サビ（Now めっちゃ Happy）

```
G → (Bm) → C → (Am)       「Now めっちゃ Happy…」
C → (Bm) → Am → D         「HAPPY YAPPY」
G → (Bm) → C → (Am)       「ハイパーハピ…」
C → (G)                   「Mommy yummy Coming…」
C → D → G                 「E jump jump…」
Am → G                    「Hey! Happy mommy…」
```

括弧内の Bm、Am、G は、ベースを段階的に動かすための経過的な和音である。G→Bm→C→Am（I-iii-IV-ii）から C→Bm→Am→D（IV-iii-ii-V）へ、ベースが一段ずつ降りていく。「Mommy yummy Coming」「E jump jump じゃかじゃんじゃん」のコール連打は C→D→G（IV→V→I）の王道のカデンツで着地し、最後は Am→G（ii→I）の柔らかい動きで「Hey! Happy mommy じゃん jump!」と締める。"mommy" をグループ名に重ねるセルフ・リファレンスも、ここに詰め込まれている。

### ブリッジ（ママママ）

前述の Ebdim7。

### ラストフック

冒頭と同じ循環に戻り、ふたたび「Hey! Brand new sunset」の Em で閉じる。「Brand new sunset」で始まり「Brand new sunset」で終わる円環の構造だ。

## カタログの中で

BPM 200 は、Happy Go Round と MY FIRST LOVE SONG（220）、Hey! get up kids（210）、ビスケットケース（206）に次ぐカタログ 5 位。PLAYFUL ROMANTIC、POJI POJI GO（196）を上回り、上位 5 曲はすべて NNBS. の作品で占められている。お祭り感 9.5 は PLAYFUL ROMANTIC の 9.9 に次ぐ 2 位、ハッピー 8.5 も Happy Go Round と並ぶ 3 位タイで、逆にエモ 1.5 は下から 3 番目。沸かせることに全振りした数字である。

和声の面では、NNBS. の近作で続く vi 始まりのループの起点に位置する。このあとカラフルポップレジスタンス（Dm→Bb→F→C）、Happy Go Round（Em→C→G→D）が同じ vi-IV-I-V を背骨に採り、経過ディミニッシュもカラフルポップレジスタンスの C#dim に受け継がれた。王道進行 IV-V-iii-vi は SCP! のサビでも使われてきた進行だが、本作では M9 のテンションで NNBS. の色に染めている。V/vi の E で一瞬だけ光らせる手法は、7777777 の F（VI のメジャー化）や MY FIRST LOVE SONG の C7（V7/vi）と同じ系統の「きらめき」の作り方といえる。

同じ年の NNBS. 作でも、2 週間前にリリースされた BPM 100 のバラード、夜空ウィズユーとはサウンドの位置づけが正反対だ。疾走感は 8.0 と 1.8。はしゃぐ極と、しっとり聴かせる極の両方を、同じ作家が立て続けに書いている。

## 総評

和声だけを取り出せば、vi-IV-I-V、王道進行、IV-V-I と、ポップスの定番を並べた曲である。それを 200 の速度とナンセンスなコールで押し切りながら、E メジャーへの反転と Ebdim7 の宙吊りという二つの瞬間だけ、聴き手の耳を引っかける。考えさせずに踊らせ、それでも一瞬だけ「おっ」と思わせる。ライブで最大瞬間風速を出すために、引き算と足し算の加減が計算された一曲だ。
