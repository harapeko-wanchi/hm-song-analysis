## 構成とコード進行

### イントロ（JJJジェットコースター life）
```
G → G → G → F → D         "（イントロ）"
G → G                     "JJJジェットコースター life"
G → F → D                 "JJJジェットコースター life"
```
- **G→F→D = I→♭VII→V** — **F（♭VII）** のミクソリディアン借用がロックの骨格。3小節トニックに留まってから ♭VII→V と落ちる、ギター・リフ向きの進行
- 単音リフのループがこの進行の上を回り続け、「ジェットコースター」が上り坂でゆっくり溜めるような助走になる
- 「JJJ」はリフに合わせたスタッター（言葉の吃り）。タイトル・コールをリズム楽器のように使う

### Aメロ1（もうにっちもさっちもいかない毎日で）
```
G                         "もうにっちもさっちもいかない毎日で"
G                         "気が付けば充電も3%です…"
C                         "寝癖ボーン 制御不能 駆け込み乗車はおやめください"
（ブレイク）              "はい。"
G                         "曖昧 me な将来も気にせず今日は派手に行こう"
D7 → C → G                "まあいつかの精神でレボリューション"
（ブレイク）              "自分次第のshow time"
```
- **G→C→G→D7→C→G = I→IV→I→V7→IV→I** — ブルース／ロックンロールの定番の形
- **D7→C（V7→IV）** はドミナントがトニックに解決せず IV に戻る**ロック的な逆行**。クラシカルな V7→I より、ラフで軽快な響きになる
- 「駆け込み乗車はおやめください」→「はい。」のブレイクで、駅のアナウンスとそれに素直に返事をする寸劇を挟む。和音を止めて言葉を立たせるコミカルな演出

### Bメロ1（Bad dayも good dayでも）
```
CM7 → G                   "Bad dayも good dayでも"
A7 → D                    "混ぜたら最強でしょ！？"
```
- **CM7→G→A7→D = IVM7→I→II7（V/V）→V**
- **A7（V/V）セカンダリードミナント**が本曲で唯一のはっきりした非ダイアトニックの高揚。C#音が「最強でしょ！？」の問いかけを持ち上げ、D（V）からサビへ飛び込む
- 冒頭の **CM7** はこの曲で唯一の7thテンション。ロック一辺倒の中で、一瞬だけ柔らかい響きになる

```
C → D → G → F             "サガッてサ ガッてサ ガッて ガッて ガッデム"
```

- **C→D→G→Em = IV→V→I→vi** を軸に、IV→V で上がっては I で着地する
- **「アガッて」で C→D（上行）、「サガッて」で G→F（下行）** — 歌詞の上がり下がりとコードの動きが一致する。「ガッデム（God damn）」は ♭VII の F で鳴り、ジェットコースターが落ちる瞬間の悲鳴とミクソリディアンの陰りが重なる
- 「got'em」と「ガッデム」の音の近さを使った言葉遊び。後半は「アガッてア ガッてア…」と刻みを細かくして、加速感を出す

```
D                         "Let's go"
```

## 楽曲の特徴

### コード面
1. **I→♭VII→V（G-F-D）ミクソリディアン・リフ** — イントロ・間奏・アウトロを貫くロックの骨格
2. **V7→IV（D7→C）ロック的逆行** — Aメロとブリッジで、ドミナントを I に解決させない
3. **A7（V/V）セカンダリードミナント** — Bメロ「混ぜたら最強でしょ！？」「ストーリーは続いていく」の高揚
4. **歌詞の上下とコードの動きの一致** — 「アガッて」= C→D の上行、「サガッて」= G→F の下行
5. **全8コード**（G, C, D, Em, F, D7, CM7, A7）のシンプルな和声。非ダイアトニックは F と A7 だけ。複雑な和声ではなく、リフとリズムで聴かせる

### リズム・サウンド面
- **BPM 142** はカタログの中速帯（7777777・MAGNET の 145、BOOOOOOON の 140 と同じ帯域）
- **ギターは8分刻み、ドラムは16ビート** — ギターのストロークは大きく刻み、ドラムのハイハットが細かく刻む。BPM 142 でも体感の速度が上がる
- **単音リフのループ**が印象的で、バッキングギターと役割を分けたツインギター的な編成。打ち込み中心の楽曲が多いカタログの中で、ギター主体のサウンド

### 歌詞面
- 「**ジェットコースターみたいな人生を進め**」「**アガッて ガッて／サガッて ガッて**」— 浮き沈みだらけの人生をジェットコースターにたとえる
- 「**気が付けば充電も3%です…**」「**寝癖ボーン 制御不能**」「**駆け込み乗車はおやめください はい。**」— 冴えない朝の日常をコミカルに描く
- 「**Bad dayも good dayでも 混ぜたら最強でしょ！？**」「**泣いても笑っても ストーリーは続いていく**」— 良い日も悪い日も丸ごと肯定する
- 「**くるくる回って目が回っても 楽しんだもん勝ちでしょ**」— 曲のテーゼ
- 「**低気圧で気分イマイチでも 心の中は常夏でgo**」「**無問題 後悔しない**」— 日常のローテンションを跳ね返すポジティブさ
- 「**got'em／ガッデム**」「**JJJ**」— 響き重視の言葉遊び

## Hey!Mommy! 楽曲群での位置づけ

- **草川瞬の初提供曲**（作曲は RUSH EYE との共作、編曲は RUSH EYE）。NNBS.・AILI のレギュラー陣とも、阿久津健太郎・古橋勇紀らの外部作家とも異なる、**ギター・リフ主導のロック**をカタログに持ち込んだ
- **Map B では「バンド寄り×グルーヴィ」**（+4.0, -2.0）に位置する。バンド感の強い楽曲の多くは BPM 190 超の疾走型（Hey! get up kids、ビスケットケース、MY FIRST LOVE SONG）なので、ミドルテンポのバンド曲は貴重。近いのは DIAMOND JET（BPM 149、バンド 7.4）や SUMI-HAJI（BPM 128、バンド 6.3）
- **I→♭VII→V のミクソリディアン**は、Happy Go Round の Aメロ（G→D→F）と同じ ♭VII 借用。ただし本曲はリフの骨格そのものとして使う
- 和声は全8コードとシンプルで、複雑さ 3.5 は控えめ。阿久津健太郎（21コード）や早川博隆／柿迫ヒカル（35コード）のような「和声で魅せる」外部作家とは正反対で、リフ・リズム・言葉遊びで勝負する
- **コミカルな日常描写**（充電3%、寝癖、駆け込み乗車）は、NNBS. のナンセンス・ワードとも AILI の自己肯定とも違う、生活感のあるユーモア。最後は「楽しんだもん勝ち」という Hey!Mommy! らしい全肯定に着地する
