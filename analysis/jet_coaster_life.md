# ジェットコースターLIFE!! — 楽曲分析

浮き沈みだらけの毎日を、ジェットコースターに乗せて笑い飛ばすギターロックである。和音はわずか 8 種。G→F→D と ♭VII で落ちるリフ、解決しないドミナント、「アガッて」で上がり「サガッて」で下がるサビ。和声の凝り方ではなく、リフとリズムと言葉遊びで聴かせる。草川瞬がカタログに持ち込んだのは、そういう種類の楽しさだ。

## ♭VII で落ちるリフが、コースターの骨格になる

曲の骨組みは、イントロで鳴る一本のリフである。

```
G → G → G → F → D           （イントロ）
G → G                       「JJJジェットコースター life」
G → F → D                   「JJJジェットコースター life」
```

3 小節トニックの G に留まってから、F→D と落ちる。I→♭VII→V。F は G major の外の和音で、同じ主音を持つ G ミクソリディアン（長調の 7 度を半音下げた旋法）から借りてきたものだ。ギターで弾くと手の形が自然に収まる、ロックの最も基本的な骨格の一つである。

この進行の上を、単音リフのループが回り続ける。トニックで溜めてから一気に落ちる形は、コースターが上り坂をゆっくり登り、頂上から滑り出す動きそのものだ。タイトルは「JJJ」とスタッター（言葉の吃り）で刻まれ、歌というよりリズム楽器のように鳴る。このリフは間奏でもアウトロでも戻ってきて、曲全体を一つの周回コースにまとめている。

## 「アガッて」は上がり、「サガッて」は下がる

サビは IV→V→I→vi、C→D→G→Em を軸にした明快な進行で、そこに歌詞の上下動がぴたりと重ねられている。

```
（ブレイク）                「Let's go」
C → D → G → Em              「ジェットコースター みたいな…」
C → D                       「アガッて ガッて got'em…」
G → F                       「サガッて ガッて ガッデム」
C → D → G → Em              「くるくる 回って…」
C → D                       「楽しんだもん 勝ちでしょ」
G                           「ジェットコースターLIFE!!（Hey!）」
```

「アガッて」では C→D と和音が上がり、「サガッて」では G→F と下がる。**歌詞の上がり下がりと、コードの動く向きが一致している**のだ。しかも下がった先は ♭VII の F で、「ガッデム（God damn）」の悲鳴がちょうどミクソリディアンの陰りの上で鳴る。コースターが落ちる瞬間の叫びと、和声が一段暗くなる瞬間が重なる。

「got'em」と「ガッデム」は音の近さを使った言葉遊びで、後半では「アガッてア ガッてア ガッて ガッて」と刻みが細かくなり、加速感が増す。そして結論は「楽しんだもん勝ちでしょ」。サビの最後は G のトニックで着地し、タイトルコールで締める。

## 解決しないドミナントと、一度だけの V/V

Aメロは I→IV→I→V7→IV→I、ブルースやロックンロールの定番の形で書かれている。

```
G                     「もうにっちもさっちも…」「気が付けば充電も3%です…」
C                     「寝癖ボーン 制御不能…」
（ブレイク）           「はい。」
G                     「曖昧 me な将来も…」
D7 → C → G            「まあいつかの精神で…」
（ブレイク）           「自分次第のshow time」
```

注目すべきは D7→C である。ドミナントの D7 が I に解決せず、IV の C へ戻る。クラシカルな V7→I に比べてラフで軽く、「まあいつか」の肩の力の抜けた気分に合う。このロック的な逆行は、後半のブリッジで曲を宙吊りにする仕掛けにもなる。

対照的に、Bメロではドミナントへの押しがはっきりと強められる。

```
CM7 → G               「Bad dayも good dayでも」
A7 → D                「混ぜたら最強でしょ！？」
```

IVM7→I→II7→V。A7 は V の D へ向かう二次ドミナント（V/V）で、G major にない C# の音が「混ぜたら最強でしょ！？」の問いかけを持ち上げ、D からサビへ飛び込ませる。曲中で非ダイアトニックの和音は ♭VII の F とこの A7 の二つだけで、高揚を作る役は A7 が一手に引き受けている。冒頭の CM7 も、曲中で唯一の長 7 度の和音として、ロック一辺倒の流れに一瞬だけ柔らかい響きを差す。

## 楽曲を追う

### イントロ（JJJジェットコースター life）

前述の G→F→D のリフ。単音リフのループと 8 分刻みのギターの上で、タイトルのスタッターが鳴る。

### Aメロ（もうにっちもさっちもいかない毎日で）

前述の I→IV→I→V7→IV→I。「気が付けば充電も3%です…」「寝癖ボーン」と、冴えない朝がコミカルに描かれる。「駆け込み乗車はおやめください」の後で和音が止まり、「はい。」と素直に返事をする。駅のアナウンスとの寸劇を、ブレイクで言葉を立たせて聴かせる演出だ。

### Bメロ（Bad dayも good dayでも）

前述の IVM7→I→V/V→V。良い日も悪い日も「混ぜたら最強」と丸ごと肯定して、サビへ渡す。

### サビ（ジェットコースターみたいな人生を進め）

前述の IV→V→I→vi。後半は進行をそのままに、刻みを細かくした「アガッてア ガッてア…」「サガッてサ ガッてサ…」へ移る。

```
C → D → G → Em        「アガッてア ガッてア…got'em」
C → D → G → F         「サガッてサ ガッてサ…ガッデム」
C → D → G → Em        「くるくる 回って…」
C → D                 「楽しんだもん 勝ちでしょ」
G                     「ジェットコースターLIFE!!（Yeah!）」
```

### 間奏

```
G → G → G → F → D
```

イントロのリフに戻る。コースターが一周して、次の周回に入る。

### Aメロ2（感情ジェット離陸モード）

```
G             「感情ジェット離陸モード（Hey!）」…「心の中は常夏でgo」
D7            「無問題 後悔しない」
C → G → G     「今日の最高を更新中」…「ride on ride on」
```

1 番より G のペダルが長く、4 行を 1 つの和音で押し切る。「離陸」「急上昇」の勢いをリフとドラムに任せ、「（Hey!）」「（Fu!）」の合いの手でコールの場所を作る。ここでも D7 は G に戻らず C へ進む。

### Bメロ2（泣いても笑っても）

```
CM7 → G       「泣いても笑っても」
A7 → D        「ストーリーは続いていく」
```

1 番と同じ進行で、A7 が「ストーリーは続いていく」を持ち上げる。サビ2は 1 番と同じ進行と歌詞だ。

### ブリッジ（JJJジェットコースターlife oh yeah）

```
G → C         「JJJジェットコースターlife oh yeah」
G → C         「JJJジェットコースターlife oh yeah」
D7 → C        「不安を破り 風切って」
D7 → C        「最高速度で 3,2,1」
```

I→IV の往復と、V7→IV の逆行の繰り返し。ドミナントを一度も解決させないまま宙吊りにして、「3,2,1」のカウントダウンでラストサビへ発射する。Aメロで聴かせたロック的な逆行が、ここで溜めの装置に変わる。

### ラストサビ〜アウトロ

```
D                     「Let's go」
C → D → G → Em …      （サビと同じ）
G → G                 「JJJジェットコースター life」
G → F → D             「JJJジェットコースター life」   （×2）
G                     （終止）
```

ラストサビだけ、「Let's go」の下に D（V）が置かれる。カウントダウンの勢いをドミナントで受け止めてから、IV 始まりのサビへ入るのだ。アウトロはイントロのリフを 2 周させ、最後は G で終わる。コースターが発着場へ帰ってくる。

## カタログの中で

草川瞬はこれがカタログ初の提供で、作曲は RUSH EYE との共作、編曲は RUSH EYE が手がけた。NNBS. や AILI のレギュラー陣とも、阿久津健太郎や古橋勇紀ら一曲ずつ書いた外部作家とも違う、ギター・リフ主導のロックをカタログに持ち込んだ。

BPM 142 はカタログ 36 曲中 29 番目で、7777777 と MAGNET の 145、BOOOOOOON の 140 と同じ中速帯にいる。一方でバンドは 7.0 とカタログ 8 位で、それより上の 7 曲のうち 6 曲は BPM 170 を超える疾走型だ。例外は DIAMOND JET（BPM 149、バンド 7.4）だけで、ミドルテンポのバンド曲という本作の立ち位置は、カタログの中でも数少ない。ギターは 8 分で大きく刻み、ドラムのハイハットが 16 分で細かく刻む。テンポは中速でも、体感の速度はそれより速い。

♭VII の借用は、直前にリリースされた Happy Go Round の Aメロ（G→D→F→C→D）にも出てくる。ただし Happy Go Round が逆さまの世界を描く一瞬の色として使ったのに対し、本作は ♭VII をリフの骨格そのものに据えている。和声の量で比べれば、阿久津健太郎の DIAMOND JET（21 種）や早川博隆／柿迫ヒカルの Hey!Yummy!（35 種）のような「和声で魅せる」外部作家の曲とは正反対で、複雑さは 3.5 にとどまる。

充電 3%、寝癖、駆け込み乗車といった生活感のあるユーモアも、NNBS. のナンセンスな言葉遊びとも AILI の自己肯定とも違う味わいだ。それでも最後は「楽しんだもん勝ち」という、Hey!Mommy! らしい全肯定に着地する。

## 総評

8 つの和音、一本のリフ、そして歌詞と同じ向きに動くコード。仕掛けはどれも単純だが、単純だからこそ、上がって下がって一周して帰ってくるジェットコースターの動きが、そのまま耳で追える。冴えない朝の「はい。」から始まり、「3,2,1」で最高速度に達する。人生の浮き沈みを、難しい顔をせずに乗りこなしてみせる一曲である。
