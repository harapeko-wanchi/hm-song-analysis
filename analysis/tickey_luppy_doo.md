# Tickey Luppy Doo — 楽曲分析

真夜中に部屋を抜け出し、パジャマをドレスに変えて朝まで踊る。シンデレラを下敷きにしたこのおとぎ話を、徳田光希と大竹智之は F minor の ♭VI→V→i という 3 つの和音だけでほぼ書き切った。BPM 118 のゆったりした足取りと、マイナーなのに暗くならない幻想的な響きが、呪文のような「Tickey Luppy Doo」を際立たせる一曲である。

## ♭VI→V→i — 3 つの和音で回る魔法

Verse を支配するのは Db→C→Fm、F minor の **♭VI→V→i** の 3 コードループだ。

```
Db → C → Fm    「窓の外では…」
Db → C → Fm    「何かを報せるの…」
Db → C → Fm    「寝れずにいたら…」
Db → C → Fm    「部屋から抜け出そう…」
```

Db から半音下の C へ、そして C から Fm へ。C は F minor の和声的短音階から生まれる長三和音のドミナントで、C→Fm のドミナント解決が毎行の終わりに力強く決まる。Verse の後半（「チョコレートビスケット…」から）も同じループが 4 行続き、合わせて 8 行が完全に同じ 3 和音で回る。

この反復は、呪文の繰り返しのように働く。マイナーの調でありながら、♭VI の Db が長三和音で鳴るため、響きは暗さよりも幻想の側に傾く。夜の森へ向かう冒険の、少し怖くて、それ以上にわくわくする気分がここにある。

## サビは M7 と 7th で洗練される

サビでも骨格は同じ ♭VI→V→i だが、和音に色が足される。

```
DbM7 → C7 → Fm → Fm7    「夢で見た通りに」
DbM7 → C7 → Fm → Fm7    「パジャマからドレスへ…」
DbM7 → C7 → Fm → Fm7    「決して図書には…」
DbM7 → C7 → Fm → Fm7    「Tickey Luppy Doo…」
DbM7 → C7 → Fm → Fm7    「ズンチャッチャ…」
DbM7 → C7 → Fm → Fm7    「ズンチャッチャ…」
DbM7 → C7 → Fm → Fm7    「パパとママに…」
DbM7 → C7 → Fm          「Tickey Luppy Doo…」
```

Db は DbM7 に、C は C7 になり、Fm のあとには Fm7 が続く。長 7 度を足した DbM7 の柔らかなきらめきと、C7 のはっきりしたドミナントの引力で、Verse の素朴なループが一段洗練されたサウンドに変わる。パジャマがドレスに変わるように、同じ和音が着飾るのだ。

歌詞の言葉遊びもここに集まる。「Tickey Luppy Doo」、1 番の「ズンチャッチャ」、2 番の「ドンタッタ」と、意味のない音の連なりが魔法の呪文として機能する。そして「決して図書には載らない」「パパとママに話すとすぐに解けてしまうの」と、**この魔法は誰にも知られない秘密の魔法**であることが語られる。8 行の同じ進行が、唱え続ける呪文の時間になっている。

## 「3, 2, 1」のカウントダウンが作る緊張

Verse からサビへの橋渡しには、ループとは違う和音が置かれる。

```
DbM7 → Dm7b5(b13) → C7/E → N.C.    「さあ今から始まる 3, 2, 1」
```

DbM7 から Dm7b5(b13)、そして C7 の第 1 転回形 C7/E へ。ハーフディミニッシュからドミナントへ進む、クラシカルなドミナントの準備である。ベースは Db→D→E とせり上がり、伴奏が止まる N.C. の一瞬に「3, 2, 1」のカウントダウンが響く。2 番の前にも「見ててよ 目を逸らさず 3, 2, 1」として同じ和声が戻ってくる。魔法が発動する直前の、息を詰める瞬間だ。

## 楽曲を追う

### Intro

```
Db → C → Fm7 → FmM7 → Fm    （×2）
```

♭VI→V→i のループの終わりで、Fm7 から FmM7、Fm へと内声が動く。FmM7 はマイナーの和音に長 7 度を足した響きで、陰影ときらめきが同居する。映画のオープニングのような、少し謎めいた幕開けである。

### Verse（窓の外では）

前述の Db→C→Fm が 8 行続く。「I'm totally stoked!」と高まる気持ちと、「破れた地図をつなぎ合わせて」森へ向かう夜の冒険が語られる。

### Build（さあ今から始まる）

前述の DbM7→Dm7b5(b13)→C7/E と N.C. のカウントダウン。

### サビ（夢で見た通りに）

前述の DbM7→C7→Fm→Fm7 が 8 行。

### ブリッジ（What are you gonna be?）

```
Db → C → Fm7    「What are you gonna be?…」
Db → C → Fm7    「容易い御用さ…」
Db → C → Fm7    「主人公の座は…」
Db → C          「Emerald, Sapphire, Ruby, Diamond」
Fm7             「散りばめたティアラで…」
```

Verse と同じ ♭VI→V→i が、Fm7 の着地で少し柔らかくなる。「主人公の座は誰にも渡さない」と自己演出の言葉が強まり、宝石の名を並べる行で Db→C と引き伸ばしてから、「ティアラでそうNo.1」の Fm7 に着地する。

### Build 2〜サビ 2（魔法の絨毯に）

Build と同じ和声のカウントダウンを経て、サビ 2 へ。進行は 1 番と同じで、歌詞が「魔法の絨毯」「かぼちゃの馬車」とシンデレラのモチーフへ広がる。2 番は最終行まで Fm7 が付く。

### Cメロ（美しい世界がここにある）

```
Fm7 → Bbm7 → C7 → Fm7 → Ebm7 → Ab    「美しい世界がここにある」
DbM7 → Bbm7                           「眩しすぎる明かりを…」
C7                                    「イメージしてよ ほら」
```

曲の中で和声が最も動く場所だ。Fm7→Bbm7→C7→Fm7 は i7→iv7→V7→i7 の正統な終止で、Bbm7 のサブドミナントの柔らかさが加わる。続く Ebm7→Ab は、Db への ii→V にあたる動きで、ふわりと浮かんで DbM7 に降り立つ。F minor の外の Ebm7 を借りることで、「美しい世界」が一瞬だけ別の光に照らされる。最後は C7 で宙に浮いたまま、大サビへ渡す。

### 大サビ〜Outro

大サビはサビ 1 と同じ構成で、「魔法の絨毯に」から「花火上げるわ」まで 2 番の言葉で歌われる。Outro は Intro と同じ Db→C→Fm7→FmM7→Fm に戻り、FmM7 の謎めいた響きを残して幕を閉じる。

## カタログの中で

Tickey Luppy Doo は、カタログで 3 番目に古い曲であり、徳田光希と大竹智之が手がけた唯一の曲である。BPM 118 はリリース時点ではカタログ最遅で、現在も夜空ウィズユー（100）に次ぐ遅さだ。疾走感 0.1 はカタログの最低値、バンド 1.8 ももちぷる、7777777 に次いで低い。シンセ主体の打ち込みで、ゆっくりと踊らせる曲である。

一方でキュートは 7.1 と高く、子供心も 5.7 ある。マイナーの調で、遅く、それでいてかわいい。この組み合わせが、カタログの中での独特な立ち位置を作っている。同じ F minor でも、山崎あおいの SUMI-HAJI がエモ 8.8、クール 7.4 で大人の情感を描くのに対し、本作はマイナーを幻想とおとぎ話の色として使う。

パジャマ、ドレス、魔法の絨毯、かぼちゃの馬車、ティアラと、非日常の舞台を歌詞で作り込む手法は、のちの GALAXY! GALAXY! の宇宙や Happy Go Round の遊園地にも通じる。その系譜の初期の一曲が、この真夜中の舞踏会だ。

## 総評

♭VI→V→i という 3 つの和音を、素朴に、着飾らせて、カウントダウンで焦らしながら回し続ける。和声の材料は少ないが、その反復こそが呪文になり、魔法の時間を作っている。速さにも凝った和声にも頼らず、物語と言葉の魔法で聴かせる、カタログの中でも異色のファンタジーである。
