# 夜空ウィズユー — 楽曲分析

BPM 100。カタログで最も遅いこの曲は、高速のパーティーチューンを主戦場にしてきた NNBS. が初めて本格的に書いたバラードである。IV から I へ上っていく循環を背骨に、add9、sus4、M7 のテンションでピアノとシンセをきらめかせ、iii と ii の二つの短調の和音で感情の層を描き分ける。聴きどころは、甘いラブソングの中に一度だけ差し込まれる「辛さ」だ。

## 夜空が明けていく IV→V→vi→I

曲を貫くのは Bb→C→Dm→F、**IV→V→vi→I** の循環である。Intro、サビ、アウトロがすべてこの 4 コードでできている。サブドミナントから出発し、ドミナント、vi を経てトニックへ上っていく形で、聴き手を少しずつ高いところへ運んでいく。暗い空が明けていくような開放感がある。

```
Bb → C → Dm → FM7         「夜空またたく…」
Bb → C → Dm → F           「たくさんの…」
Bbadd9 → C → Dm → F       「きっと ずっとずっと…」
Bb → C                    「だから 一緒に…」
BbM7 → F                  「Dreams with you…」
```

サビではこの循環に、曲名を最も高らかに歌う役目が与えられる。「ずっとずっとずっと…」の反復は Bbadd9 から始まり、9 度の浮遊感が「永遠」の感覚を引き延ばす。締めの「Dreams with you」は BbM7→F、**IVM7 から I へのプラガル終止**（ドミナントを経ず、サブドミナントから主和音へ降りる柔らかい終止）で着地する。IVM7 の長 7 度が、夢見心地の響きをそのまま主和音へ持ち込む。

## テンションが描く「そばにいたい」の震え

Bメロでは、テンションを付けた和音が連なる。

```
Bbadd9 → Csus4            「どこまでも 見たいな…」
FM7 → Am                  「心をギュッと…」
Bbadd9 → Csus4 → FM7 → Am 「声を出してずっと…」
Bb → Am                   「言葉だけじゃ 不安だよ」
F → Am                    「すぐいこう…」
Bbadd9 → Csus4            「なんでも楽しいよ」
F → Bb                    「どこまでも だいすきなんだ」
```

Bbadd9（IVadd9）→Csus4（Vsus4）→FM7（IM7）→Am（iii）。どの和音も 9 度、4 度、長 7 度を抱えていて、すっきり解決しない。「キミとずっといたい」という願いの繊細な震えは、この解決しきらない響きから生まれている。

ここで鍵を握るのが **Am（iii）**だ。iii は I と構成音を二つ共有し、主和音の代わりにもなる和音だが、短調なので明るさの中に切なさを忍ばせる。「言葉だけじゃ 不安だよ」で Bb→Am、続いて F→Am と、長調の和音から iii へ落ちる動きが歌詞に陰影を添える。

## Cメロで初めて前に出る ii

そして Cメロで、曲は感情の層を一段深く掘り下げる。

```
Csus4 → Gm → F            「一緒いると 辛くも…」
Bb → F → Bb → C           「優しすぎて…」
F → C                     「誰もいないよ…」
Gm → C                    「ずっと 隣いるよ…」
Bb → F → Bb → C           「世界中の誰よりも…」
```

ここで初めて Gm（ii）が前面に出る。Csus4→Gm→F と降りる動きに乗るのは「一緒いると 辛くも なるんだ」。好きだからこそ辛い、という両義的な感情である。それまで陰りを担ってきた iii（Am）が退き、ii（Gm）に替わる。**同じダイアトニックの短調の和音でも、切なさは Am、苦さは Gm と描き分けられている**。最後は「すきすぎるね」の Bb→C（IV→V）で高まり、ラストサビへ橋を架ける。

## 楽曲を追う

### Intro

```
F
Bb → C → Dm → FM7
Bb → C → Dm → F
Bb C Dm F （×2）
F
```

前述の IV-V-vi-I を、FM7（IM7）を差し込みながら提示する。BPM 100 のゆったりしたテンポで、ピアノとシンセの響きが映える。

### Aメロ（ひとりだと 変わらないこの道）

```
C                         「ひとりだと…」
Bb                        「そこそこ退屈に…」
F/G → C6                  「寂しいや…」
Bb → F                    「キミの笑顔で…」
```

C（V）と Bb（IV）の往復で淡々と進み、「ただただ歩いてた」単調な日々を描く。続く F/G は、F の三和音の下に G を置いた和音である。G9sus4 のように響き、続く C6（V6）へ向けて V/V 的に持ち上げる浮遊感を生む。C6 の 6 度は「全部」というフレーズに柔らかな広がりを与え、最後は Bb→F（IV→I）のプラガルな動きで「無邪気な魔法で」を温かく着地させる。

### Bメロ（どこまでも 見たいな）

前述のテンションの連鎖と、iii（Am）の陰影。2 番の Bメロ（「この先も…」）もほぼ同じ構造だが、歌詞は「すぐいこう」から「すぐきてね」へ、自分から動く言葉が相手を待つ言葉に変わる。「だいすきなんだ」も「ぜんぶぜんぶだいすきなんだ」と、反復で膨らむ。

### サビ（夜空またたく 星のもとで）

前述の IV-V-vi-I。サビの後には Intro の循環が再び置かれ、余韻を作る。

### Dメロ（Dreaming あふれる不安 響いて）

```
F/G → C                   「Dreaming あふれる不安…」
BbM7 → F                  「そんな時は…」
F → C                     「いこう かな…」
BbM7 → F                  「色が変わる…」
```

冒頭の F/G はAメロの再利用で、その宙に浮いた響きが「あふれる不安」を描く。BbM7（IVM7）は「キミの歩幅で」「香り感じる距離で」という親密な言葉に寄り添う。

### Cメロ（一緒いると 辛くも なるんだ）

前述の ii（Gm）の登場。

### ラストサビ

```
Bb → C → Dm → FM7         「夜空またたく…」
Bb → C → Dm → F           「もとで…」
Bbadd9 → C → Dm7 → F      「きっと ずっとずっと…」
Bb → C → Dm → F           「だから 一緒に…」
Bb                        「Dreams with you」
F                         「Dreams with you」
```

サビと同じ進行に、Dm7（vi7）の 7 度を差し込んで終盤の余韻を深める。「Dreams with you」は Bb（IV）と F（I）に一つずつ分けて置かれ、ゆっくりと閉じていく。

### Outro（I just wanna be with, with you）

```
Bb → C                    「I just wanna be with…」
Dm → F                    （繰り返し）
Bb → C                    「Oh! Oh! Oh!…」
Dm → F                    （繰り返し）
```

シグネチャーの IV-V-vi-I をそのままアウトロのループにする。シンプルな英語のフレーズから「Oh! Oh! Oh!」のシンガロングへ開いていき、観客が揺れながら一緒に歌える。バラードでありながら、ライブの一体感で締めくくる設計だ。

## カタログの中で

BPM 100 はカタログ最遅で、それまで最も遅かった Tickey Luppy Doo（118）を 18 下回る。21 曲を手がける NNBS. の作品の中では、次に遅い BOOOOOOON（140）とも 40 の差があり、その異質さは際立つ。疾走感 1.8 は LOOK!! と並んで下から 3 番目で、BPM ではカタログ最遅でも疾走感の最低は Tickey Luppy Doo（0.1）と OK（1.2）に譲る。

和声の作り方には、NNBS. の作家性がそのまま出ている。7777777 の Dbadd9→Eb6→Fm7→Ab も同じ IV-V-vi-I の度数進行にテンションを付けた循環で、ドリーミーなテンション和音への嗜好は高速でも低速でも変わらない。一方で、iii と ii を感情に応じて使い分ける繊細さは、パーティーチューンでは前面に出てこなかったものだ。

エモ 7.2、ハッピー 5.6 という数字は、MAGNET や OK と同じく大人っぽく感情的な側に位置しながら、「だいすきなんだ」「Dreams with you」の温かさで明るい側に踏みとどまっていることを示す。そして「Oh! Oh! Oh!」のシンガロングで終わる構成は、直前の NNBS. 作 MY FIRST LOVE SONG の「LaLaLa I love you」と同じく、言葉のない合唱で曲を閉じる NNBS. のシンガロング志向の表れでもある。

## 総評

IV から I へ上る循環を何度も繰り返し、そのたびにテンションの色を変える。甘い曲である。それでも Cメロの Gm の一瞬があることで、「だいすき」がただの甘さで終わらず、そばにいることの辛さまで引き受けた言葉になる。BPM 100 という、このグループにとって最も遅い速度は、その一瞬を聴かせるために選ばれたように聴こえる。NNBS. の引き出しに、静かに歌い上げるバラードが加わった一曲だ。
