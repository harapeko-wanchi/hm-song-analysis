## 構成とコード進行

### Intro
```
F
Bb → C → Dm → FM7
Bb → C → Dm → F
Bb C Dm F
Bb C Dm F
F
```
- **Bb→C→Dm→F = IV→V→vi→I** — この4コードが楽曲全体を貫くシグネチャー循環
- IV から始まり I に着地する上行型の進行で、夜空が明けていくような開放感
- **FM7（IM7）** の差し込みで透明感を添える。BPM 100 のゆったりしたテンポにピアノ＋シンセの響きが映える

### Aメロ（ひとりだと 変わらないこの道）
```
                  C          "ひとりだと 変わらないこの道"
                  Bb         "そこそこ退屈にただただ歩いてた"
F/G               C6         "寂しいや 辛いことも全部"
        Bb        F          "キミの笑顔で スッと消えて無邪気な魔法で"
```
- **C（V）と Bb（IV）** を軸に淡々と進む。「ただただ歩いてた」の単調さをサブドミナント／ドミナントの往復で描写
- **F/G** = I/V（ドミナント・ペダル）。ベースに G を置いた浮遊感のある「V9sus」的サウンドで、次の C6 へ向けて持ち上げる
- **C6（V6）** の6thが「全部」のフレーズに柔らかな広がりを与える
- 最後の Bb→F（IV→I）プラガル・モーションで「無邪気な魔法で」を温かく着地

### Bメロ（どこまでも 見たいな）
```
Bbadd9 → Csus4            "どこまでも 見たいな となり いたいって"
FM7 → Am                  "心をギュッと 離さないで"
Bbadd9 → Csus4 → FM7 → Am "声を出してずっと そばにいるんだ 言わなきゃ"
Bb → Am                   "言葉だけじゃ 不安だよ"
F → Am                    "すぐいこう 隣いようよ"
Bbadd9 → Csus4            "なんでも楽しいよ"
F → Bb                    "どこまでも だいすきなんだ"
```
- **Bbadd9（IVadd9）→ Csus4（Vsus4）→ FM7（IM7）→ Am（iii）** — テンションコードを連ねたドリーミーな循環
- **add9 / sus4 / M7** の多用が「キミとずっといたい」という願いの繊細な震えを表現
- **Am（iii）** の頻出が effective — I の代理として明るさの中に切なさを忍ばせる
- Bb→Am、F→Am の **長調→iii** の動きが「不安だよ」の歌詞に陰影を添える

### サビ（夜空またたく 星のもとで）
```
       C → Dm → FM7         "夜空またたく 星のもとで"
Bb → C → Dm → F            "たくさんの 夢を光らせる つかもう"
Bbadd9 → C → Dm → F        "きっと ずっとずっとずっとずっとずっと ずっとさ"
Bb → C                     "だから 一緒にいようね 叶えるんだ"
BbM7 → F                   "Dreams with you Dreams with you"

Bb C Dm F
Bb C Dm F
```
- Intro の **IV→V→vi→I** 循環がそのままサビの背骨になる — 曲名「夜空ウィズユー」を最も高らかに歌う場所
- 「ずっとずっとずっと…」の反復を **Bbadd9→C→Dm→F** に乗せ、テンションコードの浮遊感で「永遠」の感覚を演出
- **BbM7（IVM7）→ F（I）** で「Dreams with you」を着地 — IVM7 のメジャー7thが夢見心地を象徴
- サビ後に Intro の IV-V-vi-I 循環を再掲し、余韻を作る

### Dメロ（Dreaming あふれる不安 響いて）
```
F/G                        C    "Dreaming あふれる不安 響いて"
              BbM7              F "そんな時はキミの歩幅で歩いてる"
        F                  C    "いこう かな どんなに長い道も"
              BbM7              F "色が変わる 香り感じる距離でいたいな"
```
- **F/G**（ドミナント・ペダル）で再び浮遊感を呼び込み、「あふれる不安」を不安定な響きで描写
- **BbM7（IVM7）** が「キミの歩幅で」「香り感じる距離で」の親密なフレーズに寄り添う
- Aメロの F/G を Dメロ冒頭に再利用し、構造的な呼応を作る

- 「だいすきなんだ」が「ぜんぶぜんぶだいすきなんだ」へと増幅

### Cメロ（一緒いると 辛くも なるんだ）
```
Csus4 → Gm → F            "一緒いると 辛くも なるんだ"
Bb → F → Bb → C           "優しすぎて あえない 時が長過ぎて"
F → C                     "誰もいないよ キミ だけなんだ"
Gm → C                    "ずっと 隣いるよ約束だよ"
Bb → F → Bb → C           "世界中の誰よりもだいすき すきすぎるね"
```
- **Gm（ii）** がこの曲で初めて前面に出る — 「辛くもなるんだ」の苦さをダイアトニックの ii minor で表現
- **Csus4（Vsus4）→ Gm（ii）→ F（I）** の下降が「一緒にいるからこその辛さ」という両義的な感情を和声化
- それまで iii（Am）で陰影を付けていた楽曲が、Cメロで ii（Gm）に切り替え、より深い感情の層へ
- 「すきすぎるね」で Bb→C（IV→V）と高まり、ラストサビへ橋渡し

## 楽曲の特徴

### コード面
1. **IV→V→vi→I（Bb-C-Dm-F）シグネチャー循環** — Intro・サビ・アウトロを貫く背骨。上行して I に着地する開放的な進行で「夜空ウィズユー」の世界観を統一
2. **テンションコードの多用（add9 / sus4 / M7 / 6th）** — Bbadd9, Csus4, FM7, C6, BbM7, Dm7。ピアノ＋シンセのきらめく響きで夢見心地のテクスチャを形成
3. **F/G ドミナント・ペダル** — Aメロ・Dメロ冒頭で浮遊感を呼び込み、「不安」の感情を不安定な和声で描写
4. **iii（Am）と ii（Gm）の使い分け** — Bメロでは Am で明るさの中の切なさを、Cメロでは Gm で「一緒にいるからこその辛さ」を表現。マイナー・ダイアトニックの2種で感情の層を描き分ける
5. **プラガル・モーション（Bb→F = IV→I）** — Aメロ末・サビで多用し、ドミナント解決とは違う温かい着地感を生む

### リズム・サウンド面
- **BPM 100 はカタログ最遅** — 従来最遅だった Tickey Luppy Doo（118）を大幅に下回る、Hey!Mommy! 初のスロー〜ミディアムバラード
- ピアノ＋シンセ＋ギターの編成。打ち込み高速パーティーを主戦場とする NNBS. にとって異色のバラード路線
- ゆったりしたテンポ上でテンションコードのきらめきとボーカルの語りが主役になる構成

### 歌詞面
- 「**夜空またたく 星のもとで / たくさんの夢を光らせる つかもう**」— 夜空と星をモチーフにした、二人で夢を叶えていく王道ラブソング
- 「**Dreams with you**」「**I just wanna be with, with you**」— 曲名「ウィズユー」を英語フレーズで繰り返し、「キミと一緒に」を核に据える
- 「**言葉だけじゃ 不安だよ / すぐいこう 隣いようよ**」— 言葉を超えて隣にいたいという切実さ
- 「**一緒いると 辛くも なるんだ / 優しすぎて あえない 時が長過ぎて**」（Cメロ）— 愛情の深さゆえの苦さを描く両義的なパート。Gm（ii）の和声と完全に呼応
- 「**世界中の誰よりもだいすき すきすぎるね**」— Cメロのクライマックスでストレートな愛情を吐露
- 「**ぜんぶぜんぶだいすきなんだ**」— 反復による感情の増幅。NNBS. 流の素直な肯定

## Hey!Mommy! 楽曲群での位置づけ

- **BPM 100 はカタログ最遅** — 従来最遅の Tickey Luppy Doo（118）を18BPM 下回る。高BPMパーティーチューンを量産してきた NNBS. が初めて本格バラード領域に踏み込んだ一曲
- **Map B（サウンド・エンジン）で最下部に位置** — speed 1.8 はカタログ最低水準。MY FIRST LOVE SONG（BPM 220, speed 8.8）とは NNBS. 作品の両極を成す
- **IV→V→vi→I のシグネチャー循環** — 7777777 の IV-V-vi-I 装飾循環（Dbadd9→Eb6→Fm7→Ab）と同じ度数進行を、ストレートなバラードのテンポで再構築。NNBS. が高速でも低速でも IV-V-vi-I を愛用する証拠
- **テンションコード（add9/sus4/M7）への嗜好**は 7777777 と共通。NNBS. のドリーミーなサウンドアイデンティティがバラードでも貫かれている
- **iii（Am）と ii（Gm）の感情的使い分け**は、これまでパーティーチューンでは見られなかった繊細さ。NNBS. の作家性に「エモーショナルなバラード」という新たな引き出しが加わった
- Map C（エモーション）で **大人っぽい×エモーショナル象限** に位置。MAGNET や OK といったエモ系バラード群に連なりつつ、「だいすきなんだ」「Dreams with you」の温かさで happy 寄りに踏みとどまる
- 「**Oh! Oh! Oh!**」「**I just wanna be with, with you**」のシンガロング・アウトロは、バラードでありながらライブの一体感を生む設計 — MY FIRST LOVE SONG の「LaLaLa I love you」と同じく、NNBS. のシンガロング志向が表れている
