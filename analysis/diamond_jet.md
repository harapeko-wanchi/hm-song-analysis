## 構成とコード進行

### Intro
```
| Eb  Bb | Ab    Ab |
| ---- --- -| | ----- ----|
| Eb  Bb | Ab |        | Eb  Bb | Ab |
  Oh oh   oh  oh oh     Oh oh   oh  oh oh
```
- **I-V-IV** — 3コードの開放的フック
- Oh oh oh のコーラスを最初に提示 — 曲の「顔」を先に見せるポップ戦略

### Verse A（鼓動が高鳴る / イヤフォンの音）
```
| Eb  Bb | Ab |             | Eb  Bb | Ab |
  鼓動が  高  鳴る合図       閃<ひらめ>くま  ま   Take a trip

| Eb  Bb | Ab |    | Eb  Bb | Abm    Bb |
  好きなことに熱くなれば   New wave   風を起 こす
```
- 前半: I-V-IV の3コード反復 — シンプルなまま疾走
- 後半: **Abm（iv）** — 同主調（Eb minor）からの借用。IV（Ab）→ iv（Abm）の明暗切替
- 「風を起こす」で iv が登場 — 逆風の中を飛ぶイメージと同主調借用の陰りが一致

### Verse B（見た事ない色で / 一人じゃ気付けない）
```
| Ab  Bb | Gm      Cm  |
  見た事   ない色で 自由を 踊るの
| Db      | Ab/C    Abm/B |
  Ready s   teady   go ついてきて
```
- **IV-V-iii-vi**: ダイアトニック循環の変形 — iii（Gm）が初登場
- **Db（♭VII）**: Mixolydian 借用 — 「Ready」のスタート感
- **Ab/C → Abm/B**: IV/3 → iv/♯5。バスラインが **C → B(= Cb)** と半音下行 — steady → go の「加速」を低音クロマティックで表現
- Abm/B は iv の第2転回と解釈可能だが、低音 Cb（= B）は ♭VI 的レゾナンスを持つ

### Bridge（虹の向こう / 君と越えてく）
```
| Fm      Gm |         | Abm    Bb |
  虹の向こう   君となら   絶対行け  る

| Fm      Gm |         | Abm    Bb |
  君と越え  てく エンディングの ない旅 を
```
- **ii-iii-iv-V** — ii から V へ順次上行、iii を経由して iv（Abm）に着地
- **iii（Gm）→ iv（Abm）**: ダイアトニック iii からモーダル iv への半音接続（G→Ab の半音上行 + Bb→Ab の暗転）
- 「絶対行ける」「エンディングのない旅」— iv の影を V（Bb）が即座に解決する「希望に変わる瞬間」

### Chorus（飛び立て Carry on）
```
| Eb      Bb/D |                  | Cm7    Bb |
  飛び立て Carry on   ときめいた大空<おおぞ ら>へ私<わたし>を描こう

| AbM9        | Eb/G  Ebsus4/G | Eb/G       | AbM9  Bbsus4  Bb |
  奇跡のジェットに  乗っ   て     （Let me fly） 全部叶え      たい

| Eb      Bb/D |              | Cm7    F7 |
  大人も 知らない   この胸にある世  界 信<しん>じなくちゃ

| Ab  Fm | Eb      Abm    Bb |
  目の前<まえ>の 笑顔<えがお> 守<まも>れないから
```
- **第1行**: I → V/3 → vi7 → V — バスライン **Eb → D → C → Bb**（半音＋全音の順次下行）
- **第2行**: **AbM9 → Eb/G → Ebsus4/G → Eb/G → AbM9 → Bbsus4 → Bb**
  - **AbM9（IVM9）**: IV に9th（Bb）と maj7（G）を加えた拡張テンション — 「奇跡のジェット」の浮遊感
  - **Ebsus4/G（Isus4/3）**: I の 3rd を sus4（Ab）に置換し、低音 G でバス保持 — 「乗って」の瞬間浮く感覚
  - **Bbsus4 → Bb**: V のサスペンション → 解決 — 「全部叶えたい」の願いが解決する
- **第3行**: I → V/3 → vi7 → **F7（II7 = V7/V）** — 「信じなくちゃ」に V7/V の強い前傾
- **第4行**: IV → ii → I → **iv（Abm）** → V — 「笑顔が守れないから」の切なさに iv

### Verse 2（夢<ゆめ>に向かう / 強く光る日差しと）
```
| Eb  Bb | Ab |          | Fm  Gm | Abm    Bb |
  夢<ゆめ>に向 かう 毎日は Be happ y  何を 着よう
```
- Verse A と同構造 + Fm-Gm-Abm-Bb（Bridge 動機の挿入）— 2番でブリッジ素材を先取り

### Coda（可能性は誰にも決められはしない）
```
| Cm Cmsus2  Cmsus4 | Cm  Bb | Ab        |
  可能          性は   誰  にも決め  られはしない

| Fm7  Eb | Ab    |
  繋い  てくSt ory（Story）

     | Bbsus4  Bb |     Eb    Bb  |
  約束のステ    ージが  呼んでいる から  ----|
```
- **Cm → Cmsus2 → Cmsus4 → Cm**: vi のサスペンション変容 — 3rd を sus2（D）→ sus4（F）に揺らし戻す
  - 「可能性は」の歌詞に合わせ、Cm の内部音が「可能性」を探るように動く
- **Fm7 → Eb → Ab**: ii7 → I → IV — 穏やかな着地
- **Bbsus4 → Bb → Eb → Bb**: V サスペンション解決 → I-V で飛翔

### Outro
```
| Cm  Bb | Ab  Eb |  Ab   Bb |
| ---- ----| ---- ----|   | ---- ---- |
```
→ Oh oh oh × 2 → 「もっと輝くかがやいて」→ Fly high
- vi-V-IV-I-IV-V の循環で余韻 — 最後は Eb → Abm → Eb で「Fly high」

### Final Chorus（最終リピート）
```
| AbM9      | Eb/G  Ebsus4/G | Eb/G      | Ab  Am7-5  Bbsus4  G7 |
  奇跡のジェットに  乗っ   て    （Let me fly） 全部  叶え         たい

| Cm        Bb/D  |      Eb     | F7        |
  大人も 知らない   この胸にある世 界 信<しん>じなくちゃ
```
- **Ab → Am7-5 → Bbsus4 → G7**: 最終コーラス限定の4和音連結
  - **Am7-5（♯IVm7♭5）**: Ab → Am7-5 で半音上行パッシング。Eb key では ♯iv° 系和音
  - **G7（III7 = V7/vi）**: Cm（vi）へのセカンダリードミナント — 最終リピートでのみ登場する「ここ一番」の色彩

## 特徴分析

### 1. 全曲最多 21コード
Hey!Mommy! 全楽曲中最多のコード種数。比較:
| 曲 | コード数 | 作曲者 |
|----|---------|--------|
| DIAMOND JET | **21** | 阿久津健太郎 |
| SUPER MOMMY GIRLS | 15 | NNBS. |
| Summer land | 14 | しえりーほ |
| 恋するとちゅう | 13 | NNBS. |
| ご機嫌マミーはご機嫌ガール | 13 | AILI |
| もちぷる | 6 | NNBS. |

外部作家（阿久津健太郎）ならではの「職業作曲家的」コードパレット。サスペンション系（sus2, sus4, Bbsus4, Ebsus4/G）、拡張テンション（AbM9）、パッシング（Am7-5）を駆使する J-POP 王道のリッチハーモニー。

### 2. iv（Abm）同主調借用 — 全セクション横断
Abm は Verse A, Verse B後半, Bridge, Chorus, Outro のすべてに登場。「風を起こす」「go」「絶対行ける」「守れないから」— 前進する瞬間に必ず iv の影が射す。**逆風の中を飛ぶ** という曲のテーゼを和声レベルで体現。

### 3. F7（V7/V）— コーラス第3行の頂点
Chorus の「信じなくちゃ」で vi7（Cm7）→ F7（V7/V）。ダイアトニックなら vi → V だが、V7/V を挿入することで **Bb（V）への解決エネルギーが二重になる**。「信じなくちゃ」の意志の強さを和声が増幅。

### 4. AbM9 → Eb/G → Ebsus4/G 浮遊コーラス
「奇跡のジェットに乗って」のハーモニー:
| コード | 機能 | 内声 |
|--------|------|------|
| AbM9 | IVM9 | Ab-C-Eb-G-Bb — 9th(Bb)と7th(G)で浮遊 |
| Eb/G | I/3 | バス G 保持 — 低音安定×上が飛ぶ |
| Ebsus4/G | Isus4/3 | 3rd(G)→sus4(Ab) — 一瞬の「浮き」 |
| Eb/G | I/3 | sus4 解決 — 着地 |

「ジェットに乗る」→ sus4 で浮く → 解決で着地。歌詞のアクションと和声のテンション-リリースが完全同期。

### 5. Cmsus2 → Cmsus4 → Cm（vi サスペンション変容）
Coda の「可能性は誰にも決められはしない」:
- Cm(sus2) = C-D-G — 2nd が開いた明るい響き
- Cm(sus4) = C-F-G — 4th の緊張
- Cm = C-Eb-G — 短3度に戻る

vi の内部が **sus2 → sus4 → natural** と揺れ動く — 「可能性」を模索する和声的メタファー。

### 6. Am7-5（♯IVm7♭5）パッシング
最終コーラスのみ Ab → **Am7-5** → Bbsus4 → G7。Am7-5 は A-C-Eb-G で、IV(Ab) と Vsus4(Bbsus4) の間を **半音パッシング** で繋ぐ。全曲通じてのラスト・スパートの「一瞬の翳り」。

### 7. G7（V7/vi）最終コーラス限定
G7 = B♮-D-F-G の vi（Cm）へのセカンダリードミナント。通常コーラスには存在せず、**最終リピートの「全部叶えたい」でのみ出現**。曲全体のクライマックスを和声的にマーキング。

### 8. リードギター＋ギターソロ
Hey!Mommy! 楽曲で本格的なギターソロを持つ稀有な作品。打ち込み系主体のカタログにおいて、バンドサウンドの厚みが異質な texture を与える。

## 阿久津健太郎 × Hey!Mommy! カタログ比較

DIAMOND JET は Hey!Mommy! で唯一の阿久津健太郎作品。レギュラー作家（NNBS., AILI, しえりーほ）との差異:

| | NNBS. 平均 | AILI 平均 | しえりーほ平均 | 阿久津(DIAMOND JET) |
|---|-----------|----------|-------------|-------------------|
| コード数 | 5〜15 | 11〜13 | 12〜14 | **21** |
| 非ダイアトニック | 1〜3種 | 2〜4種 | 3〜5種 | **6種** |
| sus 系 | 稀 | なし | なし | **4種** (sus2/sus4/Vsus4/Isus4) |
| 拡張テンション | add9 程度 | M7 程度 | M7/6/add9 | **M9, m7-5** |
| バンド感 | 低 (band 0.5-2.0) | 低 (band 1.0) | 中 (band 2.0-3.5) | **高 (band 4.0)** |
| ギターソロ | なし | なし | なし | **あり** |

**異質さの核心**: J-POP 職業作曲家的な「和声のフルコース」を Hey!Mommy! のキラキラアイドルポップに注入。iv(Abm) の全セクション横断使用は「飛翔の影」として統一感を与え、sus/テンション系の多用は「浮遊する飛行感」を和声で描く。
