# DIAMOND JET — 楽曲分析

ギターソロを擁する骨太のエモ・ロックで、阿久津健太郎がこのカタログに書いた唯一の曲である。前へ飛び出す瞬間に必ず差し込む iv（Abm）の影、sus4 で浮いては着地するサビ、そして最後のリピートだけに取っておいた二つの和音。21 種の和音はリリース時点のカタログ最多で、今も Hey!Yummy! に次ぐ。逆風の中を飛ぶ、というテーマを和声で書き切った一曲だ。

## 前に進むたび差し込む iv の影

この曲の和声を一つの和音で語るなら、Abm である。Eb major の IV は Ab だが、その 3 度を半音下げた Abm は、同じ主音を持つ Eb minor から借りてきた iv だ。明るい IV が、一瞬だけ曇る。

```
Eb → Bb → Ab              「好きなことに熱くなれば」
Eb → Bb → Abm → Bb        「New wave 風を起こす」
```

Aメロでは I→V→IV の 3 和音の反復が続き、その最後の行で初めて Ab が Abm に替わる。歌われるのは「風を起こす」。前へ進もうとする言葉の下で、和声がふっと陰る。この Abm は Aメロ、Bメロ、ブリッジ、サビ、アウトロと、曲のほぼすべてのセクションに顔を出す。「Ready steady go」で、「絶対行ける」で、「守れないから」で、そして最後の「Fly high」で。**前進する瞬間には、必ず iv の影が射す**。

それでも Abm は、ほとんどの場合すぐに V の Bb へ進み、解決の側へ引き戻される。影が射しても飛ぶのをやめない。逆風を受けて揚力を得る、という飛行の比喩が、和声の上ではこの iv→V の繰り返しとして描かれている。

## 「奇跡のジェット」で浮き、着地する

サビは 4 行で、行ごとに違う技法が仕込まれている。

```
Eb → Bb/D → Cm7 → Bb                                「飛び立て Carry on…」
AbM9 → Eb/G → Ebsus4/G → Eb/G → AbM9 → Bbsus4 → Bb  「奇跡のジェットに乗って…全部叶えたい」
Eb → Bb/D → Cm7 → F7                                「大人も知らない…信じなくちゃ」
Ab → Fm → Eb → Abm → Bb                             「目の前の笑顔…」
```

1 行目はベースが Eb→D→C→Bb と順に下りていく。Bb/D は V の 3 度をベースに置いた転回形で、低音を滑らかにつなぐための形だ。

2 行目が、このサビの見せ場である。AbM9 は IV に長 7 度の G と 9 度の Bb を加えた和音で、地面から少し浮いたような響きを持つ。続く Eb/G は低音に G を据えたまま、上の和音を Ebsus4/G へ動かす。3 度の G が 4 度の Ab に吊り上げられ、一瞬だけ足が浮く。そして Eb/G に戻って着地する。**「ジェットに乗って」で浮き、「Let me fly」で降りる**。歌詞の動作と、和声の緊張と解放が同期している。行末の Bbsus4→Bb も同じ形で、「全部叶えたい」の願いが V の上で一度吊り上げられてから解決する。

3 行目は vi7 の Cm7 の後に F7 が来る。F7 は V の Bb へ向かう二次ドミナント（V7/V）で、普通なら vi→V と進むところに一段階のドミナントを挟むことで、Bb への引力が二重になる。「信じなくちゃ」の意志の強さを、和声が押し上げている。4 行目は IV→ii→I と穏やかに下ってから、ここでも Abm が現れる。「笑顔が守れないから」という、曲で最も切実な言葉の下だ。

## 最後のリピートだけに取っておいた二つの和音

曲の最終盤、サビの 2 行目がもう一度歌われるとき、進行が書き換えられる。

```
AbM9 → Eb/G → Ebsus4/G → Eb/G → Ab → Am7-5 → Bbsus4 → G7   「奇跡のジェットに…全部叶えたい」
Cm → Bb/D → Eb → F7                                          「大人も知らない…」
```

通常のサビでは AbM9→Bbsus4→Bb だった行末が、Ab→Am7-5→Bbsus4→G7 になる。Am7-5 は A を根音にした半減七の和音（#IVø）で、Ab と Bb の間を半音で埋める経過和音だ。ベースが Ab→A→Bb と半音ずつ上がり、最後のスパートに一瞬の翳りを差す。

そして G7。Cm（vi）へ向かう二次ドミナント（V7/vi）で、B♮ の音が鳴る。G7 はこの最終リピートにしか登場しない。それまで何度も同じ形で歌われてきた「全部叶えたい」が、最後の一回だけ、それまでなかった色彩で照らされる。曲全体のクライマックスを、和声の上で印をつけるように示しているのだ。

## 楽曲を追う

### Intro

```
Eb → Bb → Ab → Ab
Eb → Bb → Ab        「Oh oh oh oh oh」（×2）
```

I→V→IV の 3 和音に、「Oh oh oh」のコーラスを乗せる。曲の顔を最初に見せてしまう、ポップスの常套手段である。

### Aメロ（鼓動が高鳴る合図）

```
Eb → Bb → Ab              「鼓動が高鳴る合図」
Eb → Bb → Ab              「閃くまま Take a trip」
Eb → Bb → Ab              「好きなことに熱くなれば」
Eb → Bb → Abm → Bb        「New wave 風を起こす」
```

前述のとおり、I→V→IV の反復で疾走した後、最後の行で Abm が初めて現れる。

### Bメロ（見た事ない色で）

```
Ab → Bb → Gm → Cm         「見た事ない色で…」
Db → Ab/C → Abm/B         「Ready steady go…」
```

IV→V→iii→vi のダイアトニックな循環で、ここで初めて iii の Gm が出る。2 行目の Db は ♭VII で、Eb ミクソリディアンから借りた和音が「Ready」のスタートの合図になる。続く Ab/C から Abm/B では、ベースが C から B（Abm の 3 度 Cb を B と表記したもの）へ半音下がる。IV の第 1 転回形が、そのまま iv の第 1 転回形に暗転する形で、「steady」から「go」への加速を低音の半音で描いている。

### ブリッジ（虹の向こう）

```
Fm → Gm → Abm → Bb        「虹の向こう 君となら…」
Fm → Gm → Abm → Bb        「君と越えてく…」
```

ii→iii→iv→V と、ベースが F→G→Ab→Bb と順に上がっていく。Gm の 3 音（G・Bb・D）がそろって半音上がると、Abm（Ab・Cb・Eb）になる。ダイアトニックの iii が、平行移動でそのまま調の外の iv へずれ込むのだ。iv の影を V の Bb がすぐに解決し、「絶対行ける」「エンディングのない旅」と、陰りが希望に変わる瞬間を作る。

### サビ（飛び立て Carry on）

前述の 4 行。

### 2番 Aメロ（夢に向かう毎日は）

```
Eb → Bb → Ab → Fm → Gm → Abm → Bb      「夢に向かう毎日は Be happy…」
```

Aメロと同じ骨格に、ブリッジの Fm→Gm→Abm→Bb の動機を差し込む。2 番の途中でブリッジの素材を先取りし、曲の流れを詰めていく。

### Coda（可能性は誰にも決められはしない）

```
Cm → Cmsus2 → Cmsus4 → Cm → Bb → Ab     「可能性は…」
Fm7 → Eb → Ab                           「繋いでくStory（Story）」
Bbsus4 → Bb → Eb → Bb                   「約束のステージが…」
```

Cm の内側が動く。3 度を 2 度の D に開いた Cmsus2、4 度の F に吊り上げた Cmsus4、そして短 3 度の Eb に戻る Cm。明るく開いた響きから緊張を経て、元の陰りへ。vi の和音の中身が揺れ動くさまが、「可能性は誰にも決められはしない」と、まだ形の決まらない可能性を探る言葉と重なる。その後は Fm7→Eb→Ab（ii7→I→IV）で穏やかに着地し、Bbsus4→Bb の解決から I→V で再び飛び立つ。

### 最終サビ

前述の Am7-5 と G7 を含む書き換え版。

### Outro

```
Cm → Bb → Ab → Eb → Ab → Bb       「Oh oh oh」（×2）…「もっと輝くかがやいて」
Eb → Abm → Eb                     「Fly high」
```

vi→V→IV→I→IV→V の循環で余韻を引き、最後の「Fly high」は Eb→Abm→Eb で閉じる。曲の最後の最後まで、iv の影は消えない。

## カタログの中で

DIAMOND JET の 21 種の和音は、リリース時点でカタログ最多だった。それまでの上位は SUPER MOMMY GIRLS の 15 種、Summer land の 14 種、恋するとちゅうやご機嫌マミーはご機嫌ガールの 13 種で、レギュラーの作家陣とは一段違う量である。その後、AILI の OK（19 種）が迫り、半年後の Hey!Yummy! が 35 種で大きく更新した。複雑さ 8.8 も今は Hey!Yummy! の 9.9 に次ぐカタログ 2 位だ。sus2・sus4 のサスペンション、AbM9 の拡張テンション、Am7-5 の経過和音と、J-POP の職業作曲家らしい語彙が並ぶ。その Am7-5 は、Hey!Yummy! でも半音の接着剤として再び使われることになる。

数字の上では、クール 8.2 とエモ 7.7 を両立させた点が際立つ。クールは MAGNET（9.9）と Hey! get up kids（8.8）に次ぐ 3 位で、リリース時点では MAGNET に次ぐ 2 位だった。エモも Next Story、SUMI-HAJI、MAGNET、MY FIRST LOVE SONG に次ぐ 5 位にある。格好良さと切なさの両方が上位に入る曲は、このカタログでも多くない。

サウンドの面では、リードギターとギターソロが前に出る。分析した中でギターソロに触れているのは、本作のほかに CANDY POP とカラフルポップレジスタンスくらいで、打ち込みが主体のカタログでは目立つ存在だ。バンド 7.4 で BPM 149 という組み合わせも珍しく、バンドの数値が本作より高い曲は軒並み BPM 170 を超える。後に出たジェットコースターLIFE!!（BPM 142、バンド 7.0）が、ミドルテンポのバンド曲としては最も近い位置にいる。

## 総評

iv の影を全編に差し込みながら、そのたびに V で前を向く。sus4 で浮いては着地し、最後のリピートにだけ G7 の色彩を残しておく。和音の数は多いが、どれも「飛ぶ」という一つの動作のために配置されていて、散漫にならない。キラキラしたアイドルポップのカタログに、職業作曲家の和声の手さばきと、ギターロックの熱量を同時に持ち込んだ。Hey!Mommy! の「格好いい」側を代表する一曲である。
