# Voyage! — 楽曲分析

「ノーバリーノーズ」を合言葉に大海原へ漕ぎ出す、AILI の航海ソングである。骨格は IV-vi-V-I という最もまっすぐなポップ進行だが、半音で揺れる波のオスティナート、ダイアトニックの外を駆け上がる間奏、アウトロでの半音上転調と、要所に知的なフックが仕込まれている。分かりやすさと驚きを両立させた冒険の歌だ。

## IV-vi-V-I という王道のエンジン

サビは E→G#m→F#→B、**IV→vi→V→I** の 4 小節をひたすら回す。

```
E → G#m → F# → B    「全身全力で超えていこ」…
E → G#m → F# → B    「何も心配ないから行くよ！」…
```

J-POP の王道ともいえる上昇感のある進行で、IV から始まって I に着地するたびに、一歩ずつ前へ進む感覚が生まれる。「超えていこ」「行くよ！」という歌詞の前進感とぴったり重なり、4 小節の短いループの反復がライブでのコール＆レスポンスを誘う。曲のコアメッセージ「未来はノーバリーノーズ」もこのループの上で歌われる。

ラストのサビでも進行は変わらない。変わるのは歌詞で、「全身全力」が「全身全霊」に格上げされ、「子ども心を 常に忘れず」という一節が加わる。Hey!Mommy! というグループの理念そのもののような言葉だ。

## 半音で揺れる波 — 面舵いっぱいのオスティナート

この王道の曲に、一か所だけ異質な場面がある。「面舵いっぱい！」から始まる D セクションだ。

```
Bbdim(omit3) ↔ Bsus4(omit5)    （交互）「面舵いっぱい！」…「Shine like a star」
```

Bbdim と Bsus4 が交互に鳴り、Bb（＝A#）と B の間を半音で行き来する。3 度や 5 度を抜いた形なので、パワーコードのような硬さと、どちらにも決まらない不安定さが同居する。この半音の揺れが、船を揺らす波のように聴こえる。

歌詞も航海のイメージを徹底していて、「大海原へ帆を立てて」と漕ぎ出し、「メーデーメーデー！」と嵐に遭い、「オーマイ ガって 乗り越えて」と困難を笑い飛ばす。打ち込みのリズムが刻む緊張の上で揺れ続け、最後の「Shine like a star」で解放される。**王道の進行の中に置かれたこの数小節が、曲のスケールを一段大きくしている**。

## ダイアトニックの外を駆け上がる間奏

D セクションのあとの間奏は、曲の中で最も格好いい瞬間と言っていい。

```
E/G# → G#m/B → B/D# → B/F# → G#m
F# → G → G# → B7
```

前半は転回形を使ってベースを G#→B→D#→F#→G# と 3 度ずつ駆け上がらせる。後半は F#→G→G#→B7 と半音ずつのクロマティックな上行になる。G（♭VI）も G#（長三和音の VI）も B major のダイアトニックの外にある和音で、調の枠を堂々と突き破っていく。行き着く B7 はトニックに 7 度を足した I7 で、ドミナントの勢いを帯びたまま次のセクションへ強く接続する。

## 楽曲を追う

### Intro

```
B         「Yeah Yeah Yeah…」
Bsus4M7   「Yeah Yeah Yeah…」
```

Bsus4M7 は B に sus4 の E と長 7 度の A# を重ねた浮遊する和音で、航海の出発を告げるきらめきになっている。「Yeah Yeah Yeah ノーバリーノーズ」のコールで、いきなりテンションを上げる。

### フック（Yeah Yeah Yeah ノーバリーノーズ）

```
G#m → B → F# → E
F# → G#m → F# → A
```

IV-vi-V-I の素材を組み替えた進行に、A（♭VII）が現れる。B major から見た借用和音で、明るさを保ったまま一瞬の浮遊感を差し込む。このフックはサビのあとや間奏のあとにも繰り返される。

### Aメロ（イマこの瞬間さえ）

```
E → B → F# → B → F#/A#
E → B → F# → G#m → D#m7
```

IV→I→V→I と進み、F#/A#（V の第 1 転回形）のベース A# が、B と次の行の頭をつなぐ経過音になる。2 周目は G#m→D#m7、vi から iii へと静かに沈んで終わる。「答えは ノーバリーノーズ」と楽天的に歌う歌詞と、内省的な着地が対比をなす。

### Bメロ（WooWaa あなたのことを）

```
E → C#m/E → G#m → F# → B
```

E から C#m/E へ、ベースを E に保ったまま上の和音だけを IV から ii へ移すペダルポイントの手法だ。「WooWaa」の掛け声がキュートな色を添え、「やりたいように やったらいいよ」の自己肯定からサビへ橋を架ける。

### サビ（全身全力で超えていこ）

前述の IV-vi-V-I のループ。

### Cメロ（とはいっても モヤモヤ）

```
G#m → EM7
G#m → EM7
G#m → F# → B
```

vi と IVM7 の往復が、「モヤモヤ」の揺れをそのまま音にする。EM7 の長 7 度は甘く浮遊する響きで、「となりの芝は So Blue」のメランコリーに合う。最後に「断捨離せなネガティブ バイブス」「大冒険 気分コロンブス」と韻を踏みながら F#→B と解決し、ネガティブを振り払う。

### D セクション〜間奏

前述の Bbdim↔Bsus4 の波と、3 度ずつ、半音ずつ駆け上がる間奏。

### ラストサビ（全身全霊で信じてこ）

サビと同じ E→G#m→F#→B。「見たことない景色見たいから」と前を向き、「未来はノーバリーノーズ」で締める。

### アウトロ（Hey Hey Hey Hey Hey mommy）

```
Am → C → G → F
G → Am → G → Bb
Am → C → G → F
G → Am → G → Bb → C
```

ここで B major から C major へ、半音上に転調する。いわゆるトラック・ドライバーズ・モジュレーションで、キーを一段上げることで「Hey mommy」の大合唱の高揚感を最大にする。進行は Am→C→G→F（vi-I-V-IV）という C major のポップの定番だ。そして Bb（C major から見た ♭VII）が再び現れる。フックで B major の A を借りたのと同じ手法を、新しい調で再現しているのだ。最後は C で I に解決し、明るく着地する。

## カタログの中で

AILI のカタログ 5 曲のうち、本作は MAGNET に続く 2 曲目にあたる。MAGNET がクール 9.9 で尖った格好良さを打ち出したのに対し、本作はクール 6.1、子供心 6.3 と、遊び心のある側に寄っている。子供心 6.3 は AILI の 5 曲の中で最も高い。「子ども心を 常に忘れず」という歌詞が、そのまま数値にも表れたかたちだ。

♭VII を主要な色彩に使い、高めの BPM のエレクトロポップでコールを誘う作りは、2 年後のご機嫌マミーはご機嫌ガールにも受け継がれる。ただし盛り上げ方は異なり、本作が転調で盛り上げるのに対し、ご機嫌マミーはご機嫌ガールは ♭VII の変化と N.C. のブレイクで盛り上げる。

終盤で調を上げて最後のギアを入れる手法は、LOVE ME DO DO が大サビで見せる D→E の全音上転調とも通じる。同じポジティブな曲でも、1 週間前の START RUSH!! が「弱さを克服して走る」曲なら、Voyage! は「心配なんて忘れて冒険に出よう」と誘う曲で、アプローチは異なる。

## 総評

IV-vi-V-I の王道で前へ進み、半音の波に揺られ、調の外を駆け上がり、最後は半音上の新しい海へ出る。航海のイメージを、歌詞だけでなく和声の動きでも描き切った曲である。「Hey Hey Hey Hey Hey mommy」の大合唱で終わるアウトロは、セットリストの終盤やアンコールでこそ真価を発揮するだろう。
