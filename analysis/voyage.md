## 構成とコード進行

### Intro
```
B (Yeah Yeah Yeah...)
Bsus4M7 (Yeah Yeah Yeah...)
```
- **Bsus4M7** = B に sus4（E）と M7（A#）を重ねた浮遊和音。航海の出発を告げるキラキラ感
- 「Yeah Yeah Yeah ノーバリーノーズ」のコールで一気にテンションを上げる

### Post-hook（Yeah Yeah Yeah ノーバリーノーズ）
```
G#m B → F# E
F# G#m → F# A
```
- IV-vi-V-I の変形が基盤
- **A (♭VII)** が登場 — B major から見た借用和音。ハッピーを保ちつつ一瞬の浮遊感を挿入
- サビ後・間奏後にも繰り返されるキャッチーなフック

### Aメロ（イマこの瞬間さえ）
```
E → B → F# → B → F#/A#
E → B → F# → G#m → D#m7
```
- **IV→I→V→I→V/VII** — パッシングベース A# が B → F# の間を埋めるウォーキングライン
- 2周目で **G#m → D#m7** に着地し、vi → iii の静かな内省を作る
- 「ヤなこと考えたって 答えは ノーバリーノーズ」の楽天的な歌詞と対比

### Bメロ（WooWaa あなたのことを）
```
E C#m/E G#m → F# → B
```
- **E → C#m/E** = IV → ii/IV。ベースを E に保ったまま上部構造だけ移行するペダルポイント技法
- 「WooWaa」の掛け声がキュートな色彩を添える
- 「やりたいように やったらいいよ」— 自己肯定→サビへの橋渡し

### サビ（全身全力で超えていこ）
```
E → G#m
F# → B
E → G#m
F# → B
```
- **IV-vi-V-I** — J-POP 王道の上昇進行。「超えていこ」「行くよ！」の歌詞とシンクロする前進感
- 4小節ループの反復がライブでのコール＆レスポンスを誘発
- 「何も心配ないから行くよ！ / 未来はノーバリーノーズ」— 曲のコアメッセージ

### Cメロ / ブリッジ（とはいっても モヤモヤ）
```
G#m → EM7
G#m → EM7
G#m → F# → B
```
- **G#m → EM7** の繰り返し。vi → IVM7 の往復が「モヤモヤ」の揺れを音で描写
- **EM7** の長7度が甘く浮遊する響き — 「となりの芝は So Blue」のメランコリー
- 「断捨離せなネガティブ バイブス / 大冒険 気分コロンブス」で F# → B に解決し、ネガティブを振り払う

### Dセクション（面舵いっぱい！）
```
Bbdim(omit3) ↔ Bsus4(omit5) 交互
```
- **Bbdim ↔ Bsus4** = 半音で揺れるオスティナート。Bb（=A#）と B の間を行き来する
- omit3/omit5 により、パワーコード的な硬質さと不安定さが共存
- 「面舵いっぱい！/ 大海原へ帆を立てて」— 航海のイメージがコード進行の「揺れ」とリンク
- 「波はバシャー / メーデーメーデー！/ オーマイ ガって 乗り越えて」— 困難を笑い飛ばす
- 「**Shine like a star**」で解放 — このセクションのクライマックス

### 間奏（クロマティック上行）
```
E/G# → G#m/B → B/D# → B/F# → G#m
F# → G → G# → B7
```
- 前半: **G# → B → D# → F# → G#** の上行ベースライン。3度ずつ駆け上がるダイナミックな動き
- 後半: **F# → G → G# → B7** — **半音クロマティック上行**
  - G (♭VI) と G# (VI) はいずれも B major のダイアトニック外
  - B7 = I7（ドミナント化）として次セクションへ強力に接続
  - このクロマティックラインが楽曲中最も「かっこいい」瞬間

### ラストサビ（全身全霊で信じてこ）
```
E → G#m → F# → B（同一進行）
```
- 歌詞が「全身全力」→「**全身全霊**」にアップグレード
- 「見たことない景色見たいから」「**子ども心を 常に忘れず**」— Hey!Mommy! のグループ理念を反映
- 「未来はノーバリーノーズ」で締め

### アウトロ（Hey Hey Hey Hey Hey mommy）
```
Am → C → G → F
G → Am → G → Bb
Am → C → G → F
G → Am → G → Bb → C
```
- **B major → C major** への **半音上転調（truck driver's modulation）**
- Am-C-G-F = vi-I-V-IV（C major のポップ定番進行）
- **Bb (♭VII in C)** が再び登場 — Aメロ/フックの A (♭VII in B) と同じ手法を新調で再現
- 「Hey Hey Hey Hey Hey mommy」の大合唱で幕 — ライブ映えする最高のエンディング
- 最終 C で I に解決し、明るく着地

## 楽曲の特徴

### コード面
1. **IV-vi-V-I 王道進行** がメインエンジン — 明るく前進する「冒険」の音
2. **Bbdim ↔ Bsus4 オスティナート** — 半音の揺れが「航海の波」を表現する独創的セクション
3. **クロマティック上行 (F#→G→G#→B7)** — ダイアトニック外を堂々と突破する間奏
4. **♭VII 借用和音 (A / Bb)** — B major・C major 両方の調で一貫して使用
5. **B → C 半音上転調** — アウトロで瞬時にキーを上げ、「Hey mommy」の高揚感を最大化
6. **Bsus4M7** — intro の浮遊和音が航海の出発を告げる

### リズム・サウンド面
- **170 BPM** の打ち込み系 — 電子音が波・風・星のイメージを描く
- シンセベースとパッド中心の**フルエレクトロ**サウンド（band 要素はほぼなし）
- Dセクションのオスティナートはリズム隊が刻む緊張感で「航海の嵐」を演出

### 歌詞面
- 「**ノーバリーノーズ (No worries)**」— 全編を貫くキーワード
- 「**全身全力で超えていこ**」→「**全身全霊で信じてこ**」— サビの進化
- 「**面舵いっぱい！**」「**大海原へ帆を立てて**」— 航海メタファーの徹底
- 「**子ども心を 常に忘れず**」— Hey!Mommy! のアイデンティティそのもの
- 「モヤモヤ Boo! / となりの芝は So Blue / ドア閉めろ 敵はジブン」— 弱さの認識と即座の克服
- 「**断捨離せなネガティブ バイブス / 大冒険 気分コロンブス**」— ノリのいい韻
- 「**Shine like a star**」「**Hey Hey Hey Hey Hey mommy**」— ライブアンセム

## Hey!Mommy! 楽曲群での位置づけ

- **「子ども心を常に忘れず」** という歌詞は Hey!Mommy! のグループコンセプトそのもの。象徴曲の一つ
- Map B では **childlike 4.5** がグループ内最高値タイ。「全力はしゃぎ！」象限の最右翼
- IV-vi-V-I という**最もストレートなポップ進行**を採用しつつ、Bbdim↔Bsus4 交互やクロマティック間奏で**知的なフックも確保** — 「わかりやすさ」と「驚き」の両立
- **B → C 半音上転調**のアウトロは、LOVE ME DO DO の Ab→A 転調と同じ手法。ライブでの「もう一段ギアを上げる」効果
- START RUSH!! が「弱さを克服して走る」なら、Voyage! は「心配なんて忘れて冒険に出よう」— **同じポジティブでもアプローチが違う**
- 「Hey Hey Hey Hey Hey mommy」のアウトロ大合唱は、ライブのセットリスト終盤・アンコールに最適な一曲
