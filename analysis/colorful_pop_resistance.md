## 構成とコード進行

### Intro
```
Dm → Bb → F → C
Dm → Bb → F → C → C#dim
Dm → Bb → F → C → C#dim
```
- **Dm→Bb→F→C = vi→IV→I→V** — 楽曲を貫くシグネチャー循環。BABY BABY BABY（Em7-Cadd9-G-D）と同型の vi 始動ループ
- 2巡目以降は小節後半に **C#dim（#V°）** が入り、ベースが C→C#→D と半音上行して Dm に戻る。この1コードがループに「押し戻す」推進力を与える

### Aメロ（楽しみが あふれる Future）
```
Dm → Bb                   "楽しみが あふれる Future"
F → C → C#dim             "どんな困難ばっかりあっても 笑える"
Dm → Bb                   "立ち上がるよ 名もなき勇者さ"
F → C → C#dim             "ワンダフル世界へ 旅立とう"
```
- Intro の循環をそのまま歌に移す。各フレーズ末の **C#dim** が「笑える」「旅立とう」の語尾を持ち上げる
- 2番 Aメロ（個性バラバラ 仲間とミカタ）も同じ進行。末尾だけ **F→C→C#dim→F→G→Dm** となり、G（II = V/V の響き）を一瞬挟んで Dm に着地する

### プレサビ（この想いが たどり着けない 夢の途中）
```
F                         "この想いが"
C → Am → Bb → BbM7/A      "たどり着けない 夢の"
Gm7 → C                   "途中 何度でも"
F                         "何度でも"
C → Am → Bb → BbM7/A      "それさえ あれば 答え"
Gm7                       "はあるよ"
```
- **C→Am→Bb→BbM7/A→Gm7→C = V→iii→IV→IV/3→ii7→V**
- **BbM7/A** でベースが Bb→A→G と順次下降する。「たどり着けない」の歌詞に合わせてベースが沈み、Gm7→C で再び持ち上がる
- 2番では「あきらめなければ 答えはあるから」と同じ進行に、肯定のメッセージを重ねる

### DANCE ブロック（This is the DANCE DANCE）
```
C                         "This is the"
Gm7(omit3)/F → Ddim/F     "DANCE DANCE"
Gm7(omit3)/F → Ddim/F     "DANCE DANCE"
Gm7(omit3)/F → Ddim/F     "1 2"
Gm7(omit3)/F → Ddim/F     "3 Hey!"
```
- **F のトニック・ペダル**の上で上声だけを揺らす
- **Gm7(omit3)/F** は G-D-F（3度を抜いた ii7）を F の上に置いたもの。sus のように開いた響きになる
- **Ddim/F** は D-F-Ab。**Ab は F major の外の音**（同主短調 F minor の ♭3）で、明るいダンスの合間に一瞬だけ影が差す
- 「1 2 / 3 Hey!」のカウントが入る。最後の DANCE ブロックでは **「1 2 / 3 4 / 5 6 / 7 Hey!」まで数え上げて Dm に着地**する。ライブで観客と一緒に数える設計

### サビ（Let's Live SHAKE HIP HANDS UP YEAH!）
```
Dm                        "Let's Live SHAKE HIP HANDS UP YEAH!"
F                         "もきゅもきゅもきゅ もきゅもきゅもきゅ"
Gm                        "Let's Go SHAKE HIP HANDS UP YEAH!"
Bb                        "もきゅもきゅもきゅ"
C → Dm → Bb → F           "SHAKE HIP HANDS UP YEAH!"
C → Dm → Bb → F → C → C#dim "SHAKE HIP HANDS UP YEAH!"
```
- **Dm→F→Gm→Bb→C = vi→I→ii→IV→V**。ベースが **D→F→G→Bb→C** と上がり、これは D マイナー・ペンタトニックそのもの
- 1コード1小節でベースを階段状に押し上げる。英語のコールと「もきゅもきゅ」を交互に置き、テンションを積み上げる
- 「SHAKE HIP HANDS UP」で **C→Dm→Bb→F（V→vi→IV→I）** を2回回して着地する。2回目は C→C#dim を付けて次のセクションへつなぐ
- 2サビでは「もっともっと SHAKE HANDS UP YEAH!」の1巡を追加し、尺を伸ばしてクライマックスを作る

### 間奏
```
Dm → F
Gm → Bb → C
```
- サビのペンタトニック上行ベースを、歌を抜いてインストで提示する（ここがギターソロのパートと思われる）

### Dメロ（Let's DANCE もきゅもきゅ）
```
Dm                        "Let's DANCE もきゅもきゅ"
Bb                        "DADADADADA"
F                         "Let's DANCE もきゅもきゅ"
C → C#dim                 "DADADA DADADA"
（繰り返し）
```
- Intro の **vi-IV-I-V + C#dim** に戻る。ナンセンスワードと「DADADA」のスキャットだけで構成した、コール専用のブロック

### ラスト DANCE ブロック
```
Gm7(omit3)/F → Ddim/F     "DANCE DANCE"（×2）
Gm7(omit3)/F → Ddim/F     "1 2" / "3 4" / "5 6"
Gm7(omit3)/F → Ddim/F → Dm "7 Hey!"
```
- トニック・ペダルのまま7まで数え上げ、**Dm（vi）で終止**する。トニックの F ではなく vi で終わるので、余韻と次への期待が残る

## 楽曲の特徴

### コード面
1. **vi→IV→I→V（Dm-Bb-F-C）シグネチャー循環** — Intro・Aメロ・Dメロを貫く背骨。BABY BABY BABY と同じ vi 始動ループを F major で展開
2. **C#dim（#V°）パッシング・ディミニッシュ** — C→C#→D の半音上行でループを Dm に押し戻す。BABY BABY BABY の Ebdim7 に続く、NNBS. の経過ディミニッシュ
3. **F トニック・ペダル上の Gm7(omit3)/F ↔ Ddim/F** — DANCE ブロックでの上声揺動。Ddim の Ab が同主短調の色を一瞬差し込む
4. **D マイナー・ペンタトニック上行ベース**（D-F-G-Bb-C） — サビで1小節ずつ階段状に上がる
5. **BbM7/A のベース下降**（Bb→A→G） — プレサビ「たどり着けない」の沈み込み
6. **Dm（vi）終止** — トニックに帰らず vi で閉じるエンディング

### リズム・サウンド面
- **BPM 156** はカタログの中速帯（BEACH! BEACH!・Summer land の 155 とほぼ同じ）。NNBS. 作品としては落ち着いたテンポ
- バッキングギターとシンセの編成に**ギターソロ**が入る。打ち込み中心の NNBS. 作品の中ではバンド寄り
- 「DANCE DANCE」「1 2 3 Hey!」「SHAKE HIP HANDS UP」と、テンポではなくコールとカウントで盛り上げる設計

### 歌詞面
- 「**名もなき勇者さ**」「**ワンダフル世界へ 旅立とう**」「**今宵の宴もアゲていこう**」— RPG 的な冒険・勇者モチーフ
- 「**カラフルレジスタンス ここからだ**」— 個性バラバラの仲間が集まって起こす、カラフルな「抵抗」
- 「**たどり着けない夢の途中 何度でも**」「**あきらめなければ 答えはあるから**」— 夢の途中にいる自分への肯定
- 「**もきゅもきゅもきゅ**」「**DADADADADA**」— NNBS. 流のナンセンスワード
- 「**SHAKE HIP HANDS UP YEAH!**」「**TOUCH & DA DA DANCE**」— 体を動かすダンス・コール

## Hey!Mommy! 楽曲群での位置づけ

- **BABY BABY BABY の vi-IV-I-V ループを引き継ぐ**直後のシングル。G major → F major にキーを変え、Ebdim7 → C#dim とパッシング・ディミニッシュも継承している。NNBS. の「vi 始動ループ＋経過ディミニッシュ」が定番化しつつある
- **BPM 156 の中速ダンスチューン**で、NNBS. の高速パーティー路線（180〜220）とは一線を画す。Map B では「バンド寄り×ややグルーヴィ」の位置で、ビスケットケースや Hey! get up kids のような疾走バンド曲とは異なる
- **Map A は中央上**（x -0.5、y +6.0）。かわいいとかっこいいのちょうど中間で「沸かせる」に振った、バランス型のライブ曲
- **カウントアップ・コール**（1〜7まで数える）はカタログでも珍しい演出。Tickey Luppy Doo の「3, 2, 1」カウントダウンとは逆方向の数え方
- 同じ NNBS. の Happy Go Round（BPM 220）と比べると、こちらはテンポを抑え、ペダル和声とペンタトニック・ベースで「踊らせる」方向に振っている
