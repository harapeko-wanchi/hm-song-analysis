# カラフルポップレジスタンス — 楽曲分析

BPM 156。NNBS. の近作としては抑えたテンポで、この曲はスピードではなくコールとカウントで踊らせる。vi-IV-I-V の循環を経過ディミニッシュで回し続け、「This is the DANCE」ではトニックの上で和音を揺らし、サビではベースを一段ずつ押し上げる。聴きどころは、テンポを上げずに熱を上げていく、その積み上げ方だ。

## C#dim がループを押し戻す

曲の背骨は Dm→Bb→F→C、**vi→IV→I→V** の循環である。直前のシングル BABY BABY BABY（Em7→Cadd9→G→D）と同じ vi 始まりのループを、G major から F major に移して使っている。Intro、Aメロ、Dメロがすべてこの循環でできている。

ただし 2 巡目からは、小節の後半に C#dim（#V°、V を半音持ち上げた減三和音）が差し込まれる。ベースは C→C#→D と半音で上がり、そのまま Dm へ戻る。**この一つの和音が、ループを次の周回へ押し戻すばねになっている**。Aメロでは「笑える」「旅立とう」とフレーズの語尾ごとに C#dim が鳴り、言葉の終わりを上向きに持ち上げる。

経過的な減和音は NNBS. の引き出しとして定着しつつある。恋するとちゅうの Adim、Hey! get up kids の Bbdim、BABY BABY BABY の Ebdim7 に続き、本作の C#dim は「vi 始まりのループを半音で締める」という役目に絞り込まれている。

## トニックの上で揺れる「DANCE DANCE」

「This is the DANCE DANCE」のブロックでは、ベースが F に留まったまま、上の和音だけが入れ替わる。

```
C                         「This is the」
Gm7(omit3)/F → Ddim/F     「DANCE DANCE」（×2）
Gm7(omit3)/F → Ddim/F     「1 2」「3 Hey!」
```

Gm7(omit3)/F は 3 度を抜いた ii7（G-D-F）を F の上に置いた形で、sus 和音のように開いた響きを持つ。対する Ddim/F は D-F-Ab。この Ab は F major の外の音で、同主短調 F minor の 3 度にあたる。**明るいダンスの合間に、一瞬だけ影が差す**。トニック・ペダルの安定と、上声の明暗の揺れ。その往復が、踊る身体の振り子のリズムと重なる。

このブロックには「1 2 / 3 Hey!」のカウントが入り、最後の DANCE ブロックでは「1 2 / 3 4 / 5 6 / 7 Hey!」まで数え上げてから Dm に着地する。HELLO!! Hey!! WORLD!! の「1.2.3.GO」が 3 で発射するのに対し、こちらは 7 まで粘る。観客と一緒に数えることを前提にした設計である。

## 一小節ずつ上がるサビのベース

```
Dm                        「Let's Live SHAKE HIP HANDS UP YEAH!」
F                         「もきゅもきゅもきゅ…」
Gm                        「Let's Go SHAKE HIP HANDS UP YEAH!」
Bb                        「もきゅもきゅもきゅ」
C → Dm → Bb → F           「SHAKE HIP HANDS UP YEAH!」
C → Dm → Bb → F → C → C#dim
```

サビは Dm→F→Gm→Bb→C（vi→I→ii→IV→V）。1 小節に 1 和音ずつ、ベースが D→F→G→Bb→C と階段を上る。この 5 音は G マイナー・ペンタトニック（Bb メジャー・ペンタトニック）と同じ音の集まりで、全音と短 3 度だけでできた跳ねるような上り坂になる。英語のコールと「もきゅもきゅ」を交互に置いて、一段ごとに熱量を積む。

頂上の C からは C→Dm→Bb→F（V→vi→IV→I）を 2 回回して着地し、2 回目は C→C#dim を足して次のセクションへつなぐ。2 番のサビでは「もっともっと SHAKE HANDS UP YEAH!」の 1 巡が加わり、尺そのものが伸びてクライマックスになる。

## 楽曲を追う

### Intro

```
Dm → Bb → F → C
Dm → Bb → F → C → C#dim   （×2）
```

1 巡目は素の vi-IV-I-V、2 巡目から C#dim が加わる。曲の基本原理を、歌が入る前に提示してしまう幕開けだ。

### Aメロ（楽しみが あふれる Future）

```
Dm → Bb                   「楽しみが…」
F → C → C#dim             「どんな困難…」
Dm → Bb                   「立ち上がるよ…」
F → C → C#dim             「ワンダフル世界へ…」
```

Intro の循環をそのまま歌に移す。「名もなき勇者さ」「ワンダフル世界へ 旅立とう」と、歌詞は RPG のような冒険の言葉で始まる。2 番の Aメロ（「個性バラバラ…」）も同じ進行だが、末尾だけ F→C→C#dim→F→G→Dm となり、G（II、V/V の響きを持つ和音）を一瞬挟んで Dm に着地する。

### プレサビ（この想いが）

```
F                         「この想いが」
C → Am → Bb → BbM7/A      「たどり着けない…」
Gm7 → C                   「途中 何度でも」
F                         「何度でも」
C → Am → Bb → BbM7/A      「それさえ あれば…」
Gm7                       「はあるよ」
```

C→Am→Bb→BbM7/A→Gm7→C、つまり V→iii→IV→IV/3→ii7→V。BbM7/A でベースが Bb→A→G と順に下がり、「たどり着けない」という言葉に合わせて低音が沈む。そこから Gm7→C で持ち直す。2 番では同じ進行に「あきらめなければ 答えはあるから」が乗り、沈んでも答えはある、という肯定に変わる。

### DANCE ブロック〜サビ

前述のとおり、F のペダル上の揺れからカウントを経て、ペンタトニックの階段を上るサビへ入る。

### 間奏

```
Dm → F
Gm → Bb → C
```

サビの上行ベースを、歌を抜いて楽器だけで示す。編成にあるギターソロはここに入ると思われる。

### Dメロ（Let's DANCE もきゅもきゅ）

```
Dm                        「Let's DANCE もきゅもきゅ」
Bb                        「DADADADADA」
F                         「Let's DANCE…」
C → C#dim                 「DADADA…」
```

Intro の vi-IV-I-V ＋ C#dim に戻り、ナンセンスワードと「DADADA」のスキャットだけで組んだコール専用のブロックになる。

### ラスト DANCE ブロック

```
Gm7(omit3)/F → Ddim/F     「DANCE DANCE」（×2）
Gm7(omit3)/F → Ddim/F     「1 2」「3 4」「5 6」
Gm7(omit3)/F → Ddim/F → Dm「7 Hey!」
```

トニック・ペダルのまま 7 まで数え上げ、最後は F ではなく Dm（vi）で終わる。主音に帰らない終止が、余韻と次への期待を残す。

## カタログの中で

BABY BABY BABY、本作、Happy Go Round と、NNBS. は 3 作続けて vi 始まりの循環を曲の背骨に据えている。そのなかで本作は BPM 156 と、カタログ全体でも 22 位の中速帯にあり（BEACH! BEACH!、Summer land の 155 とほぼ同じ）、BPM 200 の BABY BABY BABY や 220 の Happy Go Round とは明らかに違う方向を向いている。速さで煽る代わりに、ペダル和声とペンタトニックのベースで「踊らせる」ことに振った曲だ。

数字の上でもそれは表れている。お祭り感 8.0 と沸かせる側に大きく寄りながら、疾走感は 4.5 と中位にとどまる。キュート 5.5、クール 5.0 とかわいさと格好よさがほぼ拮抗しているのも、バッキングギターとギターソロが入るバンド寄りの音作り（バンド 6.5）と、「もきゅもきゅ」の遊び心が同居しているからだろう。

## 総評

「名もなき勇者」「カラフルレジスタンス ここからだ」と、個性ばらばらの仲間が集まって起こす抵抗を歌う曲である。和声の仕掛けはどれも小さい。ループを押し戻す C#dim、トニックの上で影を落とす Ab、一段ずつ上がるベース。しかしその小さな仕掛けが、テンポに頼らずに場の熱を上げていく。7 まで数えて vi で終わる幕切れまで、ライブで観客と一緒に完成させることを前提に組まれた、NNBS. の職人的なダンスチューンだ。
