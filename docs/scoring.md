# 9 軸スコアの付け方

新曲を既存の曲と同じ物差しで点付けするための基準。各軸の説明は、いまの `songs.json` のスコアから読み取った目安で、迷ったら「基準になる曲」と聴き比べて決める。

## 尺度

- 0〜10、0.1 刻み。5.0 がカタログの真ん中。
- 初期の 32 曲は、軸ごとに曲の順位を付け、その順位を正規分布に当てはめた値（probit 正規化。平均 5.0・SD 2.3）。そのため各軸の最上位は 9.9、最下位は 0.1 で、値は 0.1 / 1.2 / 1.8 / 2.3 … / 8.8 / 9.9 の決まった並びになる。
- 後から追加した曲（BABY BABY BABY 以降の 4 曲）は全体を正規化し直さず、既存の曲と比べて **0.5 刻み**で置いている。新曲もこのやり方にそろえる。
  1. 軸ごとに、その曲が既存の曲のどのあたりに入るかを決める（「CANDY POP より上、もちぷるより下」など）。
  2. 前後の曲の値の間を 0.5 刻みで選ぶ。
  3. 既存の最上位（9.9）や最下位（0.1）を超えると思う場合でも、9.5 / 0.5 に留める。超える曲が増えてきたら、全体の正規化し直しを検討する。

## 各軸の基準

基準になる曲は、上位・下位それぞれ 3 曲と、真ん中あたりの曲（中央値付近）。

### 表現

| 軸 | 何を見るか | 高い曲 | 真ん中 | 低い曲 |
|----|-----------|--------|--------|--------|
| **キュート** cute | 歌い方・言葉・音色のかわいらしさ、甘さ | もちぷる 9.9 / LOVE ME DO DO 8.8 / CANDY POP 8.2 | HELLO!! Hey!! WORLD!! 5.1 | MAGNET 1.8 / SUMI-HAJI 1.2 / Next Story 0.1 |
| **クール** cool | 硬質さ、かっこよさ、突き放した温度感 | MAGNET 9.9 / Hey! get up kids 8.8 / DIAMOND JET 8.2 | Hey!Baby! 4.7 | CANDY POP 1.8 / LOVE ME DO DO 1.2 / もちぷる 0.1 |
| **エモ** emo | 切なさ、胸に迫る感情の深さ | Next Story 9.9 / SUMI-HAJI 8.8 / MAGNET 8.2 | LOVE ME DO DO 4.7 | BABY BABY BABY 1.5 / PLAYFUL ROMANTIC 1.2 / もちぷる 0.1 |

キュートとクールは、ほぼ反対の関係になっている（相関 -0.87）。両方とも高い・両方とも低い曲は少ないが、付けるときは別々に判断する。

### キャラクター

| 軸 | 何を見るか | 高い曲 | 真ん中 | 低い曲 |
|----|-----------|--------|--------|--------|
| **子供心** childlike | 歌詞や音の無邪気さ・幼さ、おもちゃっぽさ、遊び心 | もちぷる 9.9 / GALAXY! GALAXY! 8.8 / 7777777 8.2 | ジェットコースターLIFE!! 5.0 | OK 1.8 / SUMI-HAJI 1.2 / Next Story 0.1 |
| **ハッピー度** happy | 曲調と歌詞の明るさ、聴いたあとの晴れやかさ | もちぷる 9.9 / CANDY POP 8.8 / Happy Go Round 8.5 | ご機嫌マミーはご機嫌ガール 5.9 | MAGNET 1.8 / SUMI-HAJI 1.2 / Next Story 0.1 |
| **お祭り感** party | ライブで沸かせる力、コール・掛け声・一体感 | PLAYFUL ROMANTIC 9.9 / BABY BABY BABY 9.5 / Happy Go Round 9.0 | Hey! get up kids 5.3 | MAGNET 1.8 / SUMI-HAJI 1.2 / Next Story 0.1 |

この 3 軸とエモは、いまのスコアでは強く連動している（子供心とエモの相関 -0.89、お祭り感とハッピー度の相関 0.88 など）。曲の全体の印象に引っ張られないよう、次の違いを意識して 1 軸ずつ付ける。

- **子供心**は「幼さ・無邪気さ」。明るさではない。子供っぽいのに切ない曲なら、子供心は高く、ハッピー度は低くてよい。
- **ハッピー度**は「明るさ」。大人っぽく落ち着いた明るい曲なら、子供心は低く、ハッピー度は高くてよい。
- **お祭り感**は「ライブで沸く力」。明るくなくても、コールが多く一体感のある曲なら高い。

### サウンド

| 軸 | 何を見るか | 高い曲 | 真ん中 | 低い曲 |
|----|-----------|--------|--------|--------|
| **バンド** band | 生のギター・ベース・ドラムが前に出ているか（低いほど打ち込み・エレクトロ） | Hey! get up kids 9.9 / ビスケットケース 8.8 / LOVE ME DO DO 8.2 | HELLO!! Hey!! WORLD!! 5.3 | Tickey Luppy Doo 1.8 / 7777777 1.2 / もちぷる 0.1 |
| **疾走感** speed | テンポの速さ、前へ進む勢い | Hey! get up kids 9.9（BPM 210）/ Happy Go Round 9.5（220）/ MY FIRST LOVE SONG 8.8 | CANDY POP 4.9 | LOOK!! 1.8（125）/ OK 1.2（125）/ Tickey Luppy Doo 0.1（118） |
| **複雑度** complexity | 和声・転調・構成の凝り具合 | Hey!Yummy! 9.9 / DIAMOND JET 8.8 / POJI POJI GO 8.2 | BIRD TRIP 5.3 | CANDY POP 1.8 / もちぷる 1.2 / 7777777 0.1 |

- **疾走感**はほぼ BPM で決まっている（BPM との相関 0.97）。まず BPM で既存の曲の中の位置を決め、ビートの刻みや勢いの体感で少しだけ前後させる。
- **複雑度**は `harmony_note` の内容が手がかりになる。セカンダリードミナント・借用和音・転調・変拍子が多いほど高く、少ないコードの循環だけなら低い。

## マップとの関係

スコアから 3 つのマップの座標が決まる（式は `songs.json` の `map*_definition`）。新曲を `tools/new-song.js` で追加すると、座標は自動で計算される。

| マップ | x | y |
|--------|---|---|
| ステージ | クール − キュート | (お祭り感 − 5) × 2 |
| サウンド | (バンド − 5) × 2 | (疾走感 − 5) × 2 |
| ムード | (子供心 − 5) × 2 | ハッピー度 − エモ |

ムードマップは子供心と「ハッピー度 − エモ」が強く連動しているため、曲が右上から左下への帯に集まり、「洗練ポジティブ」（大人っぽくハッピー）と「切なかわいい」（子供っぽくエモ）がほぼ空いている。これはカタログの傾向として受け入れている。新曲が本当にその性格なら、遠慮なくそのエリアに入るスコアを付けてよい。
